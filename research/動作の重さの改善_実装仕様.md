### 案2 詳しく
- (a) `chipStack(amount,label,big,small,seed)` は、同じ引数・同じ `BB()`・同じ `innerWidth<620` なら同じ文字列を返す。`Map` に覚えておく（3000件を超えたら空にする）。
- (b) 書く前に `el.dataset.h`（または `el._h`）と比べ、同じなら書かない。ただし次の2つに気をつける：
  - `.won-pile` を後から `.mystack` に付け直している（今のコードのまま動く。書かなかった時は既にそこにある）。
  - 書いた後に中身を動かす処理（降りた札の動き `muckAdd`、`fitTable` の translate など）。同じ文字列で書かなかった時に、その飾りが残って困るものがないか見る。困るものは、その時だけ `el._h=''` にして次は必ず書く。
- `cardAnim`・`anim`（noanim）のように、毎回変わる飾りの文字が入ると比べても同じにならない。効果を出すには、作る文字列が「見た目が同じなら同じ」になるようにする（試作では15秒でチップの山の計算が280回→3回）。

### 案4 詳しく（01b_style_perf.css）
```css
/* 揺れは番の相手・テルが出ている相手・にらみ中だけ。呼吸は残す（テル「じっと」は呼吸を止めて見せるため） */
.bust:not(.turn):not([class*=cue-]):not(.stare){animation:none}
/* 降りた人・抜けた人・見ている人は呼吸も止める */
.bust.folded .body,.bust.out .body,.bust.watch .body{animation:none}
/* 奥の列のチップ：暗くする効果をやめ、色を少し暗くして同じ見た目に */
.stack.tw .trow.back .chip{filter:none;--c:color-mix(in srgb,var(--c0,var(--c)) 92%,#000);--d:color-mix(in srgb,var(--d0,var(--d)) 92%,#000)}
```
- チップの色は `.chip.c3{--c:…;--d:…}` のように色ごとに入っているので、上の color-mix がそのまま効かない場合は、色ごとに奥用の暗い値を書く（brightness(.92) と同じ＝各色を8%黒に寄せる）。
- ついでに：01_style.css に `@keyframes blink` が2つある（188行の「考え中…」用と426行のまばたき用）。188行の方を `@keyframes thinkBlink` に名前を変え、187行の `.seat .tag.think` もそれに合わせる。

### 案3 詳しく（36_layout_pass.js）
今は1回打つと、render と13個の後付け処理が「書いてすぐ測る」をくり返し、画面の形の計算が40〜54回起きている。これを1回にする。
1. `layoutSoon()` を作る：何回呼んでも、次のコマの頭（`requestAnimationFrame`）で1回だけ `LT.emit('layout')` を出す。
2. `LT.on('render',layoutSoon)` と、`resize` で `layoutSoon` を呼ぶ。
3. render の後で位置を測っている次の処理を、render の中から外して `LT.on('layout',…)` に移す：
   - faceFit（30c_ui64.js の `LT.on('render',…faceFit)` を `'layout'` に）
   - talkPlace（25_cpu.js、renderTalk の中で呼んでいる分）
   - クセの札の位置（27_render.js の `cb.style.right/top` を決める所。render では札を作るだけにして、位置は layout で）
   - nmAfterRender（33_names.js）、tbMetaSync・needleSync・barSync（30c_ui64.js）、ltTags（21d_live_table.js）、potSignPlace
   - fitTags・fitTable・fitMyHand（24_dokidoki_camera.js）
4. layout の中では、できるだけ「全部測ってから全部書く」順にする（測る→書く→測る…をしない）。
5. 見回り（setInterval）は、0.12〜0.3秒ごとに測るのをやめ、`layoutSoon` を待つ形にする。安全のため1秒ごとに1回 `layoutSoon()` を呼ぶ見回りだけ残す。対象：`setInterval(fitTags,200)`、`setInterval(()=>{fitTable();fitMyHand();tourGuard();fitScene()},300)`、`setInterval(barSync,250)`、`setInterval(tipTick,250)`（中で位置を測っていれば）。`fitRaise`（150ms）はパネルを開いた時だけ動くので、パネルを開く所から呼ぶ。
6. 吹き出しの追いかけ `sayFollow` は毎コマ動いている。出ている吹き出しが無い間は `requestAnimationFrame` を止め、吹き出しを出す時（`.say` に `go` を付ける所）とカメラが動く時（`camTo`）にだけ再開する。
- 位置がずれる心配がある所は、3画面の画面チェック（下の「できた」）で必ず見る。
