## 入っているもの
- ゲンと 1対1（ブラインド 1,000/2,000、持ち点 60,000）。どちらかのチップが尽きるまで何ハンドでも遊べる
- 卓：ラシャの質感、木の縁の光沢、金の線、ランプの光だまり（すべて GPU の描画プログラムで描画）
- 店：板張りの壁、吊りランプ3つ（光の筋とちらつき）、港の夜の窓、ぼけた灯り、客の影、立ちのぼる煙、光の中のほこり
- カード：山から弧を描いて配る、めくる、バーン、フォールドで捨て札へ、勝った5枚が光って浮く（他は暗くなる）
- チップ：色ごとに積んだ立体の山。賭けると飛んでいき、ポットにまとまり、勝った人へ戻る
- ゲン：呼吸・揺れ・まばたき。テルは今のゲームと同じ（強いと笑う 75%、弱いとしゃべる 70%、関係なく出る 10〜15%）。テルの時はカメラが顔に寄り、周りがぼけて暗くなる
- ジンの一言（最初の説明、テルを初めて見た時の解説）
- その場で作る効果音（カード・チップ・ノック）
- 右上に「なめらかさ」（1秒あたりのコマ数）。P キーで出し消し
- キー操作：F フォールド、C チェック/コール、R レイズ、A オールイン、Enter 次へ

## 入っていないもの（本格的に移すなら必要）
- 会話・ストーリー場面、章の扉、15章ぶんのデータ、他のキャラ（顔の絵は今のゲームから書き出せる）
- 6人卓、英語版、セーブ、設定、音楽、PC向けリッチ演出のうちディーラーの手など
- 自動検査（今の qa/ は Web 版の画面の部品を測る仕組みなので、Godot 用に作り直しが要る）

## 作り方
- Godot 4.7.2（無料、MIT）、描画は Web でも動く「Compatibility」
- ゲンとジンの顔は今のゲームの絵（avatar()）を 1000px の画像に書き出して使った（face.js）。ふつう・笑う・しゃべる・まばたきの4枚
- フォントは Zen Kaku Gothic New / Shippori Mincho B1 / Oswald（いずれも OFL）を使う文字だけに絞って同梱
- 書き出し：build.sh（project/ を Web 用に書き出す）。公開先の1ファイルの上限に合わせ、エンジン本体を3つに分けて置き、ページ側でつなぎ直している
- コードは約1,700行（main.gd が流れ・演出・相手の考え、card.gd カード、chips.gd チップ、hand_eval.gd 役の判定、shaders/ 店・卓・画面の仕上げ）

## 分かったこと
- 1卓ぶん（遊べる状態）はこのスレッドの作業で作れた。全体を移すと、会話・15章・6人卓・英語版・自動検査の作り直しが加わる
