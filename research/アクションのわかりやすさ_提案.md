# 誰が何をしたか分かりにくい（2026-10-17 satou）

## 原因（v0.88.2）
- v65「ライブ感の総点検 案1」で、名札の行動の札（チェック／コール／レイズ）を消した（src/js/21d_live_table.js `ltTags`）。残るのは名札が0.7秒光るだけ。
- 第4章以降はフォールドの札も消している（src/01e_style_live_look.css 3行目）。降りた人は顔が暗くなるだけ。
- ディーラーの声はベット・レイズ・オールインのときだけで、誰かは言わない（src/js/24_dokidoki_camera.js 205行目「レイズ、13,000」）。コール・チェックは声なし。
- 結果、自分の番になったとき、誰がレイズして誰がコールしたかが卓に残っていない。

## 案（見本 https://claude.ai/artifact/MMZBSQRqCrVWTPy41sw9To 、動画 research/アクションのわかりやすさ_全案.mp4）
1. 席の前に小さく行動の文字：名札の下に「レイズ」「コール」「チェック」「フォールド」を、色の箱なしの細い文字でそのストリートの間残す。額は出さない。
2. ディーラーが名前と行動を言う：「レイカさん、レイズ 13,000」「ソウさん、コール」と毎回。席番号（.llseats）を添える。名乗っていない相手は who() の呼び名。
3. 最後に動いた人に手元の灯り：次の人が動くまで明るいまま。いちばん強く賭けた人の名札に赤い細線。
4. 自分の番で「ここまでの流れ」：案内の欄に「レイカ レイズ 13,000 → ソウ コール → 3人降り」。

おすすめ：案1＋案2（卓を見れば今の状態、声で流れ。どちらもライブのディーラーと卓の見え方に近い）。

## 守ること
- 額の数字は名札に戻さない。ボタンを増やさない。ch1-3 の難しさ、CPU の考える時間、第7章ジンのテルは触らない。表示だけ。
- アニメ軽量化（dev/anim-lane）とぶつけない：:has() を使わず目印 class、新しいファイルで ltTags の後ろに足す。
- 変更後は縦・横・PC の UI 確認（名札の下の文字が席番号・D・吹き出し・チップに重ならないこと）。
