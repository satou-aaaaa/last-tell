# UIリッチ化 実装仕様（案1〜5 全部）

- 決定: 2026-10-09 satou「全部いいですね。これで進めてください。」
- 見本: research/UIリッチ化_見本.html（https://claude.ai/artifact/7SJ2DWidCmRgRkUedZh4cX）。CSS は見本の `.t1`〜`.t4` と `.ttl.rich` をそのまま流用できる。
- 動画: research/UIリッチ化_全案.mp4 ／ 提案の説明: research/UIリッチ化の提案.md
- 対象: story/shisho.html（担当: ストーリーモードの企画提案スレッド）

## 守ること
- 見た目と演出だけを変える。ルール、操作、ボタンの数、第1〜3章の難しさ、テルの出る率は変えない。第7章のジンの本物のテルは強調しない。
- キャラの絵（chars.js / avatar）には触れない（「キャラの見た目をリアルに」スレッドの担当）。
- 画像ファイルは増やさない。質感は CSS のグラデーションと、小さな SVG ノイズの data URI（見本の `--noise` と `--grain`）で作る。
- `prefers-reduced-motion` のときは、もや・光の走り・またたき・ぬぐい・光の輪の回転を止める（静止した見た目は残す）。
- カメラ演出（案2）とポットの山（案E）の今の動きは変えない。
- 変更のたびに UI チェックをする。スマホ縦 390×844、スマホ横 844×390、PC 1280×800 で、4人卓と6人卓の両方。手札・ボタン・チップ数・吹き出しが隠れたり重なったりしないこと。

## 案1　卓の素材と光
対象: `.felt-wrap` / `.felt`（319〜323行付近）、`#table` の背景
1. フェルトの塗りを3層にする（見本 `.t1 .felt`）。
   - 上: ランプの光 `radial-gradient(ellipse 48% 40% at 50% 34%, rgba(255,226,170,.20), transparent 70%)`
   - 中: `var(--noise)` を 140px で敷き、`background-blend-mode: soft-light`（毛並み）
   - 下: `radial-gradient(ellipse 70% 60% at 50% 40%, #1d5a4d, #0f3029 70%, #0a211c)`
   - 内側の影: `inset 0 1.2cqw 3cqw rgba(0,0,0,.55)` 相当（ゲームでは px で 10〜14px）。
2. 縁のレール。今の `inset box-shadow`（茶と金の線）をやめ、`.felt` の外側に `.rail` 要素を1つ足す。同じ回転（rotateX(50deg)）の中に置く。
   - 塗り: `radial-gradient(ellipse closest-side, transparent 0 88%, #5b3a26 89.5%, #7a5038 91.5%, #3b2417 95%, #1a0f09 98.5%, #c79a4c 99%, #3a2a14 100%)`（革のふくらみ＋外側の金の細線）
   - 革のざらつき: `::after` に `--noise` を overlay で重ね、mask でリング部分だけに限る。
   - ステッチ: `.stitch` を1つ足し、`border: 1.5px dashed rgba(226,182,91,.35); border-radius: 50%`。
3. ベッティングラインは点線から細い実線にする（`rgba(226,182,91,.32)`）。外側に薄い光を付ける。
4. ロゴの刷り込み: フェルトの中、ボードとポットの間に「LAST TELL」を明朝体、字間 .5em、`rgba(226,182,91,.16)` で置く。ポット表示とポットの山の下に来るように z-index を下げる。
5. ランプ: 卓の上に `.lamp` を1枚置く（`mix-blend-mode: soft-light`、中央が明るい楕円）。テーブル外の背景の上部にも、暖色の光を薄く足す。
6. もや: `.haze` を2つのぼかした楕円で作り、14秒でゆっくり動かす。不透明度は .5 以下。`pointer-events:none`。カメラが寄るときも一緒に動いてよい。
- 第4〜6章の6人卓も同じ見た目にする。店ごとの色（`--venue` など）がある場合は、フェルトの色だけ店の色にしてよい。

## 案2　カードとチップの質感
対象: `.card`（198〜219行）、`.card.back`（540行付近）、`.chip`（550行付近）
1. カードの表:
   - 塗り: 斜めの光 ＋ `var(--grain)`（90px）＋ `linear-gradient(170deg,#fbf8f0,#ece5d5)`。`--grain` は見本のもの（アルファ .13）を使う。黒い `--noise` を multiply すると灰色に濁るので使わない。
   - 内側の印刷線: `::before` で `inset:7%` に 1px の枠、`currentColor`、不透明度 .16。
   - 数字（`.r`）を明朝体（`--display`）にする。右下に180度回した同じ表示を足す（`.ix.bt` 相当）。中央のマークは中央に寄せ、白い上ハイライトと下の細い影を付ける。
   - 今の `.card::after`（光の斜線）はそのまま残す。勝ち札の光（案4）は別の要素で出す。
2. カードの裏: 今の赤い格子柄をもとに、中央に金の楕円エンブレム、金の細い格子にする。5秒に1回、光の帯が斜めに走る（`background-position` のアニメ、見本 `@keyframes sheen`）。白い外枠は残す。
3. チップ: 今のカジノチップ（縁のインサートと中央の円）をもとに、
   - インサートを 8か所 → 白とチップの色の比をやや白多めにして、小さくても模様が見えるようにする。
   - 中央の刻印の周りに白い細い輪を足す。
   - 側面の段を2段（`0 2px 0 暗色`, `0 4px 0 さらに暗色`）にして、積んだときの厚みを出す。上面に薄いハイライト。
   - サイズは変えない（ポットの山の当たり判定と配置を変えないため）。

## 案3　ボタンと名札の質感
対象: `button.act`、`.actionbar`、`.plate`、`#potSign`、`.quick` のボタン
1. アクションバー: 背景を上から薄い光 ＋ `--noise`（soft-light）＋ `#171922→#0b0c11`。上端の赤い線は、金の 1.5px のハイライト ＋ 上にじむ赤い光（`0 -4px 16px rgba(215,38,61,.25)`）に変える。
2. ボタン（フォールド・コール・レイズ、クイックベット）:
   - 上から下への3段グラデーション（見本 `.t3 .act.*`）。上端に白い内側ハイライト、下端に黒い内側の影。
   - 名前と金額の間に、薄い細い線を入れる。金額は金色（`#ffe1a0`、フォールドは灰色）。
   - 押したとき: 2px 沈んで少し明るくなり、光が左から右へ一度流れる（0.4秒）。今の `:active` の動きと置き換える。
   - 平行四辺形の形、色の意味（灰・緑・赤）、無効時の薄さは変えない。
3. 名札（`.plate`）: 黒の縦グラデーションに金の細い縁、角を2か所切る。名前は明朝体、字間を広げる。手番の人は金の縁を太くして外側に金の光。
   - 6人卓のスマホ縦では名札が小さいので、字間は広げすぎない（.06em まで）。はみ出しを必ず確認する。
4. ポット表示（`#potSign`）: 同じく黒い板に金の縁、左右を斜めに切る。

## 案4　動きの手ざわり
1. 持ち時間の光の輪:
   - 自分の番: 今の時計バー（`#clock`）は残し、自分の名札の周りにも同じ残り時間で減る金の輪を出す（`conic-gradient` ＋ `@property --p`、見本 `.t4 .plate.turn::after`）。残りが少ない（`.clock.low`）ときは輪も赤にする。
   - CPU の番: 残り時間はないので、減る輪ではなく、金の光の点が名札の周りをゆっくり1周し続ける（考えている合図）。
2. ポットの数字: `potCount` で数字が増えたとき、`.pv` を一瞬 1.18 倍にして金の光を付ける（0.5秒、見本 `@keyframes bump`）。減るとき（勝者に配るとき）は付けない。
3. 勝ち札と役名:
   - ショーダウンで勝った手に使われたカード（今 `.card.win` が付くもの）を 6〜8px 浮かせ、表面を光が1回走る（専用の子要素で出す）。
   - 同時に、ボードの下（ボードとポットの間）に役名を金の札で 1.6秒出す（明朝体、字間 .3em、見本 `.t4 .stamp`）。英語版は英語の役名にする。ショーダウンなしで終わったハンドでは出さない。
   - 名札の `.handname` はそのまま残す。
4. 場面転換: 「次のハンドへ」を押したとき（`startHand` の直前）、赤い斜めの線と黒い帯が画面を左から右へぬぐう（0.45秒、見本 `@keyframes wipe`）。章の始めとストーリーの場面切り替えにも同じぬぐいを使う。設定の「速さ：速い」では 0.25秒にする。
- どれもタップを止めない（`pointer-events:none`）。第1〜3章のテル、カメラのテルへの寄りより前に出ないこと。

## 案5　タイトル画面
対象: `#title`、`.logo`（58〜70行付近）
1. 「LAST TELL」をネオン管風にする。LAST は白に暖色の光、TELL は淡い赤に赤の光（見本 `.ttl.rich .logo` の text-shadow）。LAST の T だけ、6秒に1回ちらつく。
2. 背景: 上の方にバーの酒棚の灯り（縦の暖色と青の細い光をぼかしたもの、左右を mask で消す）と、ノイズを薄く重ねる。今の夜の街の背景（body::before/::after）はタイトル画面だけ弱める。
3. 今の主人公の立ち絵（`.hero`）の位置はそのまま。スマホ縦で立ち絵の上下にスペースがあれば、その後ろにカードの扇（裏・A♠・K♥）を置き、一番手前の1枚がときどき少しめくれる。重なって立ち絵の顔を隠す場合は、扇は PC と横向きだけに出す。
4. メニューのボタンは案3と同じ質感にする（ストーリーは赤、他は暗い色に金の縁）。主ボタンだけ光が4秒に1回流れる。

## 確認
- 3つの画面サイズ × 4人卓・6人卓で、手札、ボタン、チップ数、吹き出し、名札、役名の札が隠れたり重なったりしないこと。
- 見た目を足したことで、スマホでの動きが重くならないこと（もやとノイズは1枚ずつ。ぼかしのかかった要素を増やしすぎない）。
- 英語版で、役名の札とボタンの文字がはみ出さないこと。
- `prefers-reduced-motion` で動きが止まること。
