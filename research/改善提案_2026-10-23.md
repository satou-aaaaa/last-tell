## 0-1. ゲームを閉じるたびに落ちる

### 起きていること
- `godot --path game`（タイトルのまま）を `--quit-after` で閉じる、第1章を遊んで `get_tree().quit()` で閉じる、画面なし（`--headless`）で閉じる — **どれも終わりの値 134（落ちた）**。日本語・英語どちらでも同じ。
- gdb で見ると、終わりの片付けの中で `pthread_mutex_lock` に壊れた場所を渡して SIGSEGV。その前に「CanvasItem の RID が 9〜12 個残った」の警告。
- 原因を絞った：`core/i18n.gd` の英語の訳（`Translation`）を `TranslationServer.add_translation` で付けたまま、`static var _inst` が持ち続けている。閉じる前に `TranslationServer.remove_translation(I18n._inst)` をすると **終わりの値 0**（ほかの静的な入れ物（絵・フォント・背景）を空にしても変わらず、訳を外したときだけ直る）。

### 困ること
- Windows では確かめていないが、同じ作りなので閉じるたびに落ちている見込みが高い。テスターに送ってもらう記録（user://logs）に毎回「落ちた」が残り、本当に落ちた記録と見分けがつかない。
- 「前回は途中で終わりました」の案内（main.gd `_crash_check`）は、印を `tree_exiting` で先に消すので出ない。つまり **終わりの片付けで落ちる不具合は、案内でも拾えない**。
- Steam などに出すときも、終わりで落ちるのは審査・クラッシュの集計で目立つ。

### なぜ検査で見つからなかったか
- 落ちることは前から分かっていて、**検査の側だけで避けていた**：tests/run_keys.gd・check_i18n.gd・check_text_size.gd の終わりと、配布版の通し検査で使う `main.gd` の `bench … quit` だけに `TranslationServer.remove_translation(I18n.inst())   # 付けたまま終わると落ちる` がある。
- そのため配布版の通し（tools/release_smoke.sh）は「ゲームのふつうの閉じ方」を一度も通らず、毎回 ✅ になっていた。

### 直し方（Godot 担当）
- `I18n` に `static func shutdown()`（訳を外して `_inst = null`）を作り、`main.gd` の `_exit_tree()`（窓を閉じる・やめる・quit のどれでも通る）で呼ぶ。
- 検査・bench の終わりにばらばらに書いた `remove_translation` は消して、`I18n.shutdown()` か、何もしない（main を通るものは main が外す）にそろえる。

### 再発防止の仕組み
- **検査（tools/release_smoke.sh に1つ足す）**：配布版で「タイトルを開いて、ふつうに閉じる」（`--quit-after 120` など、検査用の抜け道を通らない終わり方）。終わりの値が 0 でなければ ❌「閉じるときに落ちた」。今の bench は検査用の終わり方なので、それとは別に。
- **検査（qa.sh）**：編集ソフトでも同じ「開いて閉じる」を1回（数秒）。
- **dev/決めたこと.md（Godot の節）**：「検査の終わりだけで不具合を避ける書き方（『付けたまま終わると落ちる』のような）はしない。見つけたら、ゲームの側で直してから検査を通す」。
- **qa.sh の頭**：`--script` の検査は main.gd を通らない（＝ゲームの始まり・終わりの処理を見ていない）ことを1行書く。

## 0-2. 卓の字が重なる（ディーラーの声・相手の吹き出し・結果の帯）

### 起きていること（第1章、ゲンと一騎打ち、1600×900）
- **ディーラーの声が相手の吹き出しに乗る**：「ベット、5,000」「ターン」「スリーカードで、あなたの勝ちです」が、ゲンの吹き出し（「うーん、迷うぜ」「ええい、コールだ！」「ナイスハンド」）の上の縁に重なり、両方読みにくい。英語でも「“Showdown”」が「I'll wait and see.」の上に乗る。8 枚撮って 4 枚で重なった。
  画像：[ディーラーの声と吹き出し.jpg](改善提案_2026-10-23/ディーラーの声と吹き出し.jpg)・[英語_Showdown_と吹き出し.jpg](改善提案_2026-10-23/英語_Showdown_と吹き出し.jpg)
- **ハンドの終わりに3つ重なる**：ディーラーの声・ゲンの「ナイスハンド」・人だかりの「（周りの客）おお……」が同じ所に重なる。さらに結果の帯「あなたの勝ち（スリーカード・+94,000）」が **ゲンの見せた札（9♣ など）の上** に乗る。勝ち負けは画面の上（字幕）にも同じ文が出ていて、2回出ている。
  画像：[ハンドの終わり_字の重なり.jpg](改善提案_2026-10-23/ハンドの終わり_字の重なり.jpg)
- 2026-10-22 の配置の決まり（字幕・声・結果の帯は互いに避ける、ディーラーの声はカードを避ける）に合っていない。

### なぜ起きるか
- scenes/table/table.gd で、字の置き場所が固定の数字：字幕 `lbl_msg` (400,16)、ディーラーの声 `lbl_dealer` (500,58)（コメントは「字幕の下（場札・相手の札にかからない）」）、結果の帯 `banner` (200,408)–(1400,468)。
- 一騎打ちと少人数の卓では、相手が上の真ん中に座るので、吹き出しが y≈60〜110 に出て、ディーラーの声とちょうど同じ高さになる。相手の見せた札は y≈420〜490 で、帯と同じ高さ。
- 人だかりの声（features/talk/crowd.gd）も同じあたりに出るが、ほかの字を避ける仕組みが無い。

### 直し方（Godot 担当）
- 相手の吹き出しが出ている間は、ディーラーの声を吹き出しと重ならない所へ（例：場札のすぐ上の左。Web 版で寄せた場所と同じ考え）。人だかりの声も同じく、出ている字を避ける。
- 結果の帯は、相手の見せた札・自分の札・場札のどれにもかからない高さへ（例：場札と自分の札の間）。字幕と帯で同じ文を2回出さない（帯を出す間は字幕を消すか、字幕は短くする）。

### 再発防止の仕組み
- **検査（新しく tests/check_table_layout.gd）**：画面ありで、第1章（2人）・第4章（4人）・フリー6人を自動で打たせ、0.25 秒ごとに「見えている字の箱」（字幕・ディーラーの声・吹き出し・人だかり・結果の帯・ジンの一言・名札・ボタン）と「札の箱」（自分・相手の見せた札・場札）を取り、**字どうし・字と札が 4px 以上重なったら NG**（Web 版 qa/checks/ui.js の重なり検査と同じ考え）。どの場面・何秒目・どの2つかを出す。qa.sh に入れる。
- 今の写真の正解比べは「前と同じか」しか見ず、最初から重なっている写真をそのまま正解にしていた。正解を作り直すとき（`compare_shots.gd -- update`）は、上の検査が通ってからにする、を README に書く。
- **dev/決めたこと.md**：「卓に字を出す部品を足すときは、置き場所を固定の数字にせず、ほかの字・札を避ける仕組み（table.gd に1つ作る）を通す」。
- 見逃した理由：Godot の検査は、物語の会話の画面（shot_story.gd）とモードの画面（shot_modes.gd）には重なりの検査があるが、**卓の画面には無い**。Web 版の ui.js の重なり検査を移していなかった。
