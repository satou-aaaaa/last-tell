# ライブポーカー要素 実装仕様

対象：`/mnt/project-files/story/shisho.html`（担当は「ストーリーモードの企画提案」スレッド）。背景は [ライブポーカー要素調査](ライブポーカー要素調査.md)。2026-10-08 にユーザー（satou）が「まさに、こういう要素を取り入れたい」と承認した。

実装の順番：**1. テル → 2. テーブルトーク → 3. ハウスルール → 4. ディーラーと店の演出**。1つずつ遊べる状態で出す。

守ること
- 第1〜3章は難易度が承認済みなので、勝敗に影響する変更は入れない（見た目やセリフは追加してよい）。テルを本格的に使うのは第4章「嘘を見抜け」から。
- チップは点数のまま。実在の店の特典などとはつながない。
- `prefers-reduced-motion` のときは動きを止め、テルは文字（ログ）で伝える。
- 下の関数名と行番号は 2026-10-08 時点の shisho.html を読んで書いた。表情アニメーションの作業で変わっている可能性があるので、最新の状態に合わせて読み替えること。

## 1. テル（表情やしぐさのクセ）

### 考え方
- CPUごとに「強い手のときのクセ」と「ブラフのときのクセ」を1つずつ持たせる。
- クセは**いつも出るわけではない**し、たまに嘘をつく。読めば得をするが、絶対ではない。
- ショーダウンで手が見えたときに「さっきのクセは本当だった／嘘だった」がわかり、プレイヤーが学べるようにする。

### データ（`CHARS` の近くに追加）
```js
const TELLS={
  // cue: 見た目の種類, rate: その状態のとき出る確率, false: 関係ないときに出てしまう確率
  'ロク':{strong:{cue:'still',rate:.7,false:.1}, bluff:{cue:'stare',rate:.6,false:.1}},
  'セキ':{strong:{cue:'glance',rate:.7,false:.1}, bluff:{cue:'talk',rate:.7,false:.15}},
  'ミナ':{strong:{cue:'smile',rate:.6,false:.15}, bluff:{cue:'fast',rate:.7,false:.1}},
  // 第4章以降のボス：reverse:true で、途中からクセの意味を逆にする（逆テル）
};
```
`cue` の種類（表情・動きのアニメーションで表現）：
| cue | 見え方 | 主な意味の例 |
|---|---|---|
| `glance` | 賭ける前に自分のチップをちらっと見る | 強い（もう参加する気でいる） |
| `still` | 急に動かなくなる、息を止める | 強い |
| `smile` | 口元がほんの少し緩む | 強い |
| `stare` | こちらをじっと見つめてくる | ブラフ（威圧） |
| `talk` | いつもより口数が多い | ブラフ |
| `fast` | 考えずにすぐ賭ける | ブラフ |
| `sweat` | 汗（既存の `SWEAT` を流用） | 弱い・迷い |

### 判定（`cpuAct` に追加）
- `cpuAct` ですでに出している `rel`（手の強さ）とスタイルの `st.hi` を使う。
  - 状態 `strong`：`rel > st.hi`
  - 状態 `bluff`：レイズを選んだのに `rel < 1`（`toCall===0&&r<st.bluff` の枝に入ったとき）
  - それ以外：`none`
- 状態に合うクセを `rate` の確率で、合わないクセを `false` の確率で `p.tell={cue,seq}` に入れる。
- 表示は**アクションの直前**。今の待ち時間（`proceed` の `650+Math.random()*600`）のあいだにクセを見せ、そのあと賭ける。
- `fast` だけは待ち時間を短く（200ms程度）する。逆に強いときはわざと長く考えるキャラがいてもよい（タイミングのテル）。

### 逆テル（ボス）
- `reverse:true` のキャラは、章の後半（例：自分のチップが初期値の半分を切ったら、または10ハンド目以降）からクセの意味を入れ替える。
- 師匠が「……今のは、わざとだ」とひとこと言う演出を1回だけ入れる。

### ショーダウンでの答え合わせ
- そのハンドで出たクセを `p.tellLog` に残し、ショーダウンで手が見えたら、ログに「ロクは強い手で動かなくなっていた」「セキの口数はブラフだった」のように出す。
- 一度答え合わせしたクセは「相手メモ」（後述）に自動で書き込む。

### 師匠のひとこと（`senseiLine` に `hint:'tell'` を追加）
- クセが出たら：「見たか。ロクが動かなくなった。強いぞ」
- 第4章後半はヒントを減らし、自分で読ませる。

### 第4章「嘘を見抜け」（ホテルのラウンジ）の案
- 勝利条件：`{type:'readcall',n:2}`＝「相手のブラフをコールして2回勝つ」。判定はショーダウンで、相手が最後にレイズしていて手が `isWeak` のとき。
- 相手：ブラフ多めのラウンジのディーラー（女性、提案書の「読めない女ディーラー」）＋ボス格1人。新しい STYLE `liar`（`bluff:.25` 前後）を追加。
- ボスは rank 3 以上なので「かっこいい」立ち絵（既存の `coolAvatar`）。

## 2. テーブルトーク

- `LINES` に強い手用とブラフ用の言い回しを分けて追加する（例：`raise_strong` / `raise_bluff`）。`afterAct` で、テルの状態に合わせて選ぶ。なければ今の `raise` を使う。
  - 例（セキ）：強い手「少し上げさせてもらうよ」／ブラフ「今夜はツイているようでね、もう少し上げよう」（口数が増える＝テル）
- しゃべるかどうかの確率（今は75%）もキャラごとに変えられるようにする。
- 後で足す要素（任意）：プレイヤーの「揺さぶる」ボタン。押すと相手のセリフが返ってきて、`talk` 系のクセが出やすくなる。勝敗への影響は小さく。

## 3. 店ごとのハウスルール

`CHAPTERS` の各章に `house` を追加し、章の始まりに「この店のルール」として1行で出す。

| ルール | 中身 | 実装のめやす |
|---|---|---|
| 7-2ゲーム | 7と2（一番弱い手）で勝つと全員からボーナス（BBの2倍） | `winUncontested`／`showdown` の後でボーナスを払う |
| ストラドル | ボタンの次の次の人が、配る前にBBの2倍を任意で置く | `startHand` でCPUが確率で置く。プレイヤーにはボタンを出す |
| ボムポット | Nハンドに1回、全員がBBの数倍を出してフロップから始める | `startHand` で全員に `post` してから `nextStreet` |
| ラン・イット・トワイス | オールインのとき、残りのボードを2回配って半分ずつ | 最終章向け。演出が必要なので後回しでよい |

割り当て案（勝敗に効くので第4章以降）：第5章「地下の賭場跡」＝ストラドル、第6章「王冠」＝ボムポット、第7章「錨亭、閉店後」＝7-2ゲーム（第1章の店に戻る遊び心）。第1〜3章は店の紹介文に「この店では昔〜というルールがあった」と書くだけにとどめる。

## 4. ディーラーと店の演出

- **ディーラーの声**：「フロップ」「ターン」「リバー」、レイズ時の「レイズ、◯◯」、勝者に「ポットは◯◯さんへ」。テーブル中央に短く出す。
- **配る・集める動き**：カードがディーラー位置から各席へ飛ぶ、ポットが勝者の席へすべる（既存の `slide` を流用）。`placeDealer` のボタン移動もアニメーションに。
- **マック**：降りた手はディーラーのほうへ伏せて流れる。
- **スタックはチップの山で見せる**：既存の `chipStack` を使い、数字は小さく、タップで大きく。ライブらしく「山の高さで読む」体験にする（第4章以降は数字を少し控えめに、は任意）。
- **店ごとの雰囲気**：既存の章の `color` に加えて、照明（背景のグラデーション）と環境音を店ごとに変える。音は WebAudio で軽く鳴らす程度（チップの音、低いBGM）。**最初はオフ**、設定でオン。
- **演出の速さ**：設定に「演出：ふつう／速い」。速いときはクセの表示時間とディーラーの声を短くする（テルは消さない）。
