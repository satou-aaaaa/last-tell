# 主人公の見た目を変えられる仕組み　提案（2026-10-10）

satou さん：「主人公の見た目を変更できる、といった要素をいれてもおもしろいかもしれません。提案をお願いします。」
前提（決定済み）：主人公アオの初期の見た目は紺の短髪・紺の作業ジャケット・白シャツ・胸に青い鉛筆（research/主人公アオ_実装仕様.md §3）。
見本：research/主人公の見た目を変える_見本.html（Artifact）

## 1. 今の作り（shisho.html v60 を読んだ結果）
- 絵はすべてコードで描いている。`avatar()` → `realAvatar()`（2384行）。キャラごとの定義は `REAL`。
- 多様なキャラのために作った部品 `genParts` がもう入っている。定義に書くだけで描き分けられる：
  - 肌 `SKIN` 7段階（2169行）
  - 髪型 `hs` 15種（short / crop / bald / sidepart / pixie / bob / bangs / long / wavy / ponytail / bun / curly / afro / locs / hijab）
  - 服 `outfit` 6種（tee / suit / jacket / knit / work / dress）
  - 眼鏡 `glasses`、耳飾り `earring`、ひげ `beard`、ひと筋の色 `streak`
- 主人公の定義は `REAL['あなた']`（2281行）。ここを設定から組み立てれば、卓・会話・リザルトの絵がすべて変わる。
- 第二部の師匠（年を取ったアオ）は、別の定義 `REAL['師匠']`（6142行、age:1）。今はアオと別に色が決め打ちされている。
- 卓のカードプロテクターは、章クリアでもらう仕組みがもうある（`SETTINGS.protector`）。

**つまり**、新しい絵をほとんど描かずに見た目を選べる土台はもうある。決めるのは「いつ・どこで選ぶか」「どこまで選べるか」「どうやって増えるか」。

## 3. おすすめ：案2＋案4＋案5
- **いつ**：第1章のおわり、壁の写真を撮る前（案2）。そのあとは「⚙ 設定 → 身なり」からいつでも変えられる。第1章が終わるまでは初期のアオ。
- **何を**：肌7段階・髪型8種（short / sidepart / crop / bob / ponytail / curly / afro / locs）・髪色6色（紺黒・黒・こげ茶・赤茶・灰・銀）・眼鏡3種（案4）。初期値は決定済みの紺の見た目。
- **増え方**：服は章クリアでもらう（案5）。お金では絶対に売らない。広告を見て開ける形にもしない。
- 案1は入れない（最初はすぐ遊べるほうがよい）。案3は「おまかせ」ボタン1つにまとめて、部品を選ぶのが面倒な人向けに残す（押すたびに6通りを順番に出す）。

### 物語とのつなぎ
- 壁の写真（章選択の「壁にあなたの写真」、第7章の写真の場面）は、選んだ見た目で描く。
- 第二部の師匠の顔見せ（第5章の最後、P2FACE）は、プレイヤーが選んだ見た目に年齢を足して描く（`REAL['師匠']` をアオの設定から作る：同じ肌・髪型、髪に少し白髪 `greyHair:.25`、age:1、服は最後に着ていた服）。「師匠の顔は、あなたが作った顔だった」が見せ場になる。
- 文の中で見た目に触れている所はない（服や髪の色を書いた地の文はない）ので、文は直さなくてよい。この先も、主人公の髪や服の色を文に書かない決まりにする。
- 第二部の師匠の一人称は「俺」のまま。見た目と言葉の組み合わせが気になるなら、あとで一人称を選べるようにするのは別の話として出す。

### 守ること
- 見た目は表示だけ。勝ち負け・テル・CPUの読みには関係させない。
- お金で売らない（収益化調査の方針どおり）。
- ストア画像・紹介動画・宣伝は初期のアオで作る。
- 卓の名札は「あなた」のまま。
- 暗い店の照明（fxLight）でも髪と服が背景に沈まないこと。部品の色はその条件で選んでおく。
