# アミューズメント店でよく見る客のタイプ調査（「アミュおじ」など）

2026-10-09 調査。LAST TELL のキャラ作り用。

- 既存の調査（`ライブポーカーあるある調査.md`、`マナーの悪いプレイヤー調査と実装仕様.md`）とは、なるべく重ならないようにした。重なるものは「既存」と書いて短くした。
- 並行して作っている `相手の穴とエクスプロイト案.md` は「キャラごとの穴」を扱っている。この調査は「その穴を持つ人が、店でどう見えて、どう話すか」を足すためのもの。
- 情報源はブログ、note、知恵袋、海外のポーカーサイト。ほとんどが**個人の体験や感想**で、統計ではない。「よく言われる型」として読む。
- 特定の人を名指しせず、からかう書き方もしない。ゲームでは「嫌なやつ」ではなく「どこかで見たことがある、憎めない人」にするのがよい。

---

## 0. 「アミュおじ」とは

- アミューズメントポーカー店に通う男性客を指す、ネット上の呼び名。自分で「アミュおじ」と名乗る人も多く、店が「アミュおじカップ」という大会を開いた例もある。悪口というより、**愛称と自虐が半々**の言葉。
- 客層は「20〜50代の男性が約8割」という声が複数ある（ディーラー経験者のnote、プレイヤーのnote。どちらも「感覚値」）。
- 店の仕組み（キャラの行動に関わるところ）
  - 現金は賭けない。チップは店から借りる。残ったチップは**店に預けて次回使える**店が多い。
  - 景品は、大きな大会（JOPT など）の**出場権**。大会のトーナメントは負けても**リエントリー（再参加）**できるものが多い。
  - ドリンクを頼み、ディーラーにも1杯おごれる店がある（「キャスドリ」）。
  - 閉店間際は盛り上がって、ストラドルや全額勝負が増えるという話がある。

## 1. よく見る客のタイプ（11種）

各タイプの「見た目・話し方」は、出典の記述をもとにした**キャラ化の提案**を含む。打ち方とミスは出典に書かれていることをまとめた。

### 1. 陽気な常連おじさん
| 項目 | 中身 |
|---|---|
| 見た目・小物 | ビールのグラスがいつも手元にある。席は決まっている |
| 話し方 | 「楽しんだもん勝ちでしょ」「勝っても負けても飲める」。誰にでも話しかける |
| 打ち方 | 勝ちより楽しさ優先。弱い手でもオールインやコールをいとわない。「マイハンドは 2-7」と好きな弱い手を公言する人もいる |
| よくあるミス | 手の強さより気分で参加する。負けを月単位で見ていない |
| テル | 強い手のときほど**よくしゃべる**。陽気な人が急に黙るとブラフ |
| マナー | 良い。卓を明るくする。店の空気を作る人 |

出典：うめおのnote（自称アミュおじ）、さよきちのnote（「陽気なおじさん」）、ポーカーアカデミーのテル解説

### 2. 教えたがりおじさん（アドバイス大好き）
| 項目 | 中身 |
|---|---|
| 見た目・小物 | 腕を組んで他人のハンドを見ている。降りたあとも卓を見ている |
| 話し方 | 「今のはね……」「レンジ的に」「エクスプロイトすると」と用語が多い。最後に「知らんけど」「多分」で逃げ道を作る |
| 打ち方 | 知識は多いが、実戦では自分の言うとおりに打てていないことがある |
| よくあるミス | 理屈で決めたことを、相手を見ずに打つ |
| テル | 自分の番で急に解説が止まる＝本気で迷っている |
| マナー | 悪気はない。ただし勝負中の口出しはルール違反（既存の「他人のハンドに口出し」「説教する」と重なる）。**頼まれたときだけ教える**ならいい人になる |

出典：さよきちのnote（「アドバイス大好きおじさん」）、知恵袋（「ハンドの批評をずっとしているお兄さん」で疲れた初心者の相談）、komeken のnote（用語の使い方と「知らんけど」）

### 3. リンプおじさん（リンパー）
| 項目 | 中身 |
|---|---|
| 見た目・小物 | 毎回、同じ額のチップを静かに前に出す |
| 話し方 | 「まあ、見るだけ見るよ」。口数は少なめ |
| 打ち方 | フロップ前はレイズせず、参加額だけ払って入る（リンプ）。どの席でも同じ手で入る |
| よくあるミス | ①小さいペアでリンプし、誰かがレイズすると**レイズし返す**（リンプからのレイズ＝強い手の合図）。②ポットとの比ではなく、**チップの絶対額**で判断する。③1回の結果で「レイズは損」「リンプは得」と覚え込んでいる |
| テル | フロップ以降の**チェックからのレイズ・先に賭けてくる**は、ほぼ手が入った合図。リバーの賭けはほぼ本物（ブラフはまれ） |
| マナー | 問題なし |

出典：booboomasa のブログ（ポーカーソウルのリンパー分析。アプリの話だが、ライブの同タイプにもよく当てはまると書かれている）

### 4. コールおじさん（なかなか降りない人）
| 項目 | 中身 |
|---|---|
| 見た目・小物 | 相手が賭けた瞬間に、もうチップに手が伸びている |
| 話し方 | 「見たいじゃん」「当たるかもしれないし」 |
| 打ち方 | 3〜4人で見る場面が多い。同じマークの2枚や、絵札が好き。Aだけ・弱いペアでも最後まで行く。ドローを追いすぎる |
| よくあるミス | 賭けの大きさに鈍い。大きく賭けても軽くついてくる。ただし**リバーで急に慎重になる**人もいる |
| テル | 相手の賭けの前にチップに手を伸ばす＝弱い（「賭けないで」という防御反応）。いつもより早いコール＝中くらいの手 |
| マナー | 問題なし。いちばん「お客さん」らしい人 |

出典：oKA のnote（アミューズメントポーカーあるある）、タイチのnote（レクの特徴）、ydpoker のnote（7つのテル）

### 5. 肩ぶん回しおじさん（攻めっぱなし）
| 項目 | 中身 |
|---|---|
| 見た目・小物 | チップの山が高い、または一気に減っている。どちらか |
| 話し方 | 「降りていいよ？」「当然レイズ」。相手を煽る |
| 打ち方 | 参加も3ベット（レイズし返し）も多い。Aと弱い札、Q-10 などでもレイズし返す。**相手を降ろすのが楽しい** |
| よくあるミス | 3ベットした後、さらにやり返されると降りられない。強い手で待たれると大きく払う |
| テル | 「コールして」「降りるの分かってる」と煽るのは、強い手のことが多い（ブラフは笑われたくないので静か） |
| マナー | 煽りが度を越すと既存の「勝ち誇る・煽る」になる |

出典：さよきちのnote（「肩ぶん回しおじさん」）、タイチのnote（3ベットが多いレク）、ydpoker のnote（ゴーディング）

### 6. 無限リエントリーおじさん
| 項目 | 中身 |
|---|---|
| 見た目・小物 | 大会のエントリー券を何枚も持っている |
| 話し方 | 「もう1回だけ」「次は本気出す」 |
| 打ち方 | 大会で早く飛んでは再参加を繰り返す。最初から全部のチップを買わない（フルスタックにしない）こともある |
| よくあるミス | 再参加できるので最初の勝負が雑になる。割に合わない大会でも気にしない |
| テル | 序盤のオールインは軽い。再参加の締め切りが過ぎると急に堅くなる |
| マナー | 問題なし。店にとってはありがたい客 |

出典：koko のnote（「無限リエントリーおじさん」）、進藤こだまのnote（リエントリーとフルスタック）、ねとらぼ（大会出場権の仕組み）

※ 主人公の口癖「あとワンハンドだけ」とよく似ている。主人公の“なりかけた姿”として使える。

### 7. 戦績アピールおじさん
| 項目 | 中身 |
|---|---|
| 見た目・小物 | SNSのアイコンが大会の写真。名前に記号。プロフィールに過去の入賞 |
| 話し方 | 「この前の○○で入賞してさ」。用語を多めに使う |
| 打ち方 | 大会に大量に出る。界隈で名前を売りたい |
| よくあるミス | 名前が売れるほど、まわりに打ち方を研究される |
| テル | 自分の評判を守りたいので、人前の大きな勝負では**ブラフを打ちにくい** |
| マナー | 問題なし。度が過ぎると周りが引く |

出典：723 のnote（ディーラー経験者。SNSのアイコン・固定ポスト・記号の名前）、イケガミコフのnote（入賞するとSNSに上げる人が多い、名を売るために大量参加する人もいる）

### 8. ディーラーに厳しいおじさん
| 項目 | 中身 |
|---|---|
| 見た目・小物 | ルールに詳しい。ディーラーの手元をよく見ている |
| 話し方 | 他の客には気さく。ディーラーのミス（ボタンの動かし忘れ、ストリングベットの見逃し）には**強い口調**で指摘する |
| 打ち方 | 堅め。手順にうるさい |
| よくあるミス | 指摘に気を取られて自分の判断が雑になる |
| テル | 自分が勝負しているときは指摘しない。黙っている＝手が入っている |
| マナー | 指摘自体は正しいことも多い。言い方の問題。既存の「ディーラーに八つ当たり」とは違い、**負けたからではなく正しさから**怒る |

出典：知恵袋（初心者が「少し怖かった」と書いた相談と、その回答「ディーラーに厳しい客は一定います」）

### 9. 堅いおじさん（ほとんど参加しない人）
| 項目 | 中身 |
|---|---|
| 見た目・小物 | 年配。コーヒーをゆっくり飲んでいる（海外では「OMC＝Old Man Coffee」と呼ぶ） |
| 話し方 | 少ない。「……降り」 |
| 打ち方 | 強い手しか参加しない。レイズよりコールやリンプを好む |
| よくあるミス | 強く賭けられると、まずまずの手でも降りる。大きな賭けが**ほぼ本物**なので読まれやすい |
| テル | 何十ハンドも降りていた人が急にレイズしたら、本物 |
| マナー | 良い。静か |

出典：PokerListings（OMC の用語解説。「年配の人が全員そうとは限らない、決めつけないこと」とも注意している）、DeucesCracked（ニットの攻め方）

### 10. バッドビート語りおじさん
| 項目 | 中身 |
|---|---|
| 見た目・小物 | 飛んだ直後に、知らない人にも話しかける |
| 話し方 | 「AAで入ったのに10-10に負けてさ」。何度も同じ話をする |
| 打ち方 | 結果で振り返る。「あれは運が悪かった」で終わる |
| よくあるミス | 1ハンドの結果で判断して、打ち方を直さない |
| テル | 語った直後のハンドは熱くなっている |
| マナー | 悪くはないが、聞く側は飽きている。一方で「ほかの打ち方はあったか」と振り返る話し方なら歓迎される |

出典：PokerNews（バッドビートの話はいつ許されるか）、booboomasa のブログ（1ハンドの結果で判断する）

### 11. 推し通いおじさん（ゲームには入れない方がよい）
- ディーラー目当てに通い、ドリンクをおごる客がいる、という話がディーラー経験者のnoteにある。プレゼントやしつこい連絡の話もある。
- **入れない理由**：恋愛・性的な方向に寄ると、年齢区分と印象が悪くなる。出すとしても「ディーラーにドリンクを1杯おごる気のいい常連」まで。

出典：723 のnote

## 2. アミューズメント店らしいミス（ゲームのCPUに足せるもの）

`相手の穴とエクスプロイト案.md` の穴の一覧にないものだけ挙げる。

| ミス | 中身 | 見せ方の例 |
|---|---|---|
| チップの絶対額で決める | 「20枚なら払える」と、ポットとの比を見ない | 大きいポットでも小さいポットでも、同じ額ならついてくる |
| リンプからのレイズし返し | 小さいペアでリンプ→誰かがレイズ→レイズし返す | リンプおじさんの見え見えの強い手 |
| 強い手ほど弱く見せる | 強い手でも小さく賭ける・チェックする | 小さい賭け＝罠 |
| ターンでオールイン | フロップは様子見、ターンで急に全部 | ターンのオールインは本物が多い |
| 再参加できるから雑 | 大会の序盤だけ軽い | 第6章（トーナメント）の序盤だけゆるい客 |
| 閉店間際に全額勝負 | 最後の数ハンドは誰でも入りたがる | 「ラストハンド」の演出と合わせる |

出典：booboomasa のブログ、oKA のnote、koko のnote、進藤こだまのnote

## 3. 店でよく見るテル（体以外のもの）

既存の `TELLS` は体のクセ中心なので、それ以外を挙げる。どれも「当たらないこともある」と出典自身が注意している。

| テル | 意味 |
|---|---|
| 相手の賭けの前にチップに手を伸ばす | 弱い。賭けさせたくない |
| 「ベット」と言ってから額を出すまでに間がある | 強い |
| 「ドローなだけだよ」など、自分を弱く言う | 強い |
| 煽る・急かす | 強い |
| コールしたあと手札を見直す | ドロー |
| 陽気な人が急に黙る | ブラフ |
| ふだん即決の人が長考する／その逆 | ふだんと違う＝何かある |

出典：ydpoker のnote、ポーカーアカデミーのテル解説、DeucesCracked

## 4. LAST TELL での使い方（提案）

1. **いまのキャラに「店の型」を重ねる**（おすすめ）。新キャラを増やさず、口ぐせと小物だけ足す。
   - ゲン（錨亭15年、楽天家）＝陽気な常連おじさん。ビールと「楽しんだもん勝ち」。
   - セキ（大勝負を降りてきた）＝堅いおじさん。コーヒー。
   - ゴウ（荒い・熱くなる）＝肩ぶん回し＋バッドビート語り。
   - ロク（「数えてから言え」）＝ディーラーに厳しい、ただし正しい人。
   - 主人公の「あとワンハンドだけ」＝無限リエントリーおじさんの入口。ジンが止める場面に使える。
2. **フリープレイのモブ客**として、名前のない「よく見る客」を数人用意する（教えたがり、リンプ、コール、戦績アピール）。見た目は「弱いほどかわいい」の方針に合わせ、強くないタイプはやわらかい絵にする。
3. **ジンの見立て**の言い回しに使う。「あの人はリンプからレイズしてきたら本物だ」など、店の型で一言で言う。
4. **入れないもの**：推し通い、ディーラーへの恋愛・性的な話、実在の店名・人名、年齢や見た目をからかう言い方。
