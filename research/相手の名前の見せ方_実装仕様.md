# 相手の名前の見せ方 実装仕様（案2＋案3、2026-10-10 satou 決定）

提案：research/相手の名前の見せ方_提案.md　見本：https://claude.ai/artifact/DmbkGrYyv6WqvbqAm5eHuh
データ：research/相手の名前の見せ方_データ.js（`LOOKNAME` 30人分、`INTRO_LINE` 30人分、日本語と英語）

## 1. 何が変わるか（遊ぶ人から見て）
- 相手の名札には、ふだんは**チップと行動だけ**が出る。名前と星（★）は卓の上から消える。
- 相手が**動いた時・声を出した時・名札をタップした時**だけ、名札の一番上に呼び名が約1.8秒出て消える。吹き出しにも小さく呼び名が付く。
- 呼び名は、**知っている相手なら名前、知らない相手なら見た目の呼び名**（「黄色いシャツ」など）。
- 知らない相手が知っている相手に変わる時、その人が名乗りのひと言を言い、呼び名が金色に光って名前に変わる。

## 2. 触る場所

- 新しいファイル：src/js/06b_names.js（`LOOKNAME`、`INTRO_LINE`、`knownName()`、`who()`）。order.json の 06_regulars.js の後ろに入れる

  - 「顔にかぶるチップ表示」の直し：名札の名前の行が消えるので、名札はむしろ低くなる。直しが先に入っていたら、その位置の決め方はそのまま使う。

## 3. 保存キー
- **新しいキーはなし。** 「知っている」かどうかは今ある保存から決める。
  - 店の常連（`MOBS`）：`mobH(name)>=10`（顔なじみ帳のページが開いた相手）
  - 入港した船の客（`SHIP`）：`loadMobAll().ship[name]>=2`（2日目から）
  - その場で名乗った相手：`S.introduced`（その回の卓だけのメモ。保存しない）
- 「セーブを消す」「引き継ぎコード」は今のキーのままで変更なし。

## 4. 作り方
### 4-1. 知っているかどうか
```js
function knownName(n){
  if(CFG.flashback)return true;                         // あの日の回想は、ジンの席から見ているので全員知っている
  if(S&&S.introduced&&S.introduced[n])return true;
  if(MOBS[n])return mobH(n)>=10;
  if(SHIP[n])return (+loadMobAll().ship[n]||0)>=2;
  return true;                                          // 物語の相手・CHARS・REAL の人は、名前で出す
}
// 卓で見せる呼び名。英語のときは LOOKNAME の en を使う
function who(n){return knownName(n)||!LOOKNAME[n]?n:(SETTINGS.lang==='en'?LOOKNAME[n].en:LOOKNAME[n].ja)}
```
- 物語の章の相手（ゲン、ロク、セキ、レイカ、ハヤト、クロウ、ジン、第二部の人たち）は、名乗りや会話で名前が出てから卓に着くので、いつも名前で出す。
- 同じ卓に同じ見た目の呼び名が2人いたら、後ろの席の人に席の番号を付ける（例「黒いスーツ（4番）」）。

### 4-2. 名札
- `pl.innerHTML` の `.nm` から星（`stars(rankOf(...))`）を外す。言語の札（`SHIP[p.name].lang`）は呼び名と一緒に出す。
- 呼び名を出す時間：`p.nmUntil`。次の時に `performance.now()+1800` を入れる。
  - `p.actSeq` が変わった時（動いた時）
  - `p.say` が新しくなった時（`sy.dataset.seq` が変わる所）
  - 名札をタップした時（今のタップ＝チップを数える動きと同じタップで、両方起きる）
- `now<p.nmUntil` の間だけ `.nm` に `who(p.name)` を入れる。それ以外は `.nm` を出さない。切れる時のために `setTimeout(render, 残り+30)` を1本だけ予約する（すでに予約があれば足さない）。
- 出る時は下から0.35秒でふわっと出す（見本の `.fl`）。見た目の呼び名は少し細く、灰色寄り（見本の `.lk`、`#cfc8b6`）。
- 自分の番の相手は今の `.plate.turn`（金の枠）のまま。顔のまわりに淡い光（`drop-shadow(0 0 6px rgba(226,182,91,.9))`）を足す。
- `pl.title` と `aria-label` は `who(p.name)`＋チップにする（読み上げでも本名が先に漏れないように）。
- 1対1の卓（`N()===2`：第1章、第4・5章の一騎打ち、第7章）も同じ作り。相手は物語の人なので名前で出る。

### 4-3. 吹き出し
- 吹き出しの頭に小さく呼び名を付ける（見本の `.say b`：.55rem、`#7b5d22`）。1対1の卓では付けない。
- タケルとハンナのメモ（（メモ）で始まる）も同じ。

### 4-4. 名乗り
- `mobCount()` で `a<10&&b>=10`（ページが開いた）になった相手が卓にいる時：その相手の次の発言の代わりに `INTRO_LINE[name]` を出し、`S.introduced[name]=true`、呼び名を金色に1回光らせる（見本の `.flip`）。
- 船の客：初めて会った日（`ship[name]===1`）の、同じ卓での3ハンド目の始めに `INTRO_LINE` を出し、`S.introduced[name]=true`。
- 名乗りは1人につき1回。第1〜3章の相手、物語の相手には出ない。

### 4-5. ほかに名前が出る所
- 卓の上の文字（`S.msg`、ディーラーのひと言、ハンドの結果の行）で相手の名前を出す所は `who(p.name)` にする。`grep -n "p.name" src/js/2*.js` で拾う。
- 顔なじみ帳・人物タブ・ノートは今のまま（10ハンドでページが開いた時点で、もう名前を知っている）。開く前のページは今どおり鍵のまま。
- 相手紹介の画面（`showVersus`、6人卓の相手紹介）：知らない相手は `who()` で出す。星はそのまま残してよい（卓の上だけ外す）。

## 5. 守ること
- 第1〜3章の難しさを変えない（見た目だけ。CPU の打ち方には触れない）／第7章のジンの本物のテルに触れない
- 「夜」を使わない（「あの日」）／セリフにお金の話を入れない
- 見た目の呼び名は服・持ち物・髪型だけ。肌の色・体つき・年齢では呼ばない
- ボタンや設定は増やさない

## 6. 「できた」の条件（自動検証に足せる形）
- 卓の名札（`#plates .plate .nm`）に、相手が動いていない間は文字が出ていない（フリー6人、自分の番で止めた画面で、直前1.8秒に動いていない相手の `.nm` が空か非表示）
- 卓の名札に `★` が1つも出ない
- `mobH(n)<10` の常連が卓にいる時、その人の名札・吹き出し・`S.msg` に本名が出ない（100ハンド）
- 名乗りのひと言は、1人につき1回だけ出る
- `LOOKNAME` と `INTRO_LINE` のキーが `MOBS`＋`SHIP` の30人と同じで、どれも `ja` と `en` がある
- 第1〜3章の勝率が今と同じ（qa/checks/winrate.js が通る）
- 新しい日本語の文字列（言語の札・名乗り以外の画面文字）が全部 EN_DICT にある
- 目で見る：スマホ縦（390x844）・横（844x390）・PC（1280x800）で、呼び名が出た時に名札が顔や吹き出しにかぶらず、はみ出さない（「金のネックレス」「青緑のスカーフ」「Red-rimmed specs」など長い呼び名で確認）
- 目で見る：常連が10ハンドに届いた時、名乗りのひと言が出て、呼び名が名前に変わる
