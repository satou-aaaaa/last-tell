# 相手の「穴」を見抜いて突く案（2026-10-09）

ライブポーカーでは、相手の**クセ（テル）**だけでなく、**打ち方の穴（戦略ミス）**を覚えて突くのが基本の勝ち方です。
例：「この人はリバーで大きく賭けられると必ず降りる」「この人は3ベットされると降りる」。
この案は、キャラごとにこの「穴」を持たせ、プレイヤーが気づいて突けるようにするものです。

- 操作は増やしません。ふだんのレイズ・コール・フォールドで突きます。
- 第1〜3章では穴を出しません（難しさは今のまま）。第7章のジン本人には穴を持たせません（本物のテルにも触れません）。
- 「相手が主人公のテルを見抜く」スレッドの案は **相手→主人公** の向き、この案は **主人公→相手** の向きです。中身（体のクセ・賭け方のクセの読み合い）は扱わず、**打ち方の判断ミス**だけを扱います。

---

## 1. いまの作り（shisho.html を読んだ結果）

| 項目 | いまの動き | 場所 |
|---|---|---|
| CPUの判断 | 勝率（モンテカルロ200〜300回）×人数で `rel` を出し、性格の数値で参加・レイズ・降りを決める | `cpuDecide()` 3513行付近 |
| 性格 | `STYLES` に12種類。数値は hi / mid / midP / bluff / margin / defPre / defPost / loose だけ | 2539行付近 |
| 性格の違い | 「全体にゆるい」「全体に降りやすい」「全体にブラフが多い」の**強弱だけ**。通り（フロップ／ターン／リバー）や場面ごとの違いはない | 同上 |
| 賭ける額 | 全員同じ。ポットの50〜90%をランダム | `cpuDecide()` |
| ドロー | 勝率に含まれるので、どのキャラも計算どおりに追う。追いすぎるキャラはいない | `equity()` |
| テル | `TELLS` で強い手／ブラフのときの体のクセ。答え合わせが「相手メモ」に自動で書かれる | 1597行付近、`noteTell()` |
| 相手メモ | テルの記録だけ。打ち方の記録はない | `renderNotes()` |
| ジンの見立て | 第5・6章とフリーなどで10ハンド目に1回。性格を1行で言う（例「セキはすぐ降りる」） | `jinView()`、`VIEW` |
| 状況での変化 | ハヤト・ゴウのティルト、見せた手の記憶、主人公のクセ読み（rank 4以上） | `mannerOf` / `S.shownMem` / `selfAdj()` |

**まとめ**：今の相手は「強弱の数値が違うだけ」なので、プレイヤーが覚えられるのは「ゆるい／かたい」まで。
実際のライブのような「**この場面だけ**おかしい」という穴がないため、見抜いて突く遊びが生まれません。

## 2. 実際のライブポーカーでよくある穴（調べた結果）

| 穴 | よくある理由 | 突き方 |
|---|---|---|
| リバーで大きく賭けられると降りすぎる | 最後に大金を失うのが怖い | リバーで大きくブラフ |
| リバーでブラフをほとんど打たない | 低いレートの客はブラフが少ない | リバーで大きく賭けられたら素直に降りる |
| ドローを追いすぎる | 「入れば勝てる」と額を見ない | ドローが見える場で大きく賭ける。ブラフはしない |
| 3ベットに弱い | 参加は広いが、やり返されると降りる | 相手の参加にレイズし返す |
| 1回だけ賭けてあきらめる | フロップで賭け、外れたらターンで止まる | フロップはコールし、ターンで賭ける |
| ペアがあれば降りない | 役ができると手放せない | 強い手のとき大きく賭け続ける |
| 負けた直後に取り返しに行く | 熱くなる（ティルト） | 次のハンドは強い手で待つ |
| チップが減ると縮こまる | 減った額が怖い | 短いあいだはブラインドを盗む |
| チェックされると必ず賭ける | 待てない | 強い手はチェックして相手に賭けさせる |

参考：Card Player の低レート客の弱点と突き方の記事、ライブ大会でよくある突き方の記事など（末尾の出典）。

## 3. 案（5つ）

### 案1　キャラごとに1つの「穴」（おすすめ）
各キャラに、性格と過去に合った穴を**1つだけ**持たせる。数値の強弱ではなく「この場面だけおかしい」動きにする。

- 気づき方（操作なし）
  1. **相手メモに「打ち方」欄を足し、見えた事実を自動で書く**。例「セキ：リバーで大きく賭けられて降りた（3回中3回）」「ゲン：大きい賭けにコールして、フラッシュを外していた」。
  2. ジンの見立て（10ハンド目）を、穴をぼかして言う形に変える。例「セキは最後に弱い」。答えは言わない。
- 突いた手ごたえ：穴が出た場面でプレイヤーがポットを取ると、2回目にジンが一言「……見つけたな。それが穴だ」。称号「穴を突く」。
- 第1〜3章は出さない。第4章以降、フリー、一夜、裏の卓で出す。

| キャラ | 穴 | 性格・過去とのつながり | 突き方 |
|---|---|---|---|
| ゲン | ドローを追いすぎる | 「入れば勝てる」の楽天家 | ドローが見える場で大きく賭ける |
| ハル | 3ベットに弱い | 慎重すぎてロクにあきれられている | ハルの参加にレイズし返す |
| ロク | 1回だけ賭けてあきらめる | 「守り」役。深追いしない | フロップはコール、ターンで賭ける |
| セキ | リバーで大きく賭けられると降りすぎる | 人生の大勝負を全部降りてきた | リバーで大きくブラフ |
| ミナ | チェックされると必ず賭ける | 待つのが苦手 | 強い手はチェックして賭けさせる |
| レイカ | ブラフはターンまで。リバーでは嘘をつかない | ディーラーの訓練。最後の1枚には誠実 | ターンは粘る、リバーの賭けには降りる |
| ソウ | リバーでブラフを打たない | 正直さそのもの | ソウのリバーの賭けには降りる |
| ハヤト | 「二代目」には引けない（主人公の賭けだけ降りにくい） | 主人公に一番腹を立てている | ブラフは打たず、薄い手でも価値の賭け |
| クロウ | 大きなポットになると、最後に降りられない | あの夜の「最後まで迷った」 | 強い手のとき大きくする。ブラフ厳禁 |
| ゴウ | 負けた直後のハンドは必ず参加 | 荒い。熱くなる | 次のハンドは強い手で待つ |
| カオル | 外れたら降りる（参加は広い） | 慎重 | フロップで小さく賭け続ける |
| テツ | ペアがあれば降りない | 何でも参加 | 強い手で大きく賭け続ける |
| ケンジ | 負けを取り返そうとする（大きく負けた次は荒い） | 焦りの裏返し | 強い手で待ち、コールを広げる |
| ミサキ | ほぼ穴なし。チップが増えると守りに入る | 3人で一番うまい | 勝っているミサキからは盗める |
| タロウ | チップが減ると縮こまる | 心配性 | 短いあいだはブラインドを盗む |
| ジン | 穴なし | 師匠 | ―（第7章は今のまま） |

**良い点**：一番ライブに近い。キャラの作りこみ（過去・性格）がそのまま打ち方に出る。覚えると次の来店で得をする（常連機能と相性がよい）。
**注意点**：第4〜7章が少しやさしくなる。rank 4以上の穴は条件を狭くして、自動対戦で勝率を確かめる。

### 案2　場面で開く穴
穴を固定せず、**場面で開く**ようにする。「大きく負けた直後」「チップが半分を切った」「20ハンドを過ぎて疲れた」「ブラフを見せられた直後」など。
今あるティルト（ハヤト・ゴウ）を全員に広げる形。
- 良い点：ライブの「流れ」が出る。毎回ちがう。
- 注意点：いつ開いたか分かりにくく、「見抜いた」手ごたえが弱い。合図が必要になり、テルと区別しにくい。

### 案3　穴を塞ぐ強い相手
案1に足す形。rank 4以上（セキ・レイカ・ハヤト・クロウ）は、**2回突かれると穴を塞ぐ**。クロウだけは、塞いだあと**わざと穴があるように見せて**罠にする（逆のクセと同じ考え方）。
- 良い点：強い相手との読み合いになる。ボスらしい。
- 注意点：単独では成り立たない（案1が先に必要）。罠は第6章の難しさを上げる。

### 案4　ジンの宿題「穴探し」
卓ごとにジンが謎かけを1つ出す。例「この卓に、最後に必ず降りる奴がいる」。
穴を2回突くと宿題クリア（3つ星チャレンジの1つにする。見た目だけの報酬）。フリー対戦では、来店のたびに穴が入れかわる。
- 良い点：目的がはっきりして、初めての人でも遊び方がわかる。
- 注意点：答えを半分教えるので、自分で見抜く楽しさが減る。ゲームっぽさが強い。

### 案5　賭け額の穴
キャラごとに「賭ける額と手の強さ」をつなげる。例：ゲンは強いと大きく、ミサキは弱いと小さく（様子見の小さい賭け）。
今は全員がポットの50〜90%をランダムに賭けているので、ここを変える。
- 良い点：実際のライブで一番よく使われる読み。チップの山を見るだけで気づける。
- 注意点：体のクセ（テル）や「主人公のクセを読む」スレッドの賭け額の話と見分けにくい。

---

## 4. おすすめ：案1

理由
- 「この人はこの場面でおかしい」を覚えて突くのが、ライブで実際に行われているエクスプロイトそのもの。
- キャラ作りこみで決めた過去（セキ＝全部降りてきた、ハル＝慎重すぎ、ハヤト＝二代目に腹を立てている）が、そのまま打ち方になる。
- 操作が増えない。相手メモとジンの見立てという、今ある場所で気づける。
- 案3（穴を塞ぐ）と案4（宿題）は、あとから上に足せる。

## 5. 案1の作り方の目安（決まったら実装仕様に書き直す）

- `LEAKS={ 'セキ':{k:'riverFold'}, 'ゲン':{k:'chase'}, … }` を追加。
- `leakOn(p)`：`LEAKS[p.name]` があり、かつ（第4章以降 または フリー・一夜・裏の卓）。`CFG.ch.no<=3` では必ず false。第7章のジンは対象外。
- `cpuDecide()` の頭で、穴ごとに**場面を判定して上書き**する。例
  - `riverFold`：リバーで `toCall>=pot*0.6` かつ `rel<1.7` なら降りる。
  - `chase`：フロップ・ターンでドロー（4枚フラッシュ／オープンエンド）があれば、ポットの額までコール。
  - `fold3b`：プリフロップで自分がレイズ済み、さらにレイズされたら `rel<2.0` で降りる。
  - `oneShot`：フロップで賭けてコールされたら、ターンは `rel<hi` でチェック・降り。
  - `heroCall`（ハヤト）：主人公の賭けにだけ margin を −0.08。
- 穴で決めた行動は `p.leakHit={k,street}` を残す。見える場面（降りた・ショーダウン）で `shisho-leaks`（localStorage、`v:1`）に回数を記録し、`renderNotes()` に「打ち方」欄として出す。
- プレイヤーがそのハンドを取ったら `S.leakWin[name]++`。2回目でジンの一言と称号「穴を突く」。英語辞書にも追加。
- `VIEW` に穴をぼかした一言を足す（例 `riverFold:'{n}は最後に弱い'`）。
- 確認：第1〜3章は変化なしを自動対戦で確認。第4〜7章・フリーで勝率の変化を見て、穴の強さを調整。UI確認（縦・横・PC）で相手メモの「打ち方」欄がはみ出さないこと。

## 6. 「アミューズメント店でよく見る客のタイプ調査.md」との照合（2026-10-09）

- ずれはありません。セキ＝堅いおじさん（強く賭けられると降りる、大きな賭けはほぼ本物）は案1の「リバーで降りすぎる」と同じ向き。ゲン＝陽気な常連、ゴウ＝攻めっぱなし・熱くなる、も案1の穴と合っています。
- 仕様を書くときに足せる候補（その調査の §2）：「チップの絶対額で決める」（ゲン・テツの追いすぎの理由づけ）、「ターンでオールイン＝本物」（ロクの1回だけ賭けると対にできる）、「閉店間際に全額勝負」（一夜・フリーの終盤）。
