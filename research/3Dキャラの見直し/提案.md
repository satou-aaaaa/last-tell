# 3D キャラを役に合う見た目に直す（2026-10-28）

satou さん「ゲンが若いので、おじさんに」「3D モデルもゲームにふさわしいように」。

## 見方
- 役の年齢・性別・強さは game/data/REAL.json（age 0=10〜30代 / 1=40〜50代 / 2=60代以上、rank 1 弱い〜5 強い）と PROFILE.json、物語の9人_計画.md。
- 決まり：強い人ほどかっこよく、弱い人ほど親しみやすく。全員日本人。

## 作り方
satou さんの PC の UE で Python だけで作り直す（1 人 30〜40 分、元の人は残す）→ release に上げる → Godot に焼き込む。髪の色だけの人は Godot の char3d.json で直す。
服（スーツ・手袋など）は別の PR #54 で着せ分ける。

## 再発防止
- 3D の人ごとに「作った見た目の年齢・性別」を char3d.json の look に書き、REAL.json の役の年齢と合わないと qa が ❌（tools/cast_look.py）。
- 新しい人を作る前に、役の年齢・強さを config に書いてから作る（chars/3d/README）。
