## 4. 作り方

### 案1 卓から数字を減らす
1. **賭けの数字**: 相手の前と自分の前の `chipStack(p.bet)` を `chipStack(p.bet,false)` にする（`.amt-label` を出さない）。ボタンの「コール 2,000」と、レイズの枠の数字は残す。
2. **名札の行動の札**: `tag` は「フォールド」「オールイン」だけ残し（状態なので）、ほかの `p.lastAct` は出さない。代わりに、行動した瞬間に名札を 0.7秒光らせる（今の `pl.classList.add('flash')` を `!p.say.talk` のときだけでなく、行動ごとに）。チェックはチェック仕様の叩く動きに任せる。
3. **考え中…**: `tag think` を出さない。`bust.think` の動き（姿勢）は残す。
4. **番です**: `$('waiting')` は空にする。相手が12秒以上考えたとき（遅い `wait` は今は最大 0.65+0.6+0.7+1.6 秒×速さなので、ふつうは出ない。読み・ディーラーのミス・クイズの待ちで長くなったときだけ）ディーラーが「{who}さん」。自分の番は 8秒何もしなければ1回「お客様です」。
5. **ポット**: `approxOn()` のとき、`.pv` を `'約'+approx(total)` にし、`.ps`（卓＋賭けの内訳）は出さない。`potSign` をタップ（`role=button`、`aria-label="ポットを数えてもらう"`）すると、`dealerCount` と同じく 600ms×速さのあと `dealerSay('ポットは{n}です')`、そのハンドの間は正確な数字にする（`S.potCounted=S.potPile.target`。額が変わったら「約」に戻す）。`approxOn()` が偽（第1〜3章、設定「正確」）は今のまま。
6. **上の行**: `#meta` はブラインドだけ（「1,000/2,000」）。ハンド番号は消す。大会は「次の上昇まで◯ハンド」を「レベル◯」に変える。`#street` は空にし、要素は残す（カメラの位置合わせに使っているため `camTopPad` は高さ0でも動くことを確かめる）。勝利・敗北の表示（`S.result`）は残す。
7. **勝った額**: `tag win` を「勝ち」だけにする（額なし）。`S.msg` の「（+◯）」と「（役・+◯）」を外し、`S.msg` は称号や「ブラフを見抜いた！」など物語の文だけにする。章の目標（ブラインドを盗んだ！ など）は文を残し、額だけ外す。
   - ハンドの記録（ログ）は今のまま額を書く（引き出しの中なので）。

### 案2 ディーラーが進める
1. **シャッフル**: `startHand()` の最初に 0.6秒×速さ の「合間」を入れる。この間にカードを集める動き（場札・手札がディーラー位置＝卓の上の縁の中央へ滑って消える）、`Sound.sfx('shuffle')`（新しい音。短い雑音を14回、35ms おき。見本の `shuffle` と同じ）、ボタン（`dbadge`）が次の席へ滑る（`placeDealer` に transition .5s）。
2. **ブラインド**: SB・BB の前にチップが置かれる動きを、ボタンのあとに 0.15秒ずつ。`blinds` の声は第1章の最初のハンドと、席が変わった最初のハンドだけ。
3. **配る**: 手札を SB から時計回りに1枚ずつ2周、1枚 0.07秒（6人で 0.84秒）、「速い」は 0.035秒。カードはディーラー位置から席へ滑る。CSS の `.card` に `--deal-delay` を付け、`render()` で `S.dealSeq` が変わったハンドだけ付ける。音は1枚ごとに `sfx('card')` を小さく。
   - 自分の手札の「めくって見る」は、2枚目が届いてから押せる。
4. **場札の枠**: `.card.slot` を透明・影なしにする（要素は残す。位置合わせに使っている）。
5. **バーンとフロップ**: `nextStreet()` で、まず伏せたカードを1枚、場札の右（ディーラー寄り）へ置く（`#burn`、ハンドが終わるまで残す、重ねる）。フロップは伏せた3枚を左端に置き、0.35秒後に3枚同時にめくり、0.25秒で広げる。ターン・リバーは伏せて置いてから 0.25秒でめくる。オールイン後の「ため」（`S.tease`）はこの伏せた札を使う。
6. **reducedMotion**: 1〜5の動きはすべて省き、今と同じ見た目で今と同じ速さ。
7. **時間**: 1ハンドで増える時間は、ふつうで約1.6秒、速いで約0.8秒まで。超えないように合計を測る（qa の perf に足す）。
8. **公開後**: 卓の奥の縁からディーラーの手を出す（配る・ポットを押す・賭けを集める）。キャラ絵と同じ作り方で手だけ描く。

### 案3 テレビ中継の演出を外す
1. **勝率**: `eqBadge` は `SETTINGS.tv` のときだけ。`calcEq()` は今まで通り計算する（プロ目線 A5「ターンの時点で約80%だった」と記録で使う）。
2. **反応**: オールインで手が開いたあと（`S.runout` が真になった直後）、残っている相手のうち1人に `RUNOUT_REACT` から1つ（rank>=3 は「……」だけ）。選び方は勝っているか負けているかに関係なく、`Math.random()` で同じ候補から。隣の卓の声 `RUNOUT_RAIL` は nextv の react 枠で（第7章は出さない、今と同じ）。
3. **英語の帯**: `camBand()` は `SETTINGS.tv` のときだけ。カメラの寄りはそのまま。
4. **カットイン**: `afterAct` の `cutIn`（ボスのオールイン）は、章ごとに1回だけ（`S.cutDone`）。フリー対戦では出さない（`SETTINGS.tv` なら今のまま）。第7章「最後のクセ」（10_scripted.js）と第二部の師匠のカットイン（29_part2.js）は変えない。
5. **役の札**: 名札の `.handname` と場札の上の大きな役の帯は `SETTINGS.tv` のときだけ。代わりに、`showdown()` の終わりで `dealerSay(dealerRead(勝った人の score))`（2回めくりのときは1回目の勝った手だけ。分けたときは「チョップです」）。
   - 負けた手（勝った人以外の `cont`、自分は今の `SETTINGS.muck` の決まりに従う）は、読み上げの 0.8秒後にディーラー位置へ伏せて滑らせる。フォールドの仕様で作る「伏せて流す」動きがあれば同じものを使う。
6. **自分の役**: `.myhand` は第1〜3章（`CFG.ch&&CFG.ch.no<=3`）と `SETTINGS.tv` のときだけ。
7. **音**: `turnCue` の `sfx('turn')` と振動を消す（設定の説明「自分の番に短く振動します」も消す）。`sfx('win')` → チップが滑る音（`click` を 4回、40ms おきに少しずつ低く）。`Sound.heart()` は呼ぶところ（オールインのため、クロック）を消し、`hush(true)` のチップをいじる音だけにする。結果の短い曲（`resultSting`）は章の勝ち負けの音楽なので残す。
8. **設定**: 「くわしい設定」に「テレビ風の表示：オン／オフ」（既定オフ）。

### 案4 時間と流れ
1. `Clock` を「クロック」に置きかえる。始まり方は今と同じ（`bigSpotForMe()` のとき、`SETTINGS.clock`）が、最初はバーを出さない。
2. 25秒たつと、そのハンドで降りている相手（`p.folded&&!p.out&&!p.human`）から1人が `CLOCK_CALL` を言う。いなければフロアの黒田の声だけ。0.8秒後にディーラー位置に「フロアです。1分でお願いします」。
3. 1分の残りが10秒になったら `dealerSay('10秒')`、5秒で「5、4、3……」、0で「時間です」→ 今と同じくフォールド（払う額があるとき）かチェック扱い。残り10秒のときだけ、ボタンの上に細い線（今の `#clock` を高さ3px、文字なし）を出す。
4. 第1〜3章は今と同じ: クロックは呼ばれず、45秒でジンが「時間だ。そろそろ決めろ」と言うだけ。
5. 裏ストーリーの `uraLv()>=3`（今は10秒）は「クロックがすぐ呼ばれる」にする: 5秒で呼ばれ、20秒。
6. 心音と振動はなし。
7. **先に選ぶ**: `preAllowed` に `SETTINGS.pre` を足す（既定 false）。設定に「先に選ぶ（オンライン式）」。今オンにしている人も、この版で一度オフに戻る（説明の文に理由を書く）。

## 5. 守ること
- 第1〜3章の難しさを変えない。CPU の判断・考える時間（`wait`）・テルには触らない。第1〜3章はポットの正確な数字と自分の役の表示を残す。
- 第7章のジンの本物のテル（顎の傷、`release`）、カットイン「最後のクセ」、第二部の師匠のカットインはそのまま。第7章では隣の卓の声を出さない。
- **テルにならないように**: 配る・シャッフル・ブラインド・バーン・めくる動きは、手の強さに関係なく全員いつも同じ速さと順番。オールインの反応は手が開いたあとだけ、強さで候補を変えない。クロックを呼ぶのはそのハンドにいない人だけ。
- 「夜」を使わない。台詞にお金の話を入れない（ディーラーの「ポットは◯です」は数を言うだけで、会話ではない）。
- reducedMotion のときは動きを省き、文字と声は同じ。
- 英語版: データ.js の en を EN_DICT に入れる。`dealerRead` は `SETTINGS.lang` で切りかえる（訳す側に任せない。数の並びが変わるため）。

## 6. 「できた」の条件（自動検証に足せる形）
- フリー6人で1ハンド: 卓の中（`#table`）に `.amt-label` が0個。名札に「コール」「レイズ」「ベット」「考え中」の文字が0回。
- 第4章以降とフリー（設定「だいたい」）: ポットの表示が「約」で始まる。タップ後に正確な数字になり、`dealerSay` が1回。第1〜3章は「約」が0回。
- `#meta` に「ハンド #」が0回。`#waiting` の文字が空。
- `SETTINGS.tv=false` で 200 ハンド: `.eqb`・`.handname`・`#camBand`（表示）が0回。ショーダウンごとに `dealerSay` の読み上げが1回。
- 自分の役 `.myhand`: 第1〜3章では出る、第4章以降は出ない（tv=false）。
- `sfx('turn')`・`sfx('win')`・`heart()` が対戦中に0回（設定で音をすべてにして数える）。
- クロック: 第4章で自分の番に何もしないと、25秒で `CLOCK_CALL` が1回、85秒で自動のフォールドかチェック。第1〜3章ではクロックの台詞が0回。
- 「先に選ぶ」の行（`#prerow`）が、既定の設定で一度も表示されない。
- 配る順: 手札の配る順が SB から時計回り（`--deal-delay` が SB の1枚目で最小）。1ハンドの増えた時間がふつうで 1.6秒以下。
- テルにならない: 1000ハンドで、配る・めくる動きの時間が手の強さ（`bestN` の役）で変わらない（全部同じ値）。オールインの反応の出る割合が、勝っている側と負けている側で同じ（±5%）。
- 第1〜3章の勝率が qa の基準どおり（winrate）。画面チェック（ui・uiux）でスマホ縦・横・PC に重なり・はみ出しがない（バーンの札と場札、ポットの「約」と名札）。
