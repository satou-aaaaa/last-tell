## S1. 最初の判断まで「6タップ以内」にする（第1章のみ）

今: 扉＋会話14画面 → 名乗り札（ゲン）→ VS → 「勝負開始」→ 案内5ページ → 最初の判断（約22タップ）。
目標: 「はじめる」から最初のフォールド／コール判断まで **6タップ以内・60秒以内**。

### 1-1. 第1章の intro を短くする
`CHAPTERS[0].intro` を次の5つだけにする。

```js
intro:[
 {door:1},
 ['','雨の夜。港のはずれにあるバー「錨亭」。'],
 ['ゲン','おう新入り、もう一勝負だ！配られた札は全部勝負、それがポーカーってもんよ！'],
 ['老人','……お前、負け方が下手だな'],
 ['老人','ゲンは何にでも参加する。だから、お前は強い手のときだけ戦えばいい。それだけで勝てる'],
],
```

### 1-2. 残りの行は「ハンドの合間」に出す（新しい仕組み `beats`）
章に `beats` を足す。`beats` は「n ハンド目が終わって、次のハンドを配る前」に1回だけ流す場面です。

```js
beats:[
 {after:1,lines:[
   ['','仕事帰りに覚えたポーカー。今日も、まるで勝てずにいる。'],   // 主人公アオ仕様の差し替え2行が入るならそちらに置き換え
   ['','老人は軽く握った指の背で顎の古い傷をなでながら、こちらの手札をのぞきこんだ。',{mark:…今の mark をそのまま…}],
   // 主人公アオ仕様の「指が、手元のチップの枚数を数えていた。」「……数えるな。顔を見ろ」はここ
   ['ジン','ジンでいい。昔、少しだけカードをやっていた'],
   // 主人公の名前仕様の「名乗る」3行（askName）はここ
   ['店主','ジンさんが人に口を出すなんて、何年ぶりだろうね'],
 ]},
 {after:2,lines:[
   {lesson:'ハンドの選び方',body:…今の body をそのまま…},
   ['ジン','いいか。降りるのも勝負のうちだ'],
 ]},
 {after:3,lines:[
   ['','カウンターの奥の壁には、写真が何枚も貼ってある。一枚だけ、裏返しのままだ。'],
   ['',"写真の上に、店の名前が削られた古い看板が一枚かかっている。錨亭のものではないらしい。"],
   ['ジン','それと、ゲンは顔に出る。いい手が来ると、すぐにニヤける'],
 ]},
],
```

- 呼び出し場所: `$('btnNext').onclick` の最後の `else startHand();` の手前で、
  `const bt=pendingBeat(); if(bt) return playScene(CFG.ch,bt.lines,()=>{show('game');Sound.bgm(CFG.bgm||0);render();startHand()});`
- `pendingBeat()`: `CFG.ch&&CFG.ch.beats&&CFG.beatsOn` のとき、`after===S.handNo` で、まだ流していない beat を返す（`S.beatDone[after]=1`）。
- `CFG.beatsOn` は `startChapter(ch, skipIntro)` で `!skipIntro` のときだけ true（負けてやり直しのときは流さない。章選択から最初から始めたときは流す）。
- **章が beat を流す前に終わったとき**（1〜3ハンド目で勝ち／負け）: 勝ちなら残りの beat の行を outro の先頭に足して流す（名乗りの場面を飛ばさないため）。負けならやり直しの前に流さない（やり直しは skipIntro なので beats も出ない）。名乗りは「章選択から第1章を始め直したとき」に出る。
- 主人公の名前・アオ・見た目の各仕様で「第1章 intro に足す」となっている行は、すべて上の `after:1` の beat に入れる（見た目の仕様は outro なので変更なし）。
- 第1章の難しさは変わらない（相手・持ち点・ブラインドは同じ。会話の位置だけ変わる）。星の課題「10ハンド以内にクリア」はハンド数で数えるので影響なし。

### 1-3. 名乗り札・VS を初回の第1章だけ1画面にまとめる
- 第1章で初めて遊ぶとき（`!loadCleared()`）は、`showNanori('ゲン')` を出さず、VS 画面だけにする（VS にも名前と肩書きが出ているため）。2回目以降・他の章は今のまま。

### 1-4. 第2章以降
- 今の intro の数: 第2章10、第3章9、第4章8、第5章14、第6章19、第7章14。
- 第6章（19）と第5章（14）は、同じ形で「最初のハンドの前は5行以内、残りは after:1〜3 の beats」に分ける。どの行をどこへ置くかは物語の担当スレッドで決める（話の順番が崩れないところで切る）。第7章は最後の勝負の空気を優先して今のまま。

## S2. 操作の案内を「その場で1行ずつ」にする

今: 初めて自分の番が来たら `startTour()`（5ページ）。吹き出しが画面上部に出て相手の顔を隠す。

変更:
1. 初回の自動 `startTour()` をやめる（4665行の `!tourDone()` で始める部分）。「？ 遊び方 → 卓の上で案内を見る」からはこれまでどおり見られる。
2. 代わりに「初めてその場面になったとき」だけ、操作ボタンの**すぐ上**に1行の案内を出す（3秒か、何か押したら消える）。保存先は今の `shisho-guide` に `{tips:{hold:1,act:1,…}}` を足す。

| キー | 出すとき | 文 |
|---|---|---|
| hold | 初めて手札が配られたとき（めくる設定がオンのとき） | 伏せた2枚をタップすると、自分にだけ見えます |
| act | 初めて自分の番が来たとき | 降りるか、同じ額を払って続けるかを選びます |
| raise | 初めて「レイズ」を押したとき | 額を選んで、もう一度押すと決まります |
| board | 初めてフロップが開いたとき | 真ん中の3枚は全員が使えるカードです |
| pot | 初めてポットを取ったとき | 賭けられたチップは、勝った人のものになります |

- 案内は相手の名札・顔・自分の手札に重ねない。位置は `#controls` の上端に合わせる（横向きは右下）。
- 第1章の「ジンの助言」と同じ瞬間に出るときは、案内を先に1.5秒出してからジンの助言を出す（同時に2つ出さない）。

## S3. 途中から再開できるようにする（「続きから」）

今: 章の途中で再読み込みするとタイトルに戻る。スマホでは裏に回すだけで消えることがある。

1. **保存のタイミング**: 各ハンドが終わって `S.handOver=true` になった時点（勝敗が決まっていないとき）と、`visibilitychange` で hidden になったときに保存する。
2. **保存先**: 新しいキー `shisho-resume`（`SAVE_KEYS` に追加。引き継ぎコード・ファイル保存にも入る）。
   中身: `{v:1, at:日時, kind:'ch'|'store'|'free'|'p2', ch:章番号, cfg:{必要な CFG の値}, S:{handNo, dealer, players:[{name,chips,start,out,tilt…}], stat, shownMem, beatDone, 星の課題に要る値(myAllin など), 章の台本の進み(finalNext, finalRead, tempted など)}}`
   - 山札・手札・場のカードは保存しない（**ハンドの途中で落ちたら、そのハンドは無かったことにして、そのハンドの開始時のチップから配り直す**）。そのため「ハンド開始時」にも1回保存しておく（チップは開始時の値）。
   - ハンドの途中でアプリを閉じて負けを消す使い方ができるが、1人用なので許容する（星の課題にも影響は小さい）。
3. **タイトル**: `shisho-resume` があるとき、「ストーリー」ボタンの位置に **「続きから（第○章・○ハンド目）」** を出す（赤い主ボタン）。その下に小さく「最初から選ぶ」（章選択へ）。
4. **再開**: `startGame` に `resume` を渡し、`buildSeats` のあと保存したチップ・状態を戻して、VS 画面を出さずに `startHand()`。intro・名乗り・噂話は流さない。BGM と照明は戻す。
5. **消すとき**: 章の勝ち／負けが決まったとき、「やめる」で確認して抜けたとき、別の章を始めたとき。
6. 第6章（トーナメント）はブラインドのレベル（`CFG.blinds`）も戻す。第7章は `S.finalHand/finalNext/finalRead` を戻す。第二部（p2）・裏の卓・はしごも同じ形で保存する。難しければ最初は第一部の本編とフリー対戦だけでよい（その場合、ほかは今までどおり）。

確認: 各章で 1ハンド後／ハンドの途中／ショーダウン中に再読み込み → 「続きから」で同じチップ・同じハンド数から再開できること。勝ち負けが決まったあとは「続きから」が消えること。

## A2. タイトル画面を3つのボタンにする

今のタイトルには、注意書き・ボタン6つ・フリー対戦の設定3つ・呼び名の入力が並んでいる。

1. ボタンは **「ストーリー（または 続きから）」「フリー対戦」「その他」** の3つ。
   - 「遊び方・役の一覧」は「その他」の一番上へ（対戦中は今どおり「？」から開ける）。

4. **注意書き**（`#firstNotice`）は初回だけ出す今の仕組みのまま、位置をボタンの下に移し、文字を一段小さくする。最初に目に入るのはロゴとボタンにする。「その他」の下の注意書き（`mfoot`）はそのまま。

## A5. テルを読めた瞬間を一番気持ちよくする

核の体験なので、演出をここに集める（新しいボタンは足さない）。
1. 読みが当たった瞬間（`mieta()` が出るとき）に、
   - 0.3秒だけ周りを暗くし、相手の顔と出ていたクセの吹き出しだけ明るく残す（`prefers-reduced-motion` のときはなし）。
   - 短い効果音を1つ（音楽仕様の音と同じ鍵盤の音で、低い1音）。
   - スマホは `navigator.vibrate(15)`（設定で振動オフなら出さない）。
2. 同じハンドでジンの助言が出るときは、ジンの一言を「見えた」の後に回す（同時に出さない）。
3. 第4章で初めて当たったときだけ、ジンの一言「……見えたな」を出す（第7章の本物のテルの演出には触れない）。

## 確認の手順（まとめ）

1. 新しいセーブで「ストーリー → はじめる」から最初の判断まで: 6タップ以内。
2. 第1章で、beats の3つが 1・2・3 ハンド目のあとに1回ずつ出る。1ハンド目で勝ったときは outro の前に残りが流れる。

4. 「続きから」: 上の S3 の確認。
5. 1行の案内（S2）が相手の顔・手札・ボタンに重ならない（4つの画面サイズ）。
6. 第1〜3章の autoplay の勝率が変更前と同じ範囲（難しさが変わっていない）。
