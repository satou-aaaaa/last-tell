## しくみ
- `game/scenes/table/props3d/prop_layer.gd`（PropLayer）：SubViewport（1600×900、透明背景、MSAA 4x）の 3D 層。
  TableView._build_world で cards_layer と fx_layer の間に置く。chips_layer・cards_layer・fx_layer の子の Card / ChipStack を毎フレーム読み、同じ場所に 3D の影武者を置く。
  - 画面の点 → カメラの線と y=0 の面の交点。大きさは卓の真ん中（場札の列）で 2D と同じになる倍率を一つ決め、手前・奥の差は本物の遠近に任せる（2026-10-23 satou「遠近感が気になる」で直した。前は場所ごとに 2D に合わせていて、奥ほど大きく作っていた）。
  - 札はどれも同じ本物の大きさ（2D の scale 0.6 未満は 0.6 とみなす）。チップは 2D の 1.15 倍（本物は直径が札の幅の 0.68 倍）。手前のチップは遠近で大きくなりすぎないよう、真ん中の大きさまで。
  - めくり：2D の scale.x/scale.y の比から長い辺まわりの角度を出す（table.gd の flip は変えない）。lift → 高さ。modulate.a → transparency。
  - チップ：額は 2D と同じ合計で、1,000 につき 1 枚（最大 32 枚）に崩す。柱は 16 枚まで、横に 2 本まで（多い分は奥の列。自分の山は 1 本ずつ奥へ）。賭け（meta "bet"）は崩さず額の大きいチップで少なく。ポット（meta "pile"）は寄せた山。
  - 影：やわらかい影の板（カード・チップの下）。
- `prop_tex.gd`（PropTex）：札 52 枚・裏・チップ 4 種（上面・側面）の絵を起動時にコードで描く（外の素材なし）。描く座標 512×800、実寸 ×0.625。4色設定が変わると表だけ描き直す。
- `prop_mesh.gd`（PropMesh）：本物の大きさ。カード 57×89×0.3mm（ブリッジ）、チップ 39×3.3mm。
- 2D 側：card.gd・chips.gd の _draw は `PropLayer.draws_2d(self)` が false なら描かない（Card の光る縁だけ 2D で下に出す）。Card ノードの位置・visible・modulate は今まで通り（check_table_layout.gd はこれで測る）。
- 画面の無い動かし方（--headless）と設定オフでは、前の 2D の絵のまま。
- 設定「立体のカードとチップ」（props3d、はじめオン）。

## 光
SpotLight3D（上から、#ffe0b0、0.85）＋ DirectionalLight（#a8b8d8、0.12）、環境光 #4a4236 0.32、トーンマップ linear。3D の人の光が決まったら合わせる。

## 検査（再発防止）
`tests/check_props.gd`（xvfb、qa.sh「立体のカードとチップ」）：
1. 3D の影武者が 2D と同じ場所（4px まで）
2. 角の数字が 1280×720 で 12px 以上（15px 未満は ⚠）。今は 15.8px
3. 表の札の真ん中が紙の色
4. チップの山が見える
5. めくりの途中で札が消えない
6. 遠近：同じ額の山・同じ札は奥ほど小さく見える（前のコードで NG になるのを確かめた）
引数に出力フォルダを渡すと 3d/flat/off の比べ写真を撮る。

`tests/check_table_layout.gd -- ch4,free6 40 3d`（xvfb、qa.sh「卓の重なり（3D のカードとチップ）」）：3D を出して、札とチップの 3D の箱（PropLayer.screen_rect）で字との重なり・チップと表の札の重なりを測る。2D の箱でも重なるもの（画面なしの検査の受け持ち）は数えない。
