## いまの問題（v40 時点のコード）

1. **大きいポットほど山が小さく見える。** `chipStack()` は額の大きいチップから積む。そのため 40,000 は黒4枚、150,000 は紫と金の2枚になる。
2. **山が脇にある。** `.potchips` は大きな `#potSign` の左に置かれているので、目に入るのは金額札のほう。
3. **集める動きが着地しない。** `gatherBets()` のチップは、飛びながら opacity .3 まで薄くなって消える。
4. **配当があっさりしている。** `potFly()` は小さな山を1つ飛ばして薄くするだけ。

## 案Eの見せ方

- 賭けたチップを輪（`.potzone`）の中へ**無造作に**置く。1〜4枚の低い山と、1枚だけのチップが混ざって散らばる。
- ストリートが進んでも、**前のチップは消さずに残す**。新しいチップは、その上や横に足していく。
- チップの枚数は「ポットがビッグブラインド何回分か」で決める。ポットが大きいほど、山は広く厚くなる。
- 金額札は細い1行の札にして、輪の下へ置く。山を隠さないようにする。
- 配当では、山全体を少し引いてから、勝った人の席へまとめて押し出す。

## 実装

### 1. 山の状態（手ごとにリセット）

`S.potPile = {chips:0, seed:<handNo から作る>}` を持たせる。山の DOM は `#potChips` の子要素として、手が終わるまで残す。

- 新しいハンドを始めるとき（`startHand`）：`#potChips` を空にして、`S.potPile` を作り直す。
- `render()` の中で `potChips.innerHTML=chipStack(...)` で山を作り直している処理はやめる。代わりに `potGrow(pot)` を呼ぶ（差分だけ足す）。
- `paid` のときは、`potPush()`（配当の演出）が終わってから山を空にする。

### 2. `potGrow(pot)`：足りない分だけチップを足す

見本の `messGrow` をそのまま移植してよい。

```js
const want = pot ? Math.min(60, Math.round(5.5*Math.log2(pot/BB()+1))) : 0;
// 色の混ぜ方：pot/BB < 8 → c1,c1,c2,c3 ／ < 30 → c1,c3,c4,c2,c4 ／ それ以上 → c4,c5,c3,c4,c6,c1,c4
// 1回に足す山の高さ：1〜2枚（小さいポット）、1〜4枚（それ以外）
// 置く場所：楕円の中のランダムな点。広がり spread = min(1, .45 + (pot/BB)/60)
// z-index は y 座標から決める（手前ほど上に重なる）
// 1枚だけの山のうち 35% は rotate(±15deg) で少し傾ける
```

- 乱数には `Math.random` ではなく、ハンド番号から作るシードの乱数を使う。こうすると再描画しても形が変わらず、同じ形がくり返されることもない。
- 新しく足したチップは、上から 10px 落ちてきて小さく弾む（260ms、1枚ごとに 25ms ずらす）。`prefers-reduced-motion` のときは動かさずに置く。
- 山の箱の大きさは、PC で 190×78px くらい。スマホでは `.felt .chip` が 34px 幅なので、スマホでは箱を 1.3 倍にするか、山の中だけチップを 26px に戻す。卓の上で山が他の物にかぶらないか、390px 幅で確かめる。

### 3. 金額札

- `.potsign` は輪の下に置く細い1行の札にする（「ポット　150,000」）。見本の `.sign.slim` を参照。
- 「卓 ○○＋賭け ○○」の小さい行は残してよい。その場合は札の右側に置く。
- 金額が増えるときは、520ms で数字を数え上げる（ease-out）。

### 4. `gatherBets()`：着地させる

- 飛んでいくチップを薄くしない（終わりも opacity 1 のまま）。
- 行き先は山の中心ではなく、山の中のランダムな点にする。最後の 15% で 5px 弾む。キーフレームは見本の `flyFrom(...,land=true)` を参照。
- 着地したら飛んでいた要素を消し、すぐ `potGrow()` で足す。こうすると、チップが山に混ざったように見える。

### 5. `pushChips()`（オールイン）

いまのまま残す（山を前へ押し出して、卓が静まる演出）。押し出したチップは、そのストリートの終わりに `gatherBets` で山に入る。

### 6. `potFly()` → 山ごと押し出す

- `#potChips` の山全体を、勝った人の席の方へ 6px 引いてから押し出す。このとき 0.55 倍に縮めながら薄くする（750ms、`cubic-bezier(.6,0,.3,1)`）。
- 同時に、札の数字を 0 まで数え下げる。
- 引き分けで分けるときは、山の子要素を交互に分けて、それぞれの勝者へ飛ばす。
- `angleCall` の「1枚だけ出す」演出は、いまのまま残す。

## 確かめること

- 第1〜3章を autoplay で回して、勝敗と難しさが変わっていないこと。テストでは設定に `quiz:false` を入れる。
- 390×844 と 1280×800 で、山と札が他の物（カード、プレート、`.mystack`）にかぶらないこと。
- 店ごとの照明（`--lamp`）の下で、黒チップが見えにくくならないこと。
- 速度設定（`SPEED()`）が新しい動きにも効くこと。
