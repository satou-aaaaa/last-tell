# 第二部「師匠になった主人公」実装仕様（2026-10-09 決定）

決定：2026-10-09 satou さん「おすすめでお願いします」。
元の提案：[第二部_師匠になった主人公_調査と提案.md](第二部_師匠になった主人公_調査と提案.md)、[ストーリーの深みとエンディング後の構成_提案.md](ストーリーの深みとエンディング後の構成_提案.md)。
対象ファイル：`story/shisho.html`（担当：「ストーリーモードの企画提案」スレッド）。

## 決まったこと

1. 第二部は「第一部の主人公が師匠になる」形（三代の師弟：ジン → 第一部の主人公 → 三代目）。
2. 第二部の主人公（三代目）は **タロウ**。
3. 師匠（第一部の主人公）の顔は、**第二部の最後の卒業試験でだけ**見せる。それまでは後ろ姿か、手元だけ。
4. 第一部の打ち方の記録を **今から始める**（遊び方は変えない）。
5. テーマは「いつ降りるか」にしぼる。本編に小さな追加を3つ入れる（下の段階1）。※この2つは前の提案で「おすすめ」としていたもので、今回の「おすすめで」に含めて決定扱いにしている。

## 守ること（いつもどおり）

- 第1〜7章の筋、勝負の中身、難しさは変えない（第1〜3章は特に）。第7章のジンの本物のテルには触れない。
- セリフでお金の話はしない。題名に「夜」を使わない。かっこいい方向（強いほどかっこよく、弱いほどかわいく）。
- 新しいボタンは足さない。
- 変更のたびに UI チェック（スマホ縦・横、PC のスクリーンショットで、重なり・はみ出し・隠れたカードやボタンが無いか）をして結果を報告する。
- 長編の骨組みは四部構成（弟子 → 師匠 → 外海 → 最初の看板）に決定済み（2026-10-09、[長編の世界の広がり_全体設計.md](長編の世界の広がり_全体設計.md)）。第二部はその2章に合わせる（下の 2-0）。第一部に入れる伏線3つは [長編の伏線3つ_実装仕様.md](長編の伏線3つ_実装仕様.md) のとおりで、この仕様とは別に入る。

## 段階1（先に入れる。小さい）

### 1-1. 第一部の打ち方の記録 `shisho-style`

第1〜7章のストーリーの勝負だけで記録する（フリー対戦、裏の卓、回想、強制ハンドは数えない）。保存は `{v:1, ...}`。読み込みは他のキーと同じく try/catch で、壊れていたら初期値。

| 項目 | 中身 | 数え方 |
|---|---|---|
| `hands` | 参加できたハンド数 | 自分に手札が配られたハンド |
| `vpip` | プリフロップで自分からチップを入れた回数 | ブラインド以外でコール・レイズした |
| `pfr` | プリフロップでレイズした回数 | |
| `folds` | 降りた回数（どの段階でも） | |
| `foldFacingBet` | ベットを受けて降りた回数 | 降りた中で、前に相手のベットがあったもの |
| `bluffs` | ショーダウンまたは相手が降りたとき、自分がワンペア未満でレイズしていた回数 | ハンドの終わりに判定 |
| `readBy` | 相手に読まれた自分のクセの回数 `{size, time, body}` | 今の `selfRecord` と「見抜かれる演出」で、相手が読んだときに +1 |
| `readHitBy` | 自分が読み当てた相手 `{名前: 回数}` | 今の `shisho-read` の `byName` をそのまま参照してよい |

- 第1〜4章は自分のクセが読まれない（`selfOn` が false）ので、`readBy` は第5〜7章だけで増える。それでよい。
- 画面には何も出さない。デバッグ用に `window.__style()` で中身を見られるようにしておくとテストが楽。

### 1-2. 本編に足すセリフ（テーマ「いつ降りるか」）

勝負の中身は変えない。会話と地の文だけ。

| 場所 | 足すもの |
|---|---|
| 各ボスの負けたあとのセリフ（第2〜6章） | 「降りる」ことへのその人の考えを1行。例：ロク「……あの夜、あいつは降りなかった。降りろと言えなかったのは、俺だ」／セキ「私は降りすぎた。ジン君は降りなさすぎた。……どちらも、負けだったね」／レイカ「降りる人の指は、迷わないの」／ハヤト「降りたのは、俺のほうだ。師匠から」／クロウ「私は、勝ちから降りられませんでした」。言い回しは担当スレッドで口癖案・話し方表に合わせて直してよい |
| 第6章のあと | クロウ「看板を持つ者は、挑まれたら断れません。15年前のジンのように」 |
| `EPILOGUE` の最後（ハヤトが扉を開ける前） | 1行足す：「最近、錨亭に新しい客が来る。『もうワンハンドだけ』が口ぐせの、心配性の男だ」（タロウ。第二部への橋） |

### 1-3. 部の表示

- 今の第5章の頭に `{part:'第二部',title:'あの夜'}` の扉がある。新しい「第二部」と名前がぶつかるので、ここを **「第一部　後編」**（題は今のままでよい）に変える。
- 第1〜7章全体が「第一部　弟子」、新しく作るのが「第二部　師匠」（四部構成の名前に合わせる）。

## 段階2（第二部本体。段階1のあと）

### 2-0. 四部構成との合わせ方（全体設計 2章より）

- 舞台は「海沿いの街々」。錨亭（ホーム）を中心に、隣の港町を2〜3つ足す。よその街の看板持ちが錨亭に来る章と、タロウが遠征する章がある。
- よその街の古い店にも、錨亭と同じ形の **名前のない看板** がかかっている（全体の謎「最初の看板」の第二部の段）。
- **ジンの師匠の名前** がこの部で初めて出る（第4章。名前は担当スレッドが全体設計と合わせて決める）。
- 部の終わりに、主人公（師匠）が **外海の卓** へ向かう。タロウは錨亭に残る。
- 新しい立ち絵は4人まで（師匠の正面、ハヤトの弟子、よその街の看板持ち1〜2人）。それ以外は後ろ姿・シルエット・噂だけ。
- 実在のカジノの街は出さない。架空の港町だけ。


### 2-1. 開き方

- 第7章クリア → エピローグ（伏線3つの仕様にある「完」のあとの招待状の場面を含む。順番はそちらに合わせる）→ **短いスタッフロール**（店の看板が1枚ずつ灯って消える。10秒前後、タップで飛ばせる）→「第二部　師匠」の扉 → タイトルに戻る。
- 章選択に「第二部」の列を足す（第7章クリアで開く）。保存は `shisho-progress` とは別に `shisho-part2` `{v:1, cleared:0..5}` を作るのがおすすめ（第一部の進み具合と混ぜない）。

### 2-2. 立場

- プレイヤーは **タロウ** を操作する。あだ名（`SETTINGS.nick`）は **師匠の名前** として使う（タロウが「〇〇さん」と呼ぶ）。
- アドバイスは **師匠のアドバイス** になる。今のジンのアドバイスの仕組み（`jinNote`、`adviceAfterHand` など）を、話し手と文言だけ差し替えて使う。表示ラベルも「師匠の教え」のまま使えるが、話し手の名前はあだ名。
- ジンはときどき師匠にだけ口を出す（1章に1回くらい）。例：「教えるのは、打つより難しいぞ」。
- タロウの立ち絵は、章が進むごとに少しずつかっこよくする（表情の差分か、服の小物1つ）。最終章でも rank は 2 まで（かわいい側から一歩出たくらい）。

### 2-3. 師匠の作り方（`shisho-style` から）

| 判定 | 条件（めやす） | 師匠の口ぐせ・教える中身 |
|---|---|---|
| 守りの師匠 | 降りた割合が高い（`folds/hands` ≥ 0.6） | 「降りるのも勝負のうちだ」をそのまま受け継ぐ。降りることを先に教える |
| 攻めの師匠 | `pfr/hands` ≥ 0.25 | 「先に打ったほうが、話を決める」。レイズの意味を先に教える |
| 読みの師匠 | 読み当てた回数が多い | 「手を見るな、顔を見ろ」。テルを先に教える |
| ふつう | 上のどれでもない、または記録が少ない（`hands` < 30） | 守りの師匠と同じ扱い |

- 判定は第二部を始めたときに一度だけ行い、`shisho-part2.mentor` に保存して以後は変えない。
- **師匠の本物のクセ** ＝ `readBy` で一番多いもの（同数・0 なら `body`＝チップを見る）。第二部最終章で使う。
- 師匠がよく読み当てた相手（`readHitBy` の一番多い名前）を、思い出話に1回使う：「〇〇の△△は、何度も見た」。
- 記録が無い人（段階1より前に第7章までクリアした人）は「ふつう」として遊べるようにする。

### 2-4. 章（5章。題名は仮、「夜」は使わない）

| 章 | 題名 | 舞台 | 相手 | 勝利条件のめやす | 物語の要点 |
|---|---|---|---|---|---|
| 1 | 三代目 | 錨亭 | ゲン、ケンジ、ミサキ | ゲンのチップを全部取る（第1章と同じ形） | タロウが「もうワンハンドだけ」で負け続けている。師匠が隣に座り、最初の教え（2-3の型による）。ジンは奥で黙って飲んでいる |
| 2 | 隣の港 | 隣の港町の店（新しい舞台） | その街の看板持ち、常連2人 | 第2章と同じお題をやさしめに | タロウの初めての遠征。店の壁に、錨亭と同じ形の名前のない看板。師匠の教え方がジンと違うことを、よその店の主に言われる（「あんたの師匠より、よくしゃべるね」） |
| 3 | もう一人の師匠 | 月影 → 地下の賭場跡 | ハヤトの弟子（新しい脇役。名前・見た目は担当スレッドで決めてよい。rank 2）、ハヤト | 規定ハンドで負けが決まっている1ハンド＋その後の勝負 | ハヤトも弟子を連れている。タロウが勝負を急いで負ける。師匠が「まだ半人前だ」と言いかけて、ジンが止める（2-5） |
| 4 | よその看板 | 王冠（6人卓。よその街の看板持ちが集まる） | ハヤトの弟子、よその街の看板持ち、クロウ、ほか | 6人卓トーナメント | ハヤトの弟子に勝つ。ジンがハヤトに「……お前も、一人前だ」。年長の看板持ちが、師匠を見て **ジンの師匠の名前** を口にする（「〇〇の孫弟子か」） |
| 5 | 最後のテル | 錨亭、閉店後 | **師匠**（ヘッズアップ） | 第7章と同じ形 | 2-6 |

- 難しさ：第二部はクリアした人向けなので、第5〜7章と同じくらいから始めて、最後は第7章より少し上でよい。
- 第3章の負けハンドは、第5章の AA バッドビートと同じく「1回だけ、短く」。

### 2-5. 師匠のつまずき（第3章）

```
['','タロウが、最後のチップを押し出した。'],
['','ハヤトの弟子が手を開く。タロウの負けだ。'],
['師匠','……まだ半——'],
['ジン','それは、俺の失敗だ。真似するな'],
['','師匠は、しばらく黙っていた。'],
['師匠', (2-3の型ごとの言い直し。例：守り「今日は2回、ちゃんと降りた。そこだけ数えろ」)],
```

- 「師匠」の表示名はあだ名。顔は出さない（後ろ姿か、手元のチップだけ）。
- 言い直しのセリフは型ごとに1つずつ用意する。

### 2-6. 第二部の最終章「最後のテル」

- 師匠は CPU として、`shisho-style` の傾向で打つ。参加率・レイズ率を style のパラメータに写す（例：参加ライン＝`vpip/hands` に近づける、レイズ頻度＝`pfr/hands`）。キャラごとのハンドレンジの仕組み（参加ライン 0.6〜1.0）がある場合はそれに合わせる。
- 師匠のテルは `CFG.tells` の仕組みを使い、**2-3の「本物のクセ」** を出す。章の途中までは一度も出さない（第7章のジンの傷と同じ作り）。
- 最後の大きなハンドで、師匠がそのクセをわざと見せる。答えは **本物**（強い手）。読み切って降りれば卒業。コールした場合は第7章の `ALT_END` と同じく短い別の結末（師匠「……まだ早かったか。もう一度だ」）。
- **師匠の顔を見せるのはここだけ**。最後のハンドの前、師匠がクセを見せる直前に、初めて正面の立ち絵を出す。立ち絵は主人公用に新しく1枚（イラスト仕様書に「主人公（第二部の師匠）」として足す。かっこいい側、rank 4 相当）。
- 卒業試験の **前** に、師匠が先に言う：「もう、一人前だ。……だから、本気で打つ」（ジンは試験のあとにしか言えなかった。その違いを見せる）。
- 終わり：錨亭の壁の写真が4枚になる（ジン、師匠、ハヤト、タロウ）。ジンが初めてチップを指の上で転がし、笑う。翌朝、師匠は外海の卓へ向かう（第一部の招待状を持って）。タロウは錨亭に残り、「もうワンハンドだけ」とは言わなくなっている。

### 2-7. 称号（案）

- 「三代目」：第二部クリア
- 「受け継いだクセ」：第二部最終章で師匠のクセを読み切って降りる
- 「半人前と言わない」：第二部をノーコンティニュー

### 2-8. テスト

- autoplay で第1〜7章の勝敗の流れが変わっていないこと（段階1の記録追加で、勝負の中身が変わらないこと）。
- `shisho-style` が無い／壊れている／`hands` < 30 のどれでも、第二部が「ふつう」の師匠で最後まで遊べること。
- 2-3の4つの型それぞれで、第二部第1章と第5章を autoplay で通す（`shisho-style` を書き換えて確認）。
- 師匠の顔が最終章の最後のハンドより前に一度も出ないこと。
- いつもの UI チェック（スマホ縦・横、PC）。特にスタッフロールと「第二部」の扉、写真4枚の場面。
- 英語版（実行時の翻訳）で新しいセリフが崩れないこと。
