## 1. 見せるか伏せるか

### ライブでは
- 全員を降ろして勝ったときは、手を見せなくてよい。見せると情報を相手に渡すことになる。
- ショーダウンで負けた人は、手を伏せて捨てる（マック）ことができる。最後にベットした人から先に見せるのが基本。

### ゲームでの動き
- **降ろして勝ったとき**（`winUncontested` でプレイヤーが勝者）：ボタンを2つ出す。**「見せる」／「見せない」**。押さなければ「見せない」で次へ進む。
- **ショーダウンで負けたとき**：最後にベットした人でなければ、プレイヤーの手は**自動で伏せる**（ログに「手を伏せて捨てた」）。設定「負けた手：伏せる／見せる」で変えられる（既定は伏せる）。
- **CPUが覚える**（`CFG.tells` のときだけ）：
  - プレイヤーが見せた手を `S.shown` に記録する（`{bluff:回数, strong:回数}`）。ブラフは「降ろして勝ち、手が `isWeak`」で判定。
  - `cpuDecide` で、プレイヤーがベットかレイズをしている場面だけ、CPUの `margin` を補正する。ブラフを見せた回数1回ごとに −0.03（コールしやすくなる）、強い手を見せた回数1回ごとに ＋0.03（降りやすくなる）。上限は ±0.09。6ハンドごとに1回分ずつ忘れる。
  - 見せた直後、CPUがひとこと。ブラフを見せた：「……覚えておく」。強い手を見せた：「やっぱりな」。
- **CPUも見せる**：レイカやハヤトなど、`MANNERS` か揺さぶり好きのキャラは、降ろして勝ったときに20%でブラフを見せる。「ふふ、見せてあげる」。ログに「レイカはブラフだった」。答え合わせのノート（`noteTell`）には入れない（テルではないので）。
- **ジンのひとこと**（初回だけ）：見せた → 「見せるな。情報はただでやるな」。わざと強い手を見せた → 「……悪くない使い方だ」。

### 称号
```js
{id:'showbluff',name:'見せブラフ',hint:'降ろして勝ったブラフを相手に見せる',jin:'次からは、もう通じんぞ。'},
```

## 2. 席選び

### ライブでは
- 荒い相手（よく賭けてくる人）の**左側**に座ると、その人の後から動けるので有利、とよく言われる。

### ゲームでの動き
- **対象**：フリー対戦と第5章以降（第1〜4章の席は固定のまま）。相手が2人以上のときだけ。
- 対戦開始前の相手紹介（`showVersus`）の後に、**席を選ぶ画面**を1枚はさむ。テーブルを上から見た図に、相手の立ち絵と性格ラベル（`label`）を並べ、空いている席をタップして座る。
- 仕組み：プレイヤーは常に配列の0番。行動順は `nextIdx` で i+1 なので、**配列の最後の席の人の直後にプレイヤーが動く**。「○○の左に座る」＝その人を配列の最後に並べ替える。`startGame` の `cfg.seats` を並べ替えてから `S.players` を作る。
- ジンのひとこと（席選び画面で）：「荒い奴の左に座れ。あいつが動いてから決められる」。荒い相手の左を選ぶと「それでいい」。
- 店の常連レベル（6）が上がると「いつもの席」が選べる（見た目だけ）。

### 称号
```js
{id:'seat',name:'いい席',hint:'荒い相手の左に座って勝つ',jin:'座った時点で、半分勝っている。'},
```

## 3. 「カウントお願いします」

### ライブでは
- 相手の持ち点は、チップの山を見てだいたいで読む。正確に知りたいときは、ディーラーに数えてもらう（「カウントお願いします」）。

### ゲームでの動き
- **対象**：`CFG.tells` のとき（第4章以降とフリー対戦）。設定「相手の持ち点：だいたい／正確」（既定はだいたい）。
- 「だいたい」のとき、相手の名札（`plate`）の数字を出さず、**チップの山だけ**を見せる。数字の代わりに「約2万」のような丸めた表示（上から1けたで丸める）。自分の持ち点とポットは正確に出す。
- 相手の名札をタップすると、ディーラーが数える：`dealerSay('ロクさん、2万3千です')`。0.6秒ほど「数えています…」の間を置く。数えた数字は、その人のチップが動くまで正確に表示したままにする。
- 自分の番で大きく賭けられているときだけ、ジンがひとこと（初回）：「迷ったら数えさせろ。恥ずかしいことじゃない」。

## 4. ディーラーのミス

### ライブでは
- 配るときにカードが表向きになってしまうことがある（よくある扱い：そのカードは交換し、見えたカードは使わない）。
- 配り方を間違えたら配り直し（ミスディール）。

### ゲームでの動き
- **対象**：`CFG.tells` のとき。1ハンドに4%（ハンド25回に1回くらい）。続けては起きない。
- `startHand` で手札を配るところに入れる。種類と結果：

| 種類 | 割合 | 見せ方 | 結果 |
|---|---|---|---|
| CPUのカードが表向き | 50% | 配る途中で1枚が表のまま止まる → ディーラー「失礼しました、交換します」 | そのカードを山から外して別のカードを配る。見えたカードはログに残る（そのカードはもう出ない＝小さな情報） |
| 自分のカードが表向き | 30% | 同じ | 同じく交換。CPUの判断には影響させない |
| ミスディール | 20% | ディーラー「ミスディールです。配り直します」 | 誰も行動していない段階なので、山を切り直して配り直す。ブラインドはそのまま |

- 交換とミスディールで、5の**フロアのクイズ**を出してよい（初回だけ、または設定でオンのとき）。
- ジンのひとこと（初回）：「ディーラーも人間だ。見えたカードは覚えておけ」。

### 称号
```js
{id:'misdeal',name:'ディーラーも人間',hint:'ディーラーのミスに立ち会う',jin:'慌てるな。慌てた奴から負ける。'},
```

## 5. フロアを呼ぶ（ルールクイズ）

### ライブでは
- もめごとや判断の難しい場面では、ディーラーが店の責任者（フロア）を呼び、フロアが裁定する。

### ゲームでの動き
- 新しいキャラ **フロア**（各店共通の黒服。名前は「フロアの黒田」など。かっこいい側、rank 3）。立ち絵は既存の `coolAvatar` で。
- **出す場面**：マナー仕様のアングルショット（`faketap`、`onechip`）、4のディーラーのミス、ストラドル（初回）、ショーダウンでの嘘の役宣言（マナー仕様）。
- 流れ：
  1. ディーラー「フロア！」 → フロアが画面に出る。
  2. 裁定の前に、プレイヤーに**「どうなる？」**と2〜3択を出す。
  3. 選んだら、フロアが正解と短い理由を言う。正解・不正解で勝敗は変わらない。
  4. 正解数を保存（`shisho-quiz`）。
- 設定「ルールクイズ：出す／出さない」（既定は出す）。同じ問題は、正解したら二度と出さない。
- ルールは店ごとに違うので、フロアの説明は「多くの店では」と言う。

### 問題の例（`QUIZ` データ）
| id | 場面 | 選択肢 | 正解と説明 |
|---|---|---|---|
| tap | テーブルを叩いてから「ベットだ」と言った | チェック／ベット | チェック。「叩いたらチェックです」 |
| onechip | 大きいチップ1枚を黙って出した | コール／レイズ | コール。「宣言がなければコールです」 |
| string | チップを2回に分けて出した | 最初の分だけ／全部 | 最初の分だけ。「一度に出さないと上乗せになりません」 |
| exposed | 配るときにカードが表向きになった | 交換する／そのまま使う | 交換する |
| speak | 「ストレートだ」と言ったが実はワンペアだった | 見せた手で判定／言った役で判定 | 見せた手で判定。「カードがしゃべる」 |
| order | ショーダウンで誰から見せる？ | 最後にベットした人／ボタンに近い人 | 最後にベットした人（誰もベットしていなければボタンの左から） |
| straddle | ストラドルを置いた人はいつ話す？ | プリフロップの最後／最初 | 最後 |
| allin | オールインで勝負が決まったら？ | 全員が手を見せる／見せなくてよい | 全員が手を見せる |

### 称号
```js
{id:'rules',name:'ルールに詳しい',hint:'フロアのクイズに5回正解する',jin:'ルールを知っている奴は、慌てない。'},
```

## 6. 常連になる

### ライブでは
- 同じ店に通うと、店主や常連に名前を覚えられ、会話が増える。

### ゲームでの動き
- **通った回数**を店ごとに保存（`shisho-regular`：`{v:1,visits:{1:回数,2:回数,...}}`）。その章で対戦を始めるたびに +1（再挑戦も数える）。
- **常連レベル**：
  | レベル | 条件 | 呼ばれ方 |
  |---|---|---|
  | 0 | 最初 | 「新入り」「お弟子さん」（今のまま） |
  | 1 | 3回 | 名前で呼ばれる |
  | 2 | 8回 | 「いつもの」が出る |
- **名前**：設定に「呼び名」を追加（8文字まで、既定は空）。空なら、レベル1以上でも「新入り」のまま。表示はすべて既存の `esc()` を通す。
- **増えるもの**：
  - `GOSSIP` に店ごとの常連レベル別のセリフを追加する（`GOSSIP[ch]` を `{0:[...],1:[...],2:[...]}` の形に広げるか、レベル1・2用を別の表にする）。例（錨亭）：Lv1 店主「{name}、今日も来たね」／Lv2 店主「いつものカレー、大盛りにしといたよ」
  - 対戦開始時のログ：Lv2 で「店主が『いつもの』を出してくれた」（中身はぼかす。お酒にはしない）。
  - 章の選択画面で、店ごとに小さく「常連度」を表示（★0〜2）。
- **クリアした店で遊べる**：章クリア後、その店でフリー対戦ができる（店の照明、BGM、ハウスルール、その店のキャラが相手）。`startFree` に店を渡せるようにする。通うほど常連度が上がるので、くり返し遊ぶ理由になる。
- 第7章（錨亭、閉店後）で、錨亭の常連度が2なら、店主のセリフを1行足す（「あんたも、もう立派な常連だ」）。

### 称号
```js
{id:'regular',name:'常連',hint:'どこかの店で常連度★2になる',jin:'顔を覚えられるのは、悪いことじゃない。'},
```

## 入れないもの
- 実在の店や大会とつながる要素（店の特典、来店ポイントを現金や景品に換える、など）。
- 他の人のハンドに口を出せる機能（マナー違反なので、プレイヤーにはさせない）。
