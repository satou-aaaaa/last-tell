## できたこと
1. **座った姿勢**（骨を回す）：腿を前へ 65°・すねを下へ・足先、腰（pelvis）は卓の外縁から 0.16m 後ろ・ラシャの 0.11m 下（ディーラーの高めのいす、座面は床から約 0.57m）。肩はラシャの上 約 0.37m。前腕は body_poses.json の `rest_table`（前腕を卓に置く形）が元。遠くへ手を伸ばすときは **腰から前へ最大 20° 傾く**（腰 8 割・胸 2 割。頭の骨組みも同じ点のまわりに回すので首・肩の継ぎ目はずれない）。首は手の行く方を少し見る（下を見すぎて顔が隠れないよう控えめ）。
2. **腕の IK**：Godot 4.6 から入った **`TwoBoneIK3D`**（`SkeletonModifier3D` → `IKModifier3D` の仲間。4.7.2 で確かめた）を体の骨組みに 1 つ、設定 2 本（左右）。上腕 `upperarm_*` → 前腕 `lowerarm_*` → 手 `hand_*`。
   - 肘の向き（pole）：肩から **外・後ろ・少し下**（体を傾けるほど少し上げる）。`pole_direction` は rest_table の形で「前腕の骨から見て肘が突き出ている向き」を測って入れた（`SECONDARY_DIRECTION_CUSTOM`）。
   - 手首から先（指の向き・手のひら下／上・手首のはじき・指の曲げ）は IK の後の自分の modifier で決める。手を体の近く（レールの近く）に引いたときは手首を自動で上げる（前腕がレールに乗り上げないように）。
   - modifier の並び（体の骨組みの子）：`DealerSeat`（座る・傾く・首）→ `DealerTargets`（手首の目標・肘の向きを置く）→ `ArmIK`（TwoBoneIK3D）→ `DealerHands`（手首から先）。頭の骨組みにも `DealerSeat`。
3. **`Dealer3D`（`game/chars/3d/dealer3d.gd`）**
   - `reach(hand, target_world_pos, sec, opts)`：手（`Dealer3D.L` / `.R`）の指の付け根を世界の点へ。opts で yaw / pitch / roll / grip / lift / ease。`await` できる。`reach2`（両手）・`hold`・`rest_hands`
   - 6 つの動き（どれも `await` できる。`busy` に名前、終わると `move_finished`）：
     `shuffle()`（手元でリフル 2 回→そろえる）、`deal_to(seat)`（右手で上の 1 枚を取り **卓の上を同じ高さで真っすぐすべらせ**、手首ではじいて離す。**弧を描かない**。離した所と向きを `card_released(seat, at, dir)` で知らせる＝その先は札だけがすべる）、`burn_and_flop()`（伏せて脇へ→3 枚まとめて置く→まとめて返す→広げる）、`collect_bets(seats)`（手を立てて小指側で寄せる）、`push_pot(seat)`（両手で囲んで押す）、`collect_muck(spots)`
   - 手が通る点は **`DEALER_HAND`（= 卓のスレッドの `Stage3D.DEALER_HAND = (0, 0, −0.40)`）** と席の位置・`BOARD_AT`・`POT_AT`・`BURN_AT` だけから決める。卓の側に `Stage3D` があればその定数・`seat_tf()` を使い、無ければ写し（`REAL_HALF=(1.30,0.66)`・超楕円 2.6・席 10・ディーラー −z、`claude/project-thread-loz431` と同じ数字）。
   - 物を取った・置いた：`grabbed(hand, at, what)` / `placed(hand, at, what)`（札・チップを動かすのは卓の側）
   - **体のキー**：`const DEALER_KEY := "hayato"`（仮）。本物のディーラーの MetaHuman が `chars/3d/dealer/` に入ったら **ここを `"dealer"` にする 1 行だけ**（`Character3D.KEYS` に `"ディーラー": "dealer"` を足してある。素材が無いうちは何も変わらない）。`Dealer3D.create(parent, key)` でほかのキーも渡せる。
4. **戻り道（今のゲームは変わらない）**：`Dealer3D.create()` は **3D の人を使わない設定（`CharacterFactory.use_3d` が false）・画面なし（headless）・素材なし** のとき `null` を返し、何も作らない。ゲームの画面にはまだつないでいない（卓の 3D は卓のスレッドの担当なので、`Dealer3D.create(stage_root)` を呼ぶ 1 か所だけで入る）。

## 検査（`game/chars/3d/demo/dealer_check.gd`、画面なしで動く）

## 仮のところ・気をつけること
- **体は借り物**（ハヤト）。服は共通の T シャツの色を画素ごとに塗り分けた **黒いベスト＋白いシャツの V・襟**、体の肌に **白い長袖・黒いズボン・黒い靴** を塗っただけ（形は T シャツのまま、袖は半袖の上に塗った長袖）。蝶ネクタイは小さな黒い 2 つの三角を首の骨に合わせて毎こま置いたもの（襟より少し下に見える）。本物のディーラーの MetaHuman（黒いベスト・白いシャツ・蝶ネクタイ）が来たら、`DEALER_KEY="dealer"` で塗り替えは自動で止まる（`key != "dealer"` のときだけ塗る）。
- **腕が届く所は限られる**：この体（肩→手首 0.52m）では、腰から 20° 傾いても指の付け根が届くのは肩からおよそ 0.6m。場札の奥・遠い席（3〜7）のベット・席の前まではもちろん届かない。届かない分は **手を届く所で止め、その先は札・チップが卓の上をすべる**（`in_reach()` が毎こま縮める。検査の「縮めた」最大：配る 6cm・フロップ 17cm・ベット 53cm・ポット 25cm）。本物のディーラーも遠い席へは押してすべらせるので、この形でよいと思うが、卓の側の札・チップのすべり（カードとチップのスレッドの直し）とつなぐ必要がある。
- ディーラーは客の席（外縁から 0.36m）より前の **外縁から 0.16m（腰）** に座らせた（卓の切り欠きに入る想定）。卓の担当の本物の卓に切り欠きが無いと、おなかがレールの外の縁に近い。
- 撮影の卓・光・小物は仮（単色の布・箱の札・円柱のチップ）。シャッフルの束は分かれて見えない（手だけ）。フロップをめくる手の返しは控えめ。
- 描画は主に Compatibility（CPU の llvmpipe）で撮った。Forward+（Vulkan の lavapipe）でも 1 組撮った：`fwd_01〜04_*.png`（肌の SSS あり）。
- 指は「曲げる量」1 本だけ（札をつまむ形・リフルの親指は作っていない）。
- `Character3D` の 2D の絵（SubViewport）は使わず、頭と体だけを 3D の世界へ移している（`adopt` の中。囲む卓のスレッドの `adopt_into()` と同じ考え）。ディーラーは正面（+z）を向くので向きの変換は要らない。
