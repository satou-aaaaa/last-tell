## 1. 切り欠きの卓（PR #28）
- PR #28 の卓の形（`Stage3D.table_pt`）：奥の真ん中で **外の縁 z=−0.54・レールの内の縁 −0.43・木の縁 −0.43〜−0.395・ラシャは −0.395 から**。レール（高さ 5cm）は切り欠きでも削られず、同じだけ前へずれているだけ。手元 `DEALER_HAND` z=−0.40 は **木の縁の上**（レールの 3cm 前）。
- 腰を `Stage3D.seat_tf(0)`（z=−0.70）に置いた。撮影の卓は PR #28 の `Table3D._build_real` と光をそのまま使う（`dealer_stage.gd`。仮の卓は Stage3D が無いときだけ）。
- 直したこと（`dealer3d.gd`）
  - 卓の面の高さを PR #28 の断面そのままで計算（`table_pt` の式を解く。5mm の格子で覚える）
  - **手首をレールに乗せる**：手首（とその後ろの前腕）がレールから 3.2cm 上に来るまで指先を下げる（最大 42°）。足りない分だけ手を浮かせる（休みで 8mm）。指の付け根から先はラシャにそわせる（指を最大 30° 起こす）
  - **肘を上げる**：肘・腕がレールに当たる形のときは、肘の向き（pole）を外のまま上へ回す（こまごとに少しずつ）
  - **おなか**：この体はおなかが腰の 0.17m 前まであり、切り欠きの縁に 1cm 食い込んでいた → 腰を 7° 起こして胸で戻す（肩の位置はほぼ同じ）。前へ傾ける量も腰 12%・みぞおち 60%・胸 28% に（腰で傾けるとおなかが前へ出る）
- 検査 `dealer_check.gd`：**NG 0**。腕と卓のすき間 最小 +5.8mm（全部の動き）、手のずれ 最大 0.8mm。**体と卓の検査を足した**（服・体の肌の頂点を skinning して、卓の板・レール・前垂れの中に無いか）：最小 +7.0mm（腿と前垂れの下の端）。結果は `check.txt`
- 腰の位置を上げたので届く所が少し狭くなった（すべらせて足す分：フロップ 113mm・ポット 181〜189mm）

### 卓のスレッドへ（提案の数字）
今の数字でも食い込みは無いが、手元がレールのすぐ前なので「前腕をレールに乗せて手を垂らす」形しか取れない（手首がラシャの上 7〜8cm）。本物の卓の切り欠きはディーラーの所に詰め物のレールが無いので、どちらかを提案：
- A（おすすめ）：**切り欠きのまっすぐな所（|x| < 0.30）だけレールを低く**：`RAIL_TOP` 0.05 → **0.015**（木の縁だけの平らな「ディーラーの縁」）。`DEALER_HAND` は −0.40 のまま
- B：レールはそのまま、`DEALER_HAND` を **(0, 0, −0.34)**（ラシャの縁から 5.5cm 内）へ。手全体がラシャに乗り、前腕だけがレールに乗る
- `DEALER_BACK` 0.16 はこの体で通る（おなかと縁 6mm）。前へ 20° 傾けても余裕を持たせるなら **0.18**

## 2. 髪（モヒカンに見える）
- 頭皮の下塗りに **髪の範囲（向きごとの生え際の高さ）** を足して焼き直し（`bake_groom.py` の `scalp_region`、`groom_color.json` の Dealer）：横は耳の上、耳の後ろ、後ろはうなじ（y 1.525）まで。耳は塗らない。前の生え際はカードの縁に少しぼかしを足しただけ
- 頭皮の膜を 1.8mm 浮かせた（焼いた 0.6mm では Godot の頭の肌に横・後ろが隠れていた＝「刈り上げ」に見えた原因）
- ディーラーだけ下塗りの材質を「短い毛の筋」に（後ろへ細長い筋の模様・照りは弱く。頭の骨について動く）
- カードの盛り上がりを縮めた（`hair_flatten` 0.45）。色は黒寄りに（melanin 0.8 → 0.86、redness 0.25 → 0.2）
- 残り：額の上の明るい帯は撮影の真上のランプの照り（肌）。生え際は UE よりまっすぐ

## 3. 襟
- **シャツの襟（白い帯）を首のまわりに足した**：T シャツの首の線の 1.2cm 下から、前 2.6cm・後ろ 4.6cm 上まで、頭のメッシュの首の外 4mm。首の骨（neck_01）に合わせて毎こま置く。蝶ネクタイは襟の前に（少し小さく）
- **頭のメッシュの胸・肩の部分をしまう**：頭のメッシュは胸の上まであり（重みは spine_04・clavicle・upperarm_fwd）、手を伸ばすと体に付いた T シャツが動いて肩でのぞいていた。頭の骨組みだけで、これらの骨を 0.55〜0.6 倍に縮めて服の下へ（首は変えない）。`14_push_pot.png` で肩の肌は出ない
