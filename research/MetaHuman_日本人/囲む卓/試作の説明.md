## 違和感の原因（数字）
今の卓（Stage3D.TABLE_CAM_POS (0,0.56,0.58)・画角 40°・2D の楕円 中心 (800,905) 半径 (1010,540) を卓の面へ写したもの）を計算すると:
- **卓が小さい机になっていた**：画面の下の端の幅で **0.97m**、真ん中から奥のレールまで **0.42m**。本物の 10 人卓は **2.4〜2.7m × 1.2〜1.4m**。幅で約 1/2.7、奥行きで約 1/1.6。
- **人が人形の大きさだった**：奥のレールの所で 1px = 0.71mm。本物の頭（あごから頭のてっぺん 約 0.23m）なら **約 326px** になるはずが、胸像は全体で 260px（頭は 90px ほど）。**人は卓とカードにくらべて約 1/3.6 の大きさ**で、カード（本物の 57mm＝場札で 90px）だけが本物の大きさ。
- **カメラが卓に顔を付けた高さ**：目がラシャの上 0.56m、奥のレールまで 0.87m（真上から見下ろす寄り）。人を写す別のカメラ（1 人ずつ正面・距離 3m）とは遠近が別なので、5 人が同じ大きさ・同じ正面向きで並ぶ。
卓の担当が卓を本物の寸法（2.6×1.32m、PR #24）にし、目のカメラを「卓上 0.42m・縁から 0.28m 後ろ・縦 50°・見下ろし 16°」（PR #24・#26）にした。この試作は人をその世界に入れた。

## 作り（一つの 3D の世界・1 台のカメラ）
- 卓（Table3D._build_real の長円を同じ世界に作らせる）、カード・チップ（PropMesh の本物の大きさ）、人、ディーラーの仮の人形を **一つの World3D** に置き、**自分の目のカメラ 1 台**（Stage3D.eye_cam(hero_seat)）で描く。後ろの店は Room3D（360° 写真のぼかし）をカメラの向きに合わせて回す。
- 人：今の Character3D をそのまま作り、組み上がったら頭と体（骨・髪・服ごと）を席の下へ移す（`Character3D.adopt_into(parent, offset)`）。表情・テル・体の姿勢（body_poses）・まばたきは今まで通り動く。自分の SubViewport・2D の絵・腕の帯はもう描かない。
- 向き：席の点は `Stage3D.seat_tf(s)`（胸の真ん中、-Z が場札）。**body_poses（肘をつく姿勢）は正面用のままで、席ごとに体ごと回して置くだけで使えた**（肩・腕・手は体の中の向きで決まっているので）。直したのは「画面の向きの軸」で骨を回す `_world_rot` が、人の根から見た軸で回すようにしたことだけ（回した席でも首・目・呼吸が正しく動く）。
- 脚：素材は立ち姿で、ズボンが無い（上だけ服）。股を 88° 前・膝を 92° 下に曲げて座らせ、膝から下はたたみ、腿は暗い箱（ズボンの代わり）で覆った。椅子の背も箱。隣の席からは腿が少し見える。
- 首と目：`Character3D.look_at_world(p, sec)`。左右は首で ±60°（neck_01・neck_02・head に 4:3:3）、残りを目で ±30°、上下は首 −15〜25°・目 −18〜22°。動く人がいると、ほかの人は少しずつずれてその人の手元・胸を見る。動く人は場札を見る／テルなら こちらを見る（にらむ）・目をそらす（横の下へ）。
- 自分の首：動いている人の方へカメラが 26° まで回る（`turn_to`、0.5 秒）。両隣・端の人を見られるように。
- 見にくい席の工夫（動かしたもの）：**スペースを押している間だけ身を乗り出してのぞき込む**（カメラを場札へ 0.26m 寄せ、場札の真ん中を見て画角 50°→30°。0.35 秒）。端の席でも場札の字が読める（04 の写真）。手札は自分の手元（カメラのすぐ下、縁から 0.31m）に表で置き、いまの 2D の手札（画面の下の真ん中に大きく）も残す。
- LOD：目から 1.5m より近い人は顔の細かい LOD0、ほかは LOD2（`lod_force`）。6 人卓・席5 では両隣だけ LOD0（0.99m）、ほかは 1.76〜2.09m で LOD2。

## 席で見え方が変わる（03・04 の写真）
- 席5（手前の真ん中）：場札を正面から。向こうの席 9・1 と、端の 2・8 が見える。両隣（4・6）は画面の端に手だけ。
- 席4・6（真ん中の隣）：場札を少し斜め。片側の隣の人の腕と体が画面の端に大きく入る（前の人の手で一部が隠れる）。
- 席2・8・1・9（端）：場札を横から細長く見る（字が小さく傾く）。向かいの長い辺の人は横顔・斜め顔、ディーラーの体が場札の向こうに重なる。→ のぞき込むで読める。
- 3D なので、前の人の手・チップの山・体で場札や人が隠れるのは自然に起きる（何も足していない）。

## 席の決め方との関係
- **物語**：台本で席を決める。章のデータに `seat`（1〜9）を足して `Stage3D.hero_seat` に入れる案。見えにくい席に座らされる章（「端の席で場札も相手も見にくい」）を演出に使える。師匠の一言「場札はのぞけばいい。顔は見逃すな」などで のぞき込む を教える。
- **フリー対戦の席選び**（features/talk/live_extra.gd pick_seat）：今は「◯◯の左（すぐあとに動く）」で順番だけ決めている。本物の卓では順番＝物理の席なので、選んだ「◯◯の左」を席の番号にし（席は時計回りに 1→9、左＝番号＋1）、**上から見た卓の小さな図**で「この席は場札が横から／◯◯の顔が正面に見える」も見せる。順番の得（荒い人の左）と見え方の得（顔が見える席）を選ばせられる。
- 人数が少ないとき：`Stage3D.seats_for` は間をあけて選ぶので、2 人のとき相手は席 9・1（ディーラーの隣）になり、遠くて小さい。一騎打ちや 3 人のときは、向かいの見える席（9・1・2・8）を先に使う並べ方にすると読みやすい（案）。

## 今の作りから変える所
### 卓（卓の担当、PR #24・#26 で入った・入る所）
- 本物の寸法の Table3D・目のカメラ・Stage3D.seat_tf / seats_for / eye_cam / project / px_per_m / to_screen。SEAT_BACK は 0.44 に（人の腕の長さに合わせた）。
- 人を同じ世界に入れるには、Table3D を「自分の SubViewport で一度だけ描く静かな絵」から「人と一緒に毎こま描く 3D の世界」に変える（試作は Table3D._build_real の形と材質を借りて自分の世界に作った）。
### カード・チップ
- 今は PropLayer が 2D のノードを読み取って別の SubViewport に描き、人より前に重ねる。同じ世界に置かないと、**チップや札が人の手の前に描かれる**（手が札の向こうにあっても）。試作（卓だけの写真）は同じ世界に置いた。ゲームの中の写真は PropLayer のまま（手の上に札が乗る所がある）。→ PropLayer の 3D の物を人の世界へ移す（カメラは同じなので、置き場所の計算はそのまま使える）。
### 人
- `Character3D.adopt_into / eye_world / head_top_world / look_at_world / lod_force / neck_turn` を足した（試作の枝の character3d.gd）。2D の人（Char2D）は今まで通り。
- テル（体の動き scar/release/glove）は回した席でもそのまま動く。顔のアップ（会話・テルのアップ）は今まで通りの 1 人用のカメラで撮る（ゲームの中は卓の世界、アップは別、の 2 つの使い方を残す）。
- ズボン・座った脚の素材が無い（今は箱で隠す）。服の担当に「座った下半身（ズボン・靴）」を頼みたい。
- ディーラー：席 0 に仮の人形（黒い胴と頭だけ）。全身の 3D のディーラー（dealer_work）が来たら置き換える。
### UI（名札・チップ数・吹き出し・ボタン）
- 名札・持ち点：人の胸ではなく **席の卓の縁の上**（`seat_tf(s) * (0, RAIL_TOP+0.02, -SEAT_BACK+0.02)`）を画面に写すと、手と重ならず読みやすい（卓の担当が PR #26 で同じ形で table.gd に入れた）。
- 吹き出し：`Stage3D.to_screen(cam, ch.head_top_world())`（頭の上 0.16m）。人が首を回すと頭が少し動くので、毎こま写し直す。
- 画面の外の人（両隣・端の席・首を回す前）：名札と吹き出しを画面の端に寄せて出す（体は見えないが何をしたか分かる）。試作は clamp で端に寄せた。
- ボタン・自分の名札・手札（2D）は画面に固定のまま。
- 自分の首が回る・のぞき込むとき、名札・吹き出し・2D の札はカメラに合わせて毎こま写し直す必要がある（今の table.gd は席替えの時だけ写す）。

- 軽くする案：(1) 人は今と同じく「動いたときだけ」描き直す：卓の世界を 2 つに分け、静かな卓（今の Table3D の一度だけ描く絵）と、人だけの層（深さを卓と合わせる）にする。(2) 人の層は 15〜30 回/秒に落とし、カメラが動く（首を回す・のぞき込む）間だけ毎こま。(3) LOD：遠い人（2m より遠い）は髪のカードを粗い LOD に、両隣（画面の端で手だけ）は頭・髪を描かない。(4) 影はランプ 1 つ・1024。

## 残る問題
- 両隣と端の席の人は、首を回さないと見えない（席5 から見えるのは 9・1・（2・8）だけ）。テルを読むゲームとしては、動いた人へ自動で首を回す（試作で入れた）か、「顔を見る」操作が要る。
- 脚・ズボン・靴の素材が無い（箱で隠している）。隣の席から腿の箱が見える。
- カード・チップを人と同じ世界に置く（PropLayer の移し替え）まで、札が人の手の前に描かれる所がある。
- 人がアクションするときの手の動き（チップを出す・札を見る）は今は無い（体は rest_table と 3 つのテルだけ）。前に出した手で場札が隠れるのは、手の動きが入ってから。
- 重さ（上）。本物の GPU の上での計測がまだ。
- 席を並べ直すと前の人が残る不具合（table.gd _build_seats が sv.ch を消さない。2D でも同じ）を見つけた。卓の担当へ知らせ済み。
