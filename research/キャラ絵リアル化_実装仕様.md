## 1. 置き換え方
1. 上の2ファイルの中身を `shisho.html` の `<script>` に足す（`fxTexture`・`fxTone` は除く）。
2. 今の `avatar(name, mood, opts)` を次の形にする。呼び出し側（卓、会話、名乗り、ノート、トーストなど約20か所）は変えない。
   ```js
   function avatar(name,mood,opts){
     mood=MOOD_ALIAS[mood]||mood||'normal';opts=opts||{};
     const key=REAL_KEY[name]||name;           // ミナ→ミナC、ゲン→ゲンC など
     if(REAL[key])return fxLight(realAvatar(key,mood,opts));
     const c=CHARS[name]||CHARS['ケンジ'];       // まだ描いていないキャラは今の絵（移行中だけ）
     return c.cool?coolAvatar(name,c,mood,opts):cuteAvatar(name,c,mood,opts);
   }
   const REAL_KEY={'ミナ':'ミナC','ゲン':'ゲンC','老人':'ジン'};
   ```
3. `REAL` の ミナ・ミナA・ミナB・ゲン・ゲンA・ゲンB（見本の比較用）は入れない。`ミナC`・`ゲンC` だけ残す。
4. `CHARS` は★（`rankOf`）と名札の判定に使っているので消さない。

### 足すときの決まり
- 年齢は `art/イラスト発注仕様書.md` §5 のとおり。20代以下は `young:1` を付け、`ew`（目の幅）5〜6.4、`eh`（目の高さ）3.4〜5、`ir`（瞳の大きさ）2.8〜3.9、`cy` 46〜47 にする。顔は `yf`（女）／`ym`（男）。
- 50代以上は `age:1`（ほうれい線）、60代以上は `age:2`（額と目の下のしわ）。
- ★1〜2 はかわいい側：`cute:1`、`blush` 0.2〜0.7、丸い顔（`o`／`O`／`s`）。★3以上はかっこいい側：目を細く（`eh` 2.2〜2.6）、`cute` なし、表情の動きを小さく。
- 明るいポップなアニメ調にしない。胴体や腕は足さない（肩まで）。18歳未満のキャラは出さない。
- キャラの色（髪・服・瞳）は発注仕様書の色をそのまま使う。
- 参考に、各キャラの髪と服は `realAvatar` の中の `if(name==='ソウ'){…}` のような分岐で描いている。同じ形で足す。

## 3. テル（必ず残す）
- **ジン**：`opts.tell!=='strong'` のとき、描き直した手（**軽く握った手の、人差し指の背で顎の傷をなでる**。`jinHand`）を出す。指を1本伸ばす形は不自然だったので使わない。手の明るさは **A 光が当たる**に決定（2026-10-09）。`opts.handDark` は使わない。テルの文章やナレーションに「指でなぞる」などの書き方があれば、「指の背でなでる」に合うよう確認する。`'strong'` のときは手を出さない。第7章の本物のテルはこの出し分けそのものなので、条件を変えない。
- **ハヤト**：`opts.tell==='strong'` で、ジンと同じ静かな顔（首を傾けない、片眉と口の端を戻す）。
- **クロウ**：白い手袋。`opts.tell==='hidden'` で指先を直す手を足す。
- 共通テルのCSS：`realAvatar` の目は `.eyes`、瞳は `.pupils` を持っているので `glance`・`stare` は今のCSSで効く。**汗（`.t-sweat`）は `realAvatar` にまだ無い**ので、`<g class="head">` の中に今の chars.js と同じ `SWEAT(64,34,'t-sweat')` を足す（位置は顔の右上、額の横）。
- 目線は待機中に動かさない（テルの「目線が泳ぐ」と混ざるため）。

## 4. 案4 生きている動き（CSS）
`shisho.html` の `<style>` に足す。卓の `.bust` と会話の `.portrait` に効かせる。46px の席アイコンには付けない（小さすぎて見えず、重くなるだけ）。
```css
.bust .av,.portrait .av{animation:breathe 4.2s ease-in-out infinite}
.bust .av .head,.portrait .av .head{transform-box:view-box;transform-origin:50% 80%;animation:sway 7.5s ease-in-out infinite}
.bust .av .eyes,.portrait .av .eyes{transform-box:fill-box;transform-origin:50% 60%;animation:blink 4.6s infinite}
@keyframes breathe{0%,100%{transform:translateY(0)}50%{transform:translateY(-1.2%)}}
@keyframes sway{0%,100%{transform:rotate(0)}30%{transform:rotate(.9deg)}70%{transform:rotate(-.7deg)}}
@keyframes blink{0%,90%,100%{transform:scaleY(1)}93%{transform:scaleY(.08)}96%{transform:scaleY(1)}}
@media (prefers-reduced-motion:reduce){.bust .av,.portrait .av,.av .head,.av .eyes{animation:none}}
```
- 席ごとにずらす：`.bust` に `style="--d:-1.3s"` のように負の遅れを付け、上の3つに `animation-delay:var(--d,0s)` を足す（全員が同時にまばたきしないように）。
- 今の `.bust.cue-glance .av .pupils` などのテル用アニメーションは、`.eyes` のまばたきと別の要素なので両方動く。

## 5. 重さ
- `fxLight` は SVG ごとにマスクを1つ作る。卓の6人＋席アイコンで20個前後。スマホで重い場合は、席アイコン（46px）だけ `fxLight` なしの `realAvatar` にする。
- `avatar()` は表情が変わったときだけ描き直している（`bd.dataset.mood` の比較）ので、そのままでよい。
