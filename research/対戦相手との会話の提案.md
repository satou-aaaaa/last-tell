# 対戦相手との会話の提案（2026-10-09）


**採用：5案すべて（satou、2026-10-09）。実装仕様は `research/対戦相手との会話_実装仕様.md`。実装はストーリーモードの企画提案スレッドが行う。**

satou の依頼「対戦相手としゃべったりする要素もおもしろいかもしれません。提案をしてください。」への答えです。

## いまある会話（重ねないための整理）

| いまある要素 | 中身 | 向き |
|---|---|---|
| テーブルトーク | 相手がアクションのたびに一言。ブラフのときは口数が増える（`raise_bluff` など） | 相手 → 自分（**しゃべる量**がテル） |
| 揺さぶる（5案採用） | 自分が一言かける。探る/急かす/黙って見る。相手の体のクセが出やすくなる | 自分 → 相手（一方通行） |
| 無視する / ナイスハンド | マナーの悪い客への反応 | 自分 → 相手（反応だけ） |
| 口癖・キャラ作りこみ | キャラらしさのセリフ。手の強さは表さない | 演出 |
| 見抜かれる演出 | 相手が自分のクセを読んでくる | 相手が自分を読む（言葉ではない） |

まだ無いのは、**言葉の「中身」で読み合うこと**と、**相手から話しかけられて答えること（双方向）**です。実際のライブポーカーでは、ここがいちばん面白いところです。

- 「どうせ負けてるだろうけど、コール」のような**弱そうに言う人は強い**ことが多い。
- 聞かれてもいないのに自分の手の話をする人は、ブラフのことが多い。
- 強いプレイヤーは「エース持ってるの？」と**質問して、答え方を見る**（ダニエル・ネグラヌの「スピーチプレイ」）。
- 手と手の間の雑談で、相手の機嫌や「あと何時に帰るか」を聞き出しておく。

**お金の話（負けた額・勝った額など）は、どの案でもセリフに入れない（satou、2026-10-09）。**

参考：Zachary Elwood『Verbal Poker Tells』、Mike Caro『Caro's Book of Poker Tells』。

## 案A：言葉そのものがテル（おすすめ・ボタンなし）

テーブルトークの**中身**に意味を持たせます。今は「よくしゃべる＝ブラフ」だけですが、**何を言ったか**で強さが分かるようにします。

| 言い方の種類 | セリフ例 | 多くの人では |
|---|---|---|
| 弱く見せる | 「まあ、たぶん負けてるけど…コール」 | 強い |
| 聞かれてないのに説明する | 「フラッシュ、来ちゃったかもなあ」 | ブラフ |
| 自信を見せつける | 「ほら、早く降りなよ」 | ブラフ |
| 迷ったふり | 「うーん…じゃあ、ベットで」 | 強い |
| 急に丁寧になる | 「失礼、少し上げます」 | 強い |

- キャラごとに「どの言い方が本当で、どれが嘘か」が違う。たとえばセキは教科書どおり、レイカは逆、クロウは第6章で混ぜてくる。
- 読めたセリフは、答え合わせのノート（`noteTell`）に「言葉のクセ」として残る。
- **ボタンも操作も増えない。** 吹き出しを読むだけ。
- 第4章以降とフリープレイだけ意味を持つ（`CFG.tells`）。第1〜3章は今のセリフのまま。
- **ジンは言葉にクセを持たない。** 第7章の本物のテル（顎の傷）だけが答えのまま。

## 案B：話しかけられたら答える（おすすめ・既存の場所を使う）

ときどき、相手から質問されます。答え方を2〜3択で選びます。

- 例：ゲン「なあ、エース持ってるのか？」
  - 黙る（安全。何も読まれない）
  - 「さあね」（はぐらかす）
  - 「持ってるよ」（本当でも嘘でもいい）
- 相手はこちらの**答え方と手の強さ**を覚える（見抜かれる演出の `S.selfMem` と同じ考え）。強いときだけ「持ってるよ」と言っていると、ランクの高い相手には読まれる。
- 逆にうまく使うと、相手が降りたりコールしたりする確率が少し動く（±10%程度）。
- 出るのは**1テーブル数回まで**。選択肢は「揺さぶる」ボタンのあった場所に出すので、**新しい常設ボタンは増えない**。持ち時間内に選ばなければ「黙る」。
- 第4章以降とフリープレイだけ。

## 案C：手と手の間の雑談

ハンドとハンドの間だけ、「揺さぶる」ボタンが「話す」に変わります（ボタンの数は同じ）。

- 相手の今の状態が、言葉から分かる。
  - 「さっきのハンド、まだ頭にきてる」→ 熱くなっていて、ゆるく打つ。
  - 「終電まであと30分」→ 早く勝負したがる。
  - 「今日はカードがよく来るんだ」→ 気が大きくなっていて、コールが増える。
- 本当の状態を言う人と、わざと嘘を言う人がいる（かっこいい系の強いキャラほど嘘がうまい）。
- 常連（`shisho-regular`）のレベルが上がると、雑談が少し打ち解けたものになる。

## 案D：「何持ってた？」と聞く

自分が降りたあと、1テーブル1回だけ「何持ってた？」と聞けます（結果の表示に小さく出す）。

- 正直に見せる人、嘘を言う人、「教えない」と言う人がいる。**誰が正直か**を知ること自体が情報になる。
- 今ある「CPUがブラフを見せる（20%）」と同じ流れに乗せる。
- 小さい案。案Aのあとに足すと、セリフの答え合わせになる。

## 案E：勝負どころの言葉の決闘（台本つき）

第5〜7章の大事な1ハンドだけ、相手との短い会話の場面が入ります。

- 第5章ハヤト：「二代目、コールするのか？　ジンさんなら降りるぜ」→ 3つの返事から選ぶ。
- 第6章クロウ：「拝見しましょう……と言いたいところですが」→ 言葉の中に嘘が混ざる。
- 第7章ジン：「あの夜のこと、覚えてるか」→ 返事で**セリフだけ**変わる。勝ち負けや本物のテルには触れない。
- 物語の山場が、カードだけでなく言葉でも盛り上がる。手間は大きめ（章ごとに台本）。

## おすすめ

**案A → 案B の順。**

- 案Aはボタンが1つも増えず、今のテーブルトークの吹き出しに「読む意味」が生まれます。「会話がテルや読み合いにつながる」にいちばん近い案です。
- 案Bで、はじめて相手と言葉を**やりとり**できます。見抜かれる演出とつながり、「しゃべると自分も読まれる」という本物のライブポーカーの怖さが出ます。
- 案C・Dは小さく足せるので、その次に。案Eは物語の山場づくりとして、余裕があれば。

## 守ること

- ボタンや操作は増やさない。案B・Cは「揺さぶる」の場所を使い回す。
- キャラに胴体を描かない。会話は今の吹き出しと顔アイコンだけ。
- 第1〜3章の難易度は変えない（会話の効果は第4章以降とフリープレイだけ）。
- ジンの本物のテルには触れない。ジンの言葉はテルにしない。
- 平常心は戻さない。
- お金の話（いくら負けた・勝った、など）は会話に入れない。
- 「隣の卓の声」とは重ねない（ここでの会話は、自分の卓の相手との会話だけ）。
- 新しいセリフは英語版の辞書にも足す。
- 入れるときは、いつもどおりスマホ縦・横とPCで画面を確認する（選択肢が吹き出しやボタンに重ならないこと）。

## 実装のめやす（担当：ストーリーモードの企画提案スレッド）

- 案A：`LINES` に言い方の種類（`weak_strong` / `explain_bluff` など）を足し、`afterAct` で手の強さとキャラの「言葉のクセ表」から選ぶ。`noteTell` に言葉のクセを記録。
- 案B：`needleLevel` と同じ出し方で質問を出す。答えは `S.selfMem` に入れ、rank の高い相手の判断に使う。
- 案C：ハンドの間だけ揺さぶるボタンの表示を「話す」に切り替える。相手の隠れた状態（ティルト・帰り時間）を1つ持たせる。
- 案D：降りたあとの結果表示に1回だけのリンク。既存の `shownMem` に正直度を足す。
