# ボタンUX調査（LAST TELL）

調査日：2026-10-08
対象：`story/shisho.html`（公開版 https://satou-aaaaa.github.io/last-tell/ と同じ内容）
方法：コードを読み、ブラウザで実際にフリー対戦を開いて撮影・計測しました（スマホ 390×844 / 375×667、PC 1280×800）。他アプリについてはWeb上の公式ブログ、レビュー、攻略記事を確認しています。出典が見つからなかった点は「未確認」と書いています。

## 1. 結論（優先度順）

| # | 課題 | 重要度 | 改善案の要点 |
|---|---|---|---|
| 1 | **自分の番でもアクションボタンが画面外にある。** 毎ハンド、スクロールが必要 | 最重要 | アクションバーを画面下に固定する |
| 2 | 「揺さぶる」ボタンがフォールドの真上にあり、見た目も目立つ | 高 | アクション列から離し、小さく卓の近くへ移す |
| 3 | レイズは毎回2タップ。よく使う額をワンタップで出せない | 高 | プリフロップは「2.5BB / 3BB」、ポストフロップは「½ / ¾ ポット」を最初から並べる |
| 4 | レイズ欄を開くとボタンの位置がずれ、文字も折り返す | 中 | レイズ欄を上に重ねて開き、確定ボタンの位置を固定する |
| 5 | オールインが確認なしの1タップで決まる | 中 | オールインのときだけ「もう一度押して確定」にする（設定で切り替え可） |
| 6 | 相手の番に何もできない（先行入力がない） | 中 | 「チェック/フォールド」「コールする」の先行入力を用意する |
| 7 | 設定ボタンが小さな丸に崩れ、3行に折り返している | 中 | 歯車アイコンの設定メニューにまとめる |
| 8 | PCでキーボード操作ができない | 低 | F / C / R、数字キーでプリセット、Enterで確定 |
| 9 | 自分の番になったことに気づきにくい | 低 | 番が来たら振動（スマホ）と短い音、ボタンが光る |

すでに良くできている点もあります（第3章）。とくに「チェックできるときはフォールドを押せない」「時間切れはチェック優先、無理ならフォールド」は、大手アプリと同じかそれ以上の作りです。

## 2. 現状の課題（詳細）

### 2-1. アクションボタンが画面の外にある【最重要】
- アクションバー（`.actionbar`）はページの流れの中に置かれていて、画面下に固定されていません。CSSのコメントには「画面下に固定」とありますが、実際には `position:fixed` も `sticky` もありません。
- 自分の番が来ても自動でスクロールしません（`scrollIntoView` などはない）。
- 実測では、自分の番のときボタンの上端は次の位置にありました。
  - iPhone 14 相当（390×844）：上端 853px で、**画面の外**。Safariではアドレスバー分さらに狭くなります。
  - iPhone SE 相当（375×667）：上端 823px で、画面より **約160px 下**。
  - PC（1280×800）：上端 800px で、ちょうど画面の外。
- そのため、毎回スクロールして押し、卓を見るために戻るという往復が起きます。ポーカーはこの操作を1ゲームに何十回も繰り返すので、いちばん効く改善です。
- 他アプリの例：888poker、partypoker、ポーカーチェイスはどれも縦画面で、フォールド/コール/レイズを画面下の親指が届く範囲に固定しています。

### 2-2. 「揺さぶる」がフォールドの真上にある
- 紫色で幅が広く、メインのアクション列のすぐ上にあります（スマホでは幅249×高さ44px）。
- 押すとテーブルトークが起きるだけで、アクションは進みません。それでも位置と目立ち方のせいで「次に押すボタン」に見えてしまい、押し間違えや迷いのもとになります。
- ストラドルの切り替えも同じ列にあります。

### 2-3. レイズが毎回2タップで、よく使う額がすぐ出ない
- 1回目のタップで額の欄が開き、2回目で確定します。開いたときの初期値は、ベットならポットの½、レイズなら今の賭け額の3倍です。
- プリセットは「最小 / ½ポット / ¾ポット / ポット / 全額」です。プリフロップでよく使う **2.5BB・3BB がありません**。
- 他アプリの例：
  - GGPokerは公式ブログで、プリフロップは 2.5x / 3x / 4x、ポストフロップは 33 / 50 / 75 / 100% のプリセットを勧めています。スライダーは「誤操作のもと」なのでプリセットを使うよう書いています。
  - PokerStarsでは、プリフロップ用とポストフロップ用に別々のプリセット（最大4つずつ）を設定できます。
  - ポーカーチェイスでは、ベット額ボタンをプリフロップとポストフロップで別々にカスタムでき、＋−の刻みは0.5BBです。

### 2-4. レイズ欄を開くとボタンの位置がずれる
- 額の欄（高さ約260px）がアクション列の上に差し込まれるので、列全体が下へ動きます。指の下のボタンが動くのは押し間違えのもとです。
- 375〜390px幅で文字が折り返します。
  - 確定ボタンが「6,000 にレイ / ズ」と2行になる
  - 見出しが「いくらにす / る？」と割れる
  - 「残り 94,000」が次の行へ落ちる
- ＋−はBB単位（2,000）で動き、スライダーは1,000刻みです。刻みがそろっていないので、細かく合わせにくくなっています。

### 2-5. オールインに確認がない
- 「全額」を選んで確定、またはコール額が手持ち以上のときの「オールイン」は、1タップで決まります。
- GGPokerは、大きなベットとオールインに確認を出す設定を勧めています。ほかのサービスでも、オールイン確認を求める声が多くあります。
- ストーリーの大事な勝負で誤タップによるオールインが起きると、取り返しがつきません。

### 2-6. 先行入力（プリアクション）がない
- 相手の番には「○○の番です」と表示されるだけで、ボタンは隠れます（`acts.hidden`）。
- PokerStars、888poker、GGPokerには「チェック/フォールド」「どんなベットにもフォールド」などの先行入力があります。
- このゲームはCPUの考える時間が短いので必須ではありませんが、演出の速さを「ふつう」にしているときに待ち時間が気になる人には効きます。
- ボタンの出し入れでバーの高さが変わるのも、位置ずれの一因です。

### 2-7. 設定ボタンが崩れている
- 「手札：めくって見る」「音：オフ」「演出の速さ：ふつう」「立体：オン」「持ち時間：あり」の5つが角丸のピルボタンとして並んでいます。スマホでは幅47〜71pxに縮み、2〜3行に折り返して丸いかたまりに見えます（[スマホ_全体.png](ボタンUX画像/スマホ_全体.png) の最下部）。
- オン/オフの状態が文字でしか分からず、押すと何が変わるのかも分かりにくいです。

### 2-8. PCでキーボード操作ができない
- キー操作は会話の送り（Enter / Space）と手札めくりだけで、アクション用のショートカットはありません。
- PokerStarsやGGPokerにはホットキー設定があります。PCで遊ぶ人には便利です。

### 2-9. 自分の番の合図が弱い
- 振動は持ち時間の残りが少ないときだけです（`navigator.vibrate(25)`）。
- 番が来たときの音や光の合図はありません。ボタンが画面外にあることと合わさって、気づきにくくなっています。

## 3. すでに良い点（残すべきもの）

- **チェックできるときはフォールドが押せない。** さらに「チェックできます」と表示しています。PokerStarsは2016年に同じ理由でフォールドボタンを消しました。
- **時間切れの扱いが安全。** チェックできればチェック、できなければフォールドになります。第1〜3章は時間切れでもジンが声をかけるだけです。ポーカーチェイスには「時間切れでコール扱いになった」という不満があるので、ここは勝っています。
- **ボタンに金額が出る。** 「コール 2,000」「6,000 にレイズ」と表示し、ベットとレイズの言葉も状況で切り替えています。
- **並びと色が業界の定番どおり。** 左からフォールド（グレー）、コール（緑）、レイズ（赤）です。ボタン本体も58px（スマホ54px）と押しやすい高さです。
- **プリセットに金額が併記されている。** 「½ポット 6,000」のように出ます。
- **キーボードで操作したときにフォーカス枠が出て、動きを減らす設定（`prefers-reduced-motion`）にも対応している。**

## 4. 改善案

### 案A：アクションバーを画面下に固定する（課題1、2-4）
- `#controls` と `#between` を `position:sticky; bottom:0`（または fixed）にし、`padding-bottom:env(safe-area-inset-bottom)` でiPhoneのホームバーを避けます。
- 卓の下に、バーと同じ高さの余白を入れて重なりを防ぎます。
- 相手の番もバーの高さを変えず、ボタンは消さずに無効表示にするか、先行入力ボタンに置き換えます（案E）。
- これで、卓を見たまま親指だけで遊べるようになります。

### 案B：アクション列の外へ「揺さぶる」を移す（課題2）
- 卓の自分の席の近くに、小さな吹き出しアイコン（💬）として置きます。または、アクション列の上ではなく横に、細いサブボタンとして置きます。
- 色は紫のまま、サイズと明るさを落とします。そうすれば「主役はフォールド/コール/レイズ」が一目で分かります。
- ストラドルの切り替えも同じ扱いにします。

### 案C：よく使う額をワンタップで（課題3）
- レイズ欄を開かなくても、アクション列のすぐ上に **クイックベット** を3つ並べます。
  - プリフロップ：「2.5BB」「3BB」「4BB」
  - ポストフロップ：「⅓」「½」「¾」ポット
  - 押すと、その額のレイズがボタンに表示されます（例：「6,000 にレイズ」）。もう1回で確定です。合わせて2タップですが、額を探す手間がなくなります。
- 細かく決めたい人向けに、今のスライダーと＋−も残します。＋−の刻みはBBの½にし、スライダーの刻みとそろえます。
- 余裕があれば、プリセットを設定で変えられるようにします（GGPoker、PokerStars、ポーカーチェイスと同じ方式）。

### 案D：ボタン位置を動かさない、文字を割らない（課題4）
- レイズ欄は、アクション列の上に重ねて表示します（オーバーレイ）。確定ボタンは、元のレイズボタンと同じ位置から動かしません。
- ボタンの文字は「レイズ」と「6,000」の2段に分け、折り返さないようにします。見出しは「いくらにする？」の短い形にし、「今の賭け 2,000」は小さい補足に回します。

### 案E：先行入力（課題6）
- 相手の番に、次の2つをトグルで出します。
  - 「チェック/フォールド」（チェックできればチェック、ベットされたらフォールド）
  - 「コール（○○まで）」（額が変わったら自動で解除）
- 自分の番が来たら、選ばれていた行動をすぐ実行します。
- ストーリーの序盤（第1〜3章）は、覚えることを増やさないために出さなくてもよいです。

### 案F：オールイン確認（課題5）
- オールインになるときだけ、ボタンが金色に変わって「もう一度押してオールイン」と表示します。3秒で元に戻ります。ポップアップは出さず、2タップで済ませます。
- 設定でオフにできるようにします。

### 案G：設定をまとめる（課題7）
- 右上の「やめる」の隣に歯車ボタンを置き、開くとトグルスイッチの一覧が出るようにします。
- 各項目には、何が変わるかの一言を添えます（例：「立体：画面を傾けると卓が動く」）。

### 案H：PCショートカット（課題8）
- F＝フォールド、C/Space＝チェック・コール、R＝レイズ欄を開く、1〜5＝プリセット、↑↓＝額の増減、Enter＝確定、Esc＝レイズ欄を閉じる。
- ボタンの隅に小さくキー名を表示します（PCのときだけ）。

### 案I：番が来た合図（課題9）
- 自分の番になったら、アクション列が一度だけ光り、短い音とスマホの軽い振動（15ms程度）を出します。音と振動は既存の音設定に従います。
- ボタンを押したときにも、ごく短い振動を出します（対応端末のみ）。

---

## 5. おすすめの進め方

1. **まず案A（画面下に固定）と案B（揺さぶるの移動）。** 体感がいちばん大きく変わり、作業も小さめです。
2. 次に案C（クイックベット）、案D（位置固定と文字の整理）、案F（オールイン確認）。レイズまわりを一度に直すと効率的です。
3. 余裕があれば案G（設定まとめ）、案E（先行入力）、案H（PCショートカット）、案I（番が来た合図）。

注意：第1〜3章の難易度とロジックには触れません。どれも見た目と操作だけの変更です。
