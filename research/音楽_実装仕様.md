# 音楽 案A 実装仕様（2026-10-10 satou 決定）

決定：案A「場面で変わる音楽をコードで作る」（2026-10-10 satou「Aでお願いします」）。
提案：research/音楽の提案.md　見本（音のコードの元）：research/音楽_見本.html　https://claude.ai/artifact/DL7XfXopkCA7QpCgGLj9q3

## 0. 守ること
- 音源ファイルは使わない。すべて WebAudio で鳴らす（権利の心配なし、容量ほぼ0）。
- 音楽の場面切り替えは**見えている情報だけ**で決める。伏せたカードの強さ、CPUのテル（特に第7章のジンの release）と音楽を連動させない。音がヒントにならないように。
- 第1〜3章の難しさは変えない（音だけの変更なので勝敗の処理には触れない）。
- 「夜」を名前に使わない。台詞は追加しない。
- 画面のボタンは増やさない。

## 1. 置き換えるもの
shisho.html の `const Sound=(()=>{...})()`（4327行付近）の中身。外から呼ばれている名前はそのまま残す：
`sfx(kind)`, `hush(on)`, `murmur(loud)`, `heart()`, `thud()`, `bgm(n)`, `stop()`, `pause()`, `resume()`、`window.Sound`、`visibilitychange`。

中身は見本の `<script>` をほぼそのまま移す：
- 楽器：`epiano` `piano` `bass` `ride` `brush` `hat` `kick` `clank` `pad` `horn` `box` `heart` `chip`
- 楽器ごとのバス（drums/bass/keys/pad/lead/fx）と部屋の響き（Convolver）、Compressor
- 先読みスケジューラ（25msごとに0.15秒先まで8分音符単位で予約、スイング付き）
- 主題 `MOTIF`（ジンのメロディ）
- 既存の効果音（chip/card/turn/win、hush 中のチップいじり、murmur、thud）は今の音をそのまま残す。

## 2. 店ごとの曲（`bgm` 番号 → 曲）
`bgm(n)` の n は今の `CH` の番号のまま使う。

| n | 店 | 曲の形（見本の設定を元に） |
|---|---|---|
| 0 | フリー対戦（店なし） | 月影の形を少し遅く（bpm 112）、key +1 |
| 1 | 錨亭 | 見本の anchor（ブラシ、ゆっくり、エレピ）。8小節ごとに主題を薄く |
| 2 | 銀の扉 | anchor の形でエレピをピアノに、ドラムはブラシを半分の量、key +2、bpm 76 |
| 3 | 月影 | 見本の moon（速いスイング、ウォーキングベース、ライド） |
| 4 | 天空（ホテルのラウンジ） | crown の形を明るく：コード進行を長調（Dmaj9–Bm9–Gmaj9–A13 相当）、ピアノ、パッド、bpm 90 |
| 5 | 地下の賭場跡 | 見本の under（キック、金属音、暗いうなり） |
| 6 | 王冠 | 見本の crown（ピアノ、弦のパッド、まっすぐな拍） |
| 7 | 錨亭、閉店後（第7章） | 見本の「ジンの主題」（主題をはっきり鳴らす）。ブラシだけ |

- 回想（`startFlashback`、今は bgm:6）：見本の「回想（オルゴール）」。`bgm('memory')` のように文字列でも受けられるようにする。
- クロウが出る場面（第6章）の終盤レベルや対決の手：見本の「クロウ」の形（主題を半音下げて暗い金管）を使ってよい。どこで切り替えるかはゲーム担当の判断で。
- 第二部などで新しい店が増えたら、表に1行足す。番号に曲がないときは 0 の曲を鳴らす。

## 3. 場面で音楽を変える（`setMood(m)` を追加）
楽器のバスの音量を1.2秒かけて変える（ブツッと切らない）。

| mood | いつ | 鳴り方 |
|---|---|---|
| normal | 手の始め（4427行の `Sound.hush(false)` の隣） | 全部 |
| calm | 自分の番で考えている間 | ドラムをかなり小さく、和音は1拍目だけ |
| tension | CPUが大きく賭けて黙り込む時（4631行の `Sound.hush(true)` の場所）、自分が大きく賭けられた時 | ドラムは足のハイハットだけ、ベースは同じ音を8分で刻む、不安な和音を伸ばす、2小節ごとに鼓動 |
| allin | オールインで残りのカードをめくる時（4596行の `S.runout=true`） | 楽器は全部止めて、低いうなりと鼓動だけ。鼓動はだんだん速く |

- 今の `hush(true)` は「BGMを止めてチップの音だけ」。これを `setMood('tension')` に置き換え、チップいじりの音は残す。`hush(false)` は normal に戻す。
- 結果の音：手が終わった時、自分が勝ったら見本の「勝った」（主題の頭を明るく）、大きなポットで負けたら「負けた」。小さいポットは今の `sfx('win')` / `sfx('chip')` のままでよい（毎手鳴ると、うるさいので）。結果の音の後は normal に戻す。
- 6人卓などCPU同士の手でも mood は同じルールで変わる（見えている情報だけ）。

## 4. 音の設定
- 今の「音：オン／オフ」ボタンを「音：オフ → 効果音だけ → すべて」の3段階に（ボタンは増やさない）。`SETTINGS.sound` を `0|1|2` にし、古い保存の `true` は 2、`false` は 0 として読む。
- 最初はオフのまま（今と同じ）。
- 音量は今より大きくなるので、master は見本と同じく Compressor を通す。

## 5. 止める・再開
- `pause()`／`resume()`、`visibilitychange`、`showInterstitial` での停止は今と同じ動き。スケジューラの `setInterval` も止め、再開時は小節の頭から。
- `show()` で game 以外の画面に行くと `Sound.stop()`（今と同じ）。うなり（allin）も止める。

## 6. 確認
- 自動プレイで第1〜7章とフリー対戦を回し、エラーが出ないこと、勝敗の結果が変わらないこと。
- 各店で音が出ること（Analyser でピーク0.9未満、無音でない）。tension／allin／結果の音の切り替え。
- スマホ縦・横とPCで画面確認（ボタンの文字「音：効果音だけ」がはみ出さないこと）。
- 裏に回して戻ったとき、音が二重にならないこと。
