# プロのゲームクリエイター目線で LAST TELL を見る（2026-10-10）

対象: `story/shisho.html`（v60）。ゲーム本体は編集していません。
やったこと: プロが共通して見る観点を調べ、そのうえで「初めて遊ぶ人」として最初の1手までを実際に操作して数えました（スマホ縦 390×844、セーブなしの状態）。画像は [プロ目線画像/](プロ目線画像/) にあります。

---

## 1. 結論

1. **中身の量はもう十分。足りないのは「最初の5分」と「削る判断」。** 保存している仕組みが22種類あり、さらに掛け合い・音楽・第4弾の5要素・主人公まわりが控えています。プロがまず止めるのは「新しく足す」ことより「初めての人が迷わず面白さに届くか」です。
2. **今は、最初に自分で判断するまでに約22回タップして文章を読む必要がある。** 会話15画面 → VS画面 → 操作説明5ページ。プロの目安は「1分以内、数タップで最初の判断」です。
3. **スマホでは途中から再開できない。** 章の途中で再読み込みするとタイトルに戻りました（下で確認方法を記載）。スマホは裏に回すとアプリが落とされることが多く、プロが必ず確認する点です。
4. **「遊んでもらって黙って見る」テストがまだない。** テスト計画（launch/テストプレイ計画.md）はストア審査を通すためのもので、どこで迷い・やめるかを見る段取りは入っていません。

## 2. プロが見る観点（調べた内容）

| # | 観点 | プロが見ていること |
|---|---|---|
| 1 | **コンセプトと柱（ピラー）** | 「このゲームは〇〇」と一言で言えるか。すべての機能がその一言に奉仕しているか。柱に合わない機能は、よくできていても削る（kill your darlings）。 |
| 2 | **最初の5分（FTUE）** | 最初の判断までの時間とタップ数。説明は読ませず、遊びながら1つずつ教える。スマホゲームは最初の数分で多くの人がやめる。 |
| 3 | **コアループと手触り** | いちばん繰り返す操作（ここでは1ハンド）が、それ単体で気持ちいいか。押した瞬間の反応、音、振動、間（ま）。 |
| 4 | **リスクとリターン／緊張と緩和** | 桜井政博さんがくり返し話している考え方。危ない選択ほど見返りが大きく、張り詰めた後に必ずゆるむ時間があること。 |
| 5 | **学ばせ方の段階** | 「教える → 安全に試させる → ひねって出す」の順。新しい要素は1回に1つ。 |
| 6 | **画面の読みやすさ** | 今いちばん大事な情報（相手の顔、自分の手、押すボタン）が一目でわかるか。説明や吹き出しがそれを隠していないか。 |
| 7 | **スコープ管理** | 機能が増えるほど、テスト・UI・翻訳・不具合の量が掛け算で増える。リリース前は「機能凍結」して磨く期間を取るのが普通。 |
| 8 | **プレイテストと数字** | 作った人以外に遊んでもらい、口を出さずに見る。どこで止まり、どこで笑い、どこでやめたか。数字（どの章で離れたか）も取る。 |
| 9 | **やめどころと再開** | 1回の遊びが何分か。キリのいい所でやめられ、次に開いたら続きからすぐ遊べるか。 |
| 10 | **公正感** | カードゲームでは「CPUがズルしている」と感じた瞬間に人は離れる。仕込んだ展開は、仕込みだと分かる見せ方にする。 |
| 11 | **5秒で伝わるか** | ストアの1枚目の画像と最初の画面だけで、何が面白いゲームか伝わるか。 |

出典は末尾にまとめました。

## 3. LAST TELL に当てはめた診断

### よくできている点（プロが評価するところ）
- **一言で言える核がある。** 「老いた師匠に教わりながら、相手のクセ（テル）を読んで街のクラブを制する」。題名とも一致している。
- **ストーリーと遊びが結びついている。** 第1章の「降りるのも勝負」がそのまま最初に覚えるべき戦い方になっている。第7章の本物のテルが物語の答えになっている。
- **第1章からテルの予告がある。** ジンの「ゲンは顔に出る。いい手が来ると、すぐにニヤける」で、題名の面白さを第1章から匂わせている。
- **見た目の方向が一貫している。** 暗い港町、赤と金、クールな文字。

### 気になる点（実際に操作して確認したもの）

**A. 最初の1手までが長い**（画像 [3](プロ目線画像/3_VS画面_15タップ後.png)、[4](プロ目線画像/4_最初の1手_説明5ページ.png)）
- 「ストーリー」→「はじめる」→ 会話15画面 → VS画面 →「勝負開始」→ 操作説明 1/5〜5/5 → やっと最初の判断。
- 操作説明の吹き出しが画面上部にかぶり、相手の顔が隠れている。
- 会話の中身はよい（裏返しの写真、削られた看板などの伏線）。問題は量ではなく「全部を遊ぶ前に読ませている」順番。

**B. タイトル画面に情報が多い**（画像 [1](プロ目線画像/1_タイトル.png)）
- 最初に目に入るのが「実際のお金を賭けることを勧めるものではありません」の注意書き。
- フリー対戦の「店ルール」「人数」「感じの悪い客」の設定がタイトルに並んでいる。初めての人には意味がわからない。
- 「その他」の中に設定・引き継ぎ・バックアップ・規約が10項目並ぶ。

**C. 途中から再開できない**
- 第1章の最初のハンドで再読み込み → タイトル画面に戻った。「続きから」のボタンもない。
- スマホアプリ化（Capacitor）後は、電話や他のアプリで裏に回すだけで消えることがある。

**D. 機能の量が「初めての人」に一度に見える**
- 保存している仕組み: 22種類（`shisho-` で始まるキー）。テーブル画面にも「役の一覧」「ハンドの記録」「相手メモ」「ベット額の候補3つ」などが最初から並ぶ。
- 今後: 掛け合い239組、音楽、第4弾の5要素、主人公の名前・見た目。決まった内容はどれも良いが、全部が同時に見えると「何をすればいいゲームか」がぼやける。

**E. 遊んでもらって見る段取りと、数字がない**
- 外部の解析は入っていない（`analytics` は注意書きの文言だけ）。どの章で人がやめているかが分からない。
- テスト計画は「12人×14日」を通すためのもので、観察の手順はない。

**F. 公正感（第5章の仕込みのバッドビート）**
- AA が負ける場面は物語として強いが、ポーカーアプリの利用者は「乱数が操作されている」という疑いに敏感。仕込みであることを物語の中ではっきり見せ、ストーリー以外では絶対に乱数を操作しないと書いておくのが安全。

## 4. 改善点（優先度つき）

ルールは守ります: 第1〜3章の難しさは変えない／名前に「夜」を使わない／会話にお金の話を入れない／チップを現金で売らない。

### 優先度 S（リリース前にやる。効果が大きく、作業は小さめ）

| # | 改善 | 具体的に |
|---|---|---|
| S1 | **最初の判断まで5タップ・60秒以内にする** | 第1章の冒頭は「雨の港の1行 → ゲンの1行 → ジンの『負け方が下手だな』」の3画面だけにして、すぐ配る。残りの会話（写真、看板、店主の一言、ハンドの選び方）は、1ハンド目・2ハンド目の合間に1つずつ出す。会話の中身は消さず、順番だけ変える。 |
| S2 | **操作説明を「その場で1つずつ」にする** | 5ページの説明をまとめて出さず、初めてその操作が必要になった瞬間に1行だけ出す（例: 初めて自分の番 →「降りるか、払って続けるか」だけ）。相手の顔は隠さない位置に出す。 |
| S3 | **途中から再開できるようにする** | 1ハンド終わるごとに章の状態（チップ、何ハンド目か、会話の進み）を保存し、タイトルに「続きから」を出す。ハンドの途中で落ちたら、そのハンドの最初からやり直し。 |
| S4 | **外部テストに「黙って見る」回を入れる** | 既存のテストプレイ計画に、知り合い3〜5人に画面を見ながら遊んでもらう回を足す。口を出さず「どこで止まったか」「どこで声が出たか」「いつやめたか」をメモする。アンケートより先にやる。 |

### 優先度 A（リリース前にやりたい）

| # | 改善 | 具体的に |
|---|---|---|
| A1 | **機能を「段階的に見せる」** | 初めての人には、使う章が来るまでボタンや設定を見せない。例: 相手メモ・揺さぶるは第4章から、ハンドの記録は第1章クリア後、フリー対戦の店ルールは該当の店に行ってから。既にある機能を消すのではなく、出てくる順を決めるだけ。 |
| A2 | **タイトル画面を3つのボタンだけにする** | 「ストーリー（続きから）」「フリー対戦」「その他」。注意書きは初回だけ1回出して、その後は「その他」の中へ。フリー対戦の設定はフリー対戦を押した後の画面へ。 |
| A3 | **柱（ピラー）を3つ決めて、控えている機能をそれで並べ替える** | 案: ①テルを読む ②師匠と弟子の物語 ③ライブの空気。第4弾の5要素・掛け合い・音楽を、どの柱を強くするかで並べ、柱に効くものから入れる。決定済みの内容は止めない。順番の決め方だけ変える。 |
| A4 | **リリース前に「機能凍結」の期間を取る** | どこかの版で新機能の追加を止め、不具合・見た目のずれ・文章の直しだけをやる期間を作る。今見えている 375幅6人卓のチップ重なりなどはここで片付ける。 |
| A5 | **テルを読めた瞬間を一番気持ちよくする** | ゲームの核なので、ここに演出を集中させる。読みが当たった瞬間の音、短い間（ま）、ジンの一言、振動。既にある「見えた」演出をこの1点に寄せる。 |
| A6 | **仕込みの展開を公正に見せる** | 第5章のバッドビートの直後に、そのときの勝率（例「この時点であなたの勝率は約80%」）を見せ、ジンに「それがポーカーだ」と言わせる。フリー対戦と第1〜4章は乱数を操作していないことを「遊び方」に1行書く。 |

### 優先度 B（リリース後でもよい）

| # | 改善 | 具体的に |
|---|---|---|
| B1 | **やめた場所が分かる最小限の記録** | 外部の解析を入れる前に、端末の中だけで「どの章まで進んだか・何回負けたか」を記録し、テスターに引き継ぎコードと一緒に送ってもらう形にする。外部送信を入れるならプライバシーポリシーの更新が必要。 |
| B2 | **1回の遊びの長さを測って整える** | 1章が何分かを実測し、スマホで1回に遊ぶ長さ（目安5〜10分）を超える章には途中の区切り（休憩の会話）を入れる。 |
| B3 | **ストアの1枚目で核を伝える** | 「相手のクセを読め」が5秒で伝わる1枚（ジンの顔＋相手のテルの表示）を1枚目にする。launch/store_images の並びを見直す。 |
| B4 | **読みやすさの選択肢** | 文字サイズ（大）、スートを4色にする選択肢、片手で届く位置のボタン。世界向けに出すなら効果が大きい。 |
| B5 | **第3部以降より、第1部の磨き込みを先にする** | 長編の計画（弟子→師匠→外海→最初の看板）は良いが、最初の数章で離れた人は第2部に届かない。新しい部より第1部の最初の30分に手間をかける。 |

---

## 5. おすすめの進め方

1. **S1〜S3**（最初の5分と続きから）をゲーム担当のスレッドに先に入れる。今の予定（掛け合い → 音楽 → 第4弾）の前か、掛け合いの次。
2. 入ったら **S4** の「黙って見る」テストを知り合い数人で行う。
3. テストの結果で **A3**（柱で並べ替え）をして、第4弾の5要素のうちどれから入れるかを決め直す。

## 6. 確認方法（再現手順）

- Playwright でセーブなしの状態から開き、Google Fonts を止めた状態で「ストーリー」→「はじめる」→「次へ」を押し続け、フォールド/チェックのボタンが出るまでを数えた: 会話15画面＋VS画面＋操作説明5ページ。
- 最初のハンドが表示された状態で再読み込み → タイトル画面に戻ることを確認（「続きから」なし）。
- コード検索: 保存キー `shisho-*` が22種類。外部解析のコードなし。
