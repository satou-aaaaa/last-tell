## 全体の決まり

- 第1〜3章の勝ち負け・難しさは変えない。第7章のジンの本物のテル（release）には触れない。第7章の勝負中は、どの新要素も出さない。
- タイトル画面のボタンは増やさない。置き場所は「卓を立ったあと」「ジンのノート」「章を選ぶ画面」「その他」に限る。
- 名前に「夜」を使わない。セリフにお金の話を入れない（チップの額を「勝った・負けた」と話すのも避ける）。チップや景品を売らない。ご褒美は見た目と会話だけ。
- 新しい保存キーは shisho- で始め、`v:1` を入れ、引き継ぎコード・セーブファイルの対象リスト（3908行目付近の配列）に足す。
- 英語版：新しい日本語の文はすべて EN_DICT に足す。
- 毎回の変更で、自動対戦（fuzz）と画面チェック（390×844、844×390、1280×800、375×667）をする。

## おすすめの実装順

1 → 2 → 3 → 4 → 5（1と2は同じデータを使う。3〜5は独立）。リリース前に1と2、ほかはリリース後の更新でもよい。

## 案1 打ち方カルテ

### データ（新キー `shisho-karte`）
`shisho-style`（第二部用）はそのまま残す。カルテ用に、すべての卓（ストーリー・店・フリー・裏の卓・はしご）を数える別の記録を作る。数えないもの：`S.autoMe`、`S.scriptAI`、`CFG.flashback`、影と打つの卓（案2）、観戦（案4）。

```js
{v:1,
 hands, vpip, pfr, raises, calls,          // 入り方・攻め方
 foldSt:{pre,flop,turn,river},              // どの街で降りたか（賭けられて降りた回だけ）
 sd, shown, mucked,                         // ショーダウンに行った回／見せた／伏せた（自分が勝って見せないで済んだ回は数えない）
 byCh:{"1":{h,vpip,pfr,fRiver,fAll}, ...}   // 章ごとのまとめ（ストーリーのみ、第二部は "p2-1" など）
}
```
- 数え方は `shisho-style` の `act`／`endHand` のラップ（3432〜3445行目付近）と同じ形で、もう一つラップを足す。`raises`／`calls` はポストフロップも含めた自分の行動の回数。
- 見せた・伏せた：既存の show/muck の選択（btnShowYes/btnShowNo、`muck` 設定）の結果から数える。

### 4本の目盛り（0〜100 に直す）
| 目盛り | 左 → 右 | 計算 |
|---|---|---|
| 入り方 | かたい → ゆるい | vpip/hands を 10%→0、60%→100 で直線 |
| 攻め方 | 受ける → 押す | raises/(raises+calls) を 0.15→0、0.6→100 |
| 降りどころ | 早い → 最後まで | (turn+river の降り)/(全部の降り) を 0.1→0、0.6→100 |
| 見せ方 | 隠す → 見せる | shown/(shown+mucked) をそのまま |
- 20ハンドに満たない目盛りは「記録中（あと○ハンド）」と出し、点を置かない。

### 型の名前（常連から借りる。8つ）
目盛りの組み合わせで1つ選ぶ（上から順に当てはまったもの）。
| 条件 | 名前 | 一言 |
|---|---|---|
| 入り方≥65 かつ 攻め方≤40 | ゲン型 | 引きを追う |
| 入り方≥65 かつ 攻め方≥60 | ゴウ型 | 押して押す |
| 入り方≤35 かつ 攻め方≥60 | レイカ型 | 少なく、鋭く |
| 入り方≤35 かつ 攻め方≤40 | ハル型 | 待って待つ |
| 降りどころ≥65 | セキ型 | 最後に降りる |
| 降りどころ≤25 | ロク型 | 早く見切る |
| 見せ方≥70 | ミナ型 | 手の内を見せる |
| どれでもない | ジン型 | まっすぐ打つ |
（ジン型は、ジンの名前を使うのでジンのセリフで「……俺の真似か」と一度だけ反応させる。名前は PROFILE にいる人物だけを使う。登場前の人物の型は「？？？型」と伏せる。）

### ジンの一言（20行ほど）
前回のカルテと比べて、いちばん動いた目盛りについて言う。例：
- 降りどころが早くなった：「降りるのが早くなったな。悪くない」
- 入り方がゆるくなった：「入る手が増えたな。全部、意味のある手か？」
- 変化なし：「……変わらないのも、一つの打ち方だ」
- 第二部（P2ON）では話し手を師匠（mentorName）にし、タロウのカルテとして同じ画面を出す。

### 画面
1. **卓を立ったあと**：既存の「ジンの三行」の箱（btnQuit のレビュー、5931行目付近、章クリア時の S.review の表示）の下に、小さなカルテ（型の名前＋4本＋ジンの一言）を足す。新ボタンなし。
2. **ジンのノート**：タブに「打ち方」を足す（tabs 配列、3564行目付近）。大きなカルテ、章ごとの「降りどころ」の折れ線（byCh）、「画像にする」ボタン（既存の `shareImage` を使う。チップの額は描かない）。
3. 第7章の勝負中は出さない（クリア後のノートでは見られる）。

### テスト
- 20ハンド未満で「記録中」が出る。古いセーブ（shisho-karte 無し）で壊れない。
- 第二部 p2Init が `shisho-style` だけを読んでいることを確認（カルテが第二部の師匠の型を変えない）。

## 案2 影と打つ

### 打ち方コード
- カルテの4本（各0〜100を 0〜31 の5ビットに丸める）＋ハンド数の段階（3ビット）＋呼び名（`nick()`、8文字まで）を、短い文字列にする。
- 形：`LT` ＋ 4本と段階を Crockford Base32 で8文字 ＋ `-` ＋ 呼び名を UTF-8 → base64url。チェック用に1文字足す。例：`LT7Q4KM2RA-44K144Ld`。
- 読むとき：チェック文字が合わない、形が違う → 「コードが読めませんでした。もう一度コピーしてください」。
- 呼び名は表示前に、記号と空白を消し、8文字で切る。空なら「名無しの影」。

### 置き場所（ボタンは「その他」の中だけ）
「その他」に「影と打つ」のまとまりを足す。
- 「自分の打ち方コードを出す」：コードとカルテの小さな絵。コピー（既存の引き継ぎコードと同じやり方）と「画像にする」。カルテが20ハンド未満なら「もう少し打つとコードが出せます」。
- 「影を呼ぶ」：コードを貼る欄 → 読めたら、影のカルテを見せて「この影と打つ」。

### 影の卓
- `startFree` と同じ形の4人卓。席は「あなた」「影：〈呼び名〉」と、freeSeats から2人。`CFG.shadow={code,name,axes}`。
- 影の打ち方：STYLES に動的な `shadow` を作る（normal を元に）。
  - 入り方 → `margin`（ゆるいほど低く、-0.10〜+0.10）と `loose`（入り方≥65 で true）
  - 攻め方 → `bluff`（0.02〜0.20）と `midP`（0.30〜0.50）
  - 降りどころ → `defPost`（早いほど 1.2、最後までほど 0）
  - 見せ方 → ショーダウン後に勝って見せるかの確率（既存の CPU の show/muck 処理に渡す）
- 影には絵を出さない（シルエット。第二部の師匠のシルエットと同じ `filter:brightness(0)` のやり方）。テル・穴・マナー・掛け合いは無し。
- 自分の記録（カルテ・称号・星）は数えない。
- 終わり方：どちらかが0になるか、50ハンドで多いほうの勝ち。
- 勝つと「影を越えた」と結果コード（`W` ＋ 自分のコードの先頭6文字 ＋ ハンド数）。「画像にする」で共有。称号「影を越えた」を1つ足す。

### テスト
- コードを作る → 読むで同じ4本に戻る。壊れたコード、空、長すぎるコードで落ちない。
- 影の目盛りが極端（0や100）でも fuzz で止まらない。

## 案3 週替わりの卓（港の掲示板）

### 週の決め方
`dayNo(todayKey())` を使い、`Math.floor((d+3)/7)`（月曜はじまり）を週番号にして、8種類を順番に回す。サーバーは使わない。

### 8種類（すべて既存のハウスルールと設定の組み合わせ）
| id | 名前 | 中身 |
|---|---|---|
| straddle | 全員ストラドルの週 | house:'straddle'、CPUも毎回ストラドル |
| turbo | 短い勝負の週 | 10ハンドごとにブラインドが上がる（第6章の上げ方を流用） |
| bomb | ボムポットの週 | house:'bomb' |
| seven2 | 7-2の週 | house:'seven2' |
| twice | 2回めくりの週 | house:'twice' |
| photo | 記念写真の週 | ショーダウンで見せるたびに名場面に1枚残る |
| pair | 常連2人の週 | 掛け合いの多い2人（キャラ同士の掛け合いの組から選ぶ）を同じ卓に |
| patience | 待てる者の週 | 課題が「降りる」中心 |

### 課題（毎週3つ、見本の「全員ストラドル」の例のような形）
- 種類ごとに3つ決めておく（例：straddle「ストラドルに3回レイズで返す」「一度もポットを諦めずに卓を終える」「最後まで残る」）。
- 3つそろうと、見た目のご褒美を1つ：カードの裏柄（新しく4種類）かプロテクター（新しく4種類）。8週で全部そろう。
- 保存：`shisho-weekly` `{v:1,week,done:[0,0,0],got:[ids]}`。週が変わったら done を戻す。

### 置き場所
- 「章を選ぶ」画面のいちばん上に「錨亭の掲示板」の紙を1枚（第1章クリア後から）。紙に今週の名前と課題3つ、「この卓で遊ぶ」。
- カードの裏柄は、設定にプロテクターと同じ形の選択を足す（`SETTINGS.back`）。`.card.back` の模様だけ差し替える。

### テスト
- 端末の日付を変えて8週ぶん回す。週をまたいで遊び途中でも落ちない（卓が終わったときの週で判定）。

## 案4 後ろから見る（ジンと観戦）

### 開き方
- 第2章クリア後、「章を選ぶ」の各店（クリア済み）に「後ろから見る」を足す（既存の「この店で遊ぶ」「会話を見る」の並び）。第7章の店（ジンがいる卓）には出さない。

### 中身
- その店の常連3人の卓を、プレイヤーは打たずに見る。`startGame` に `CFG.rail=true`。席0は人間ではなく、その店の常連（`S.autoMe` と同じ AI で打たせる。名前と絵はその常連）。
- 全員の手札は伏せたまま。ショーダウンでだけ開く。
- 1回の観戦は3ハンド。
- ジンのささやき：各ハンドの大事なところ（大きな賭け、テルが出た、穴が出た）で1行。既存の TELLS・LEAKS の文言から作る（例：「ハルが迷ってる。押されると弱いぞ」）。第1〜3章の店では、テルや穴の答えそのものは言わない（「あいつの顔、よく見ておけ」程度）。
- 「次どうする？」：各ハンドで1回、CPUが大きな賭けに向き合ったところで止め、「降りる・コール・レイズ」から当てる。当たると、その人の相手メモ（shisho-notes）に1行。外れても何もなし。
- ジンは自分のクセの話をしない。
- 称号「よく見ている」：当てた回数が10回。

### 守ること
- 記録（カルテ・style・星）は数えない。
- 速さ設定（SPEED）に合わせる。「スキップ」で次のハンドへ。

### テスト
- 7店ぶん各1回、止まらずに3ハンド終わる。止まる場面でボタンが画面の外に出ない。

## 案5 ディーラー見習い（店の手伝い）

### 開き方
- 第1章クリア後、章のおわりの場面（outro）のあとに、錨亭の店主が一度だけ「ちょっと手伝ってくれ」と声をかける（断れる）。
- その後は「章を選ぶ」の第1章の店に「店を手伝う」。

### 3つの遊び（1回30秒、各5問）
1. **ポットを数える**：チップの山（既存の STACK_DENOMS と描き方を使う）を見せ、合計を3択から選ぶ。
2. **勝った人を当てる**：場5枚と、2〜3人の手札。勝った人を選ぶ（bestN で答えを出す）。引き分けもある。
3. **ポットを分ける**：オールインが2人いる場面で、メインポットとサイドポットの額を3択から選ぶ。答えは、各人の出した額（total）を小さい順に重ねる普通の分け方で出す。

### ご褒美
- 3つとも全問正解すると、店主とディーラーの短い会話が1つずつ開く（全部で6つ）。
- 称号「店の手伝い」。チップは出さない。

### 守ること
- 時間切れでも罰はない。「やめる」でいつでも戻れる。
- 第7章の前後の場面には割り込まない。

### テスト
- 3つの遊びの答えが、ゲームの判定（bestN と実際の配り方）と一致することを、ランダム1000問で確かめる。
