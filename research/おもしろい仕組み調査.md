# おもしろい仕組み 調査と提案（2026-10-09）

LAST TELL に、まだ入っていない「遊びの仕組み」を足す案です。
すでにあるもの（テル、揺さぶる、テーブルトーク、ハウスルール、ディーラー、マナーの悪い客、見せる/伏せる、席選び、カウント、フロアクイズ、常連、今日の1ハンド、名場面画像、オールイン勝率、ジンのノート、回想、後日談、称号、プロテクター、スクイーズ）は外しています。

守ること：第1〜3章の難しさは変えない／チップは売らない、現実のお金やお店の特典とつなげない／ガチャは入れない。

---

## 1. 調べたゲームと、借りられる仕組み

| ゲーム | おもしろさの芯 | LAST TELL で借りられるところ |
|---|---|---|
| **Card Shark**（2022） | イカサマ中に相手の「疑い」が上がり、手元のテンポを乱すとバレる | **自分にもクセが出る**。平静を保つ操作 |
| **Balatro**（2024） | ポーカー役＋周回ごとに選ぶ強化（ジョーカー）、ボスごとの「縛り」、段位（ステーク） | クリア後の**周回モード**、**ボスの縛り**、**段位** |
| **Liar's Bar**（2024） | 嘘を見抜く1回の「コール」に全部がかかる緊張 | **読み宣言**（相手の手を言い当てる） |
| **Buckshot Roulette**（2023） | 情報が少しずつ増え、最後の1手で決める | 勝負前の**情報を集める**仕組み |
| **逆転裁判** | 証拠を「つきつける」と一気に形勢が変わる | 読み宣言が当たったときの演出 |
| **Hitman／スター評価のあるゲーム** | 章ごとの任意チャレンジで、同じ場所を何度も遊ぶ | **章の3つ星課題** |

## 2. 提案（おすすめ順）

### 案1：自分にもクセが出る「平常心」【おすすめ】
- 大きなブラフや大きな勝負のとき、画面に**手の震え（小さなゲージ）**が出る。指を止める・ゆっくり押すなどの簡単な操作で抑える。
- 抑えきれないと、主人公にクセが出て、**CPUがそれを読んで降りる／コールしてくる**。
- 第5〜7章とフリーで使う。第4章で「お前にもクセがある」とジンが教える。
- **物語との合い方**：題名「LAST TELL」が「相手のクセ」だけでなく「自分のクセを消す話」にもなる。第7章で、ジンが主人公のクセを読もうとする場面が作れる。
- 作る量：中（ゲージ表示＋CPUの判断に1項目足すだけ）。苦手な人向けに設定でオフにできる。

### 案2：読み宣言（ハンドを言い当てる）
- 最後のコールの前に「相手は **役なし／ワンペア／ツーペア以上**」を選んで宣言できる。
- 当たると「見えた」演出＋ノートに記録。チップは増えない（難しさは変わらない）。
- 当てた数で称号。第6章のクロウ（逆テル）ではわざと外れやすくする。

### 案3：章ごとの3つ星課題
- 各章に任意の課題を3つ（例：「ブラフで1回勝つ」「ショーダウンなしで3回勝つ」「クセを2回読む」）。
- クリア条件は今のまま。星は見た目と称号だけ。第1〜3章にも付けられる（難しさは変わらない）。
- 何度も遊ぶ理由になる。作る量：小。

### 案4：ボスの縛り＋段位（クリア後の「裏の卓」）
- クリア後、各ボスに**縛り**つきで再戦できる（例：「ジン：最初の2周はレイズ禁止」「レイカ：自分の手札が1枚伏せたまま」）。
- 勝つと段位が上がり、次の段位で縛りが重なる（Balatro のステーク方式）。
- 本編には影響しない。作る量：中。

### 案5：一夜の周回モード（ローグライト）
- 少ないチップから5つの卓を一晩で回る。卓の合間に**ジンの教え3つから1つ**を選ぶ（例：「ゴウのクセが見える」「1回だけ降りたチップが戻る」）。
- 毎回ちがう流れになる。教えはチップで買えない（収益化の方針どおり）。
- 作る量：大。発売後のアップデート向き。

### 案6：勝負前の情報集め（噂・情報屋）
- 章の前に、常連レベルや今日の1ハンドの正解数に応じて**噂を1〜2個**聞ける（「あいつは強いとき黙る」など）。
- 第4章以降のみ。テルの「ヒント」を物語の中で渡せる。作る量：小。

### 案7：ジンの赤ペン（ハンドの振り返り）
- 負けた大きいハンドだけ、終わった後に**ジンが一番大事だった1手**に赤ペンでひとこと。
- 練習アプリの採点を、師匠のセリフで出す形。作る量：中（判断の良し悪しは今の勝率計算を流用）。

### 案8：ラン・イット・トワイス（ハウスルール追加）
- オールイン後、残りの場札を2回めくって半分ずつ分ける実店舗のルール。
- 第5章の AA バッドビートの後に「次からは2回めくるか？」と聞くと物語にもなる。作る量：小。

## 3. 入れないほうがよいもの
- **イカサマをする仕組み**（Card Shark そのまま）：主人公が「クセを読む」話とずれる。マナーの悪い客の調査でも不正は入れないと決めている。
- **他の人と賭ける対戦（Liar's Bar 型の対人戦）**：サーバーが必要で、賭けの規制にも近づく。
- **教え・強化をチップやお金で買う**：収益化の方針と合わない。

## 4. おすすめ
**案1「平常心」**を一番におすすめします。題名とぴったり合い、第7章の山場も強くなります。
次に、作る量が少なく何度も遊ぶ理由になる **案3（3つ星課題）** と **案8（ラン・イット・トワイス）**。
