- **第1〜3章は何も変えない**。新しい仕組みは `CFG.ch.no>=4`、またはフリー対戦・クリア後モードだけで動かす。例外は案3（星課題）で、見た目と称号だけなので第1〜3章にも付けてよい。
- 勝ち負けに効く仕組み（案1・案6・案8）は**効果を小さく**し、設定でオフにできるようにする。
- チップは売らない。教え・噂・段位はお金で買えない。ガチャなし。
- 保存は今と同じ形（`localStorage`、`{v:1,...}`、壊れていても落ちない読み込み）。
- 追加した日本語は `EN_DICT`／`EN_TPL` に英語も入れる。
- テスト：`t5w2.js` で第1〜4章の勝率が変わらないこと、`fuzz32.js` で全章が止まらないこと。新しいオーバーレイはテストで閉じられるよう、設定で切れるようにする（クイズと同じ注意）。

## 案1：平常心（自分にもクセが出る）

### 遊び方
- 第5〜7章とフリー対戦で、**自分が大きく賭けるとき**（ポットの75%以上のベット／レイズ、またはオールイン）に、ボタンを押したあと **1.2秒の「平常心」ゲージ**が出る。
- ゲージの中を動く針が、真ん中の帯にあるときに画面をタップすると「平常心を保った」。外すと「手が震えた」。
- 手が震えると、主人公にクセ（`cue:'shake'`、ラベル「チップを置く手が震えた」）が出て、CPU がそれを読む。

### CPU の読み方
- クセが出たとき、そのストリートだけ CPU の `margin` を動かす。
  - 実際に強い手で震えた → CPU は「ブラフだ」と読みにくくなる：`margin +0.04`（降りやすい）。
  - 弱い手（ブラフ）で震えた → `margin -0.06`（コールされやすい）。
- 実際の手の強さは `equity(me.hand, S.board, opps, 200)` で判定（`>= 0.6` を強い、`< 0.35` をブラフ）。
- ランク4以上（ボス級）の相手だけが読む。ランク1〜3は気づかない。
- 帯の幅：第5章 40%、第6章 32%、第7章 28%、フリー 36%。`SETTINGS.calm`（'on'／'off'／'auto'）で、off なら常に保てたものとする。

### 物語
- 第4章クリア後のジンのセリフに足す：「クセがあるのは相手だけじゃない。お前もだ」。
- 第7章：ジンは主人公のクセを読む（ランク5扱い）。最後のハンドで、ジンが「……手は、震えなくなったな」と言う分岐（そのハンドで平常心を保てていた場合だけ）。**ジンの本物のクセ `release` の判定には触らない**。
- 称号 `calm`「平常心」：大きな勝負で5回続けて平常心を保つ。ジン「手が静かになったな。それが一番強い」。

### データ
- `S.calm={street, ok, strong}`。`cpuDecide` の最初で、`S.calm && S.calm.street===S.street && !S.calm.ok && rankOf(p.name)>=4` のとき `st.margin` を補正。
- 保存：`shisho-calm` に `{v:1, streak, best}`。

## 案2：読み宣言（相手の手を言い当てる）

### 遊び方
- 第4章以降とフリー対戦で、**リバーで相手のベットにコールするとき**、コールボタンの横に「読みを宣言」が出る。
- 3択：**役なし／ワンペア／ツーペア以上**。選ばずにコールしてもよい（今まで通り）。
- ショーダウンで当たっていれば「見えた」演出（`mieta()` の小さい版）。外れたらジンのひとこと。
- **チップは増えない**。勝敗にも影響しない。

### 記録
- `shisho-read`：`{v:1, tries, hits, byName:{名前:{t,h}}}`。ジンのノートの人物ページに「読み宣言 3/5」を出す。
- 称号 `soulread`「ソウルリード」：5回当てる。ジン「手が見えるようになってきたな」。
- クロウ（第6章）の逆テル中は当たりにくいのが自然なので、特別な処理はいらない。

### 実装メモ
- `showdown()` の `cont.forEach(...hname...)` の後で、`S.declare`（{target, guess}）と相手の `score[0]` を比べる（0=役なし、1=ワンペア、2以上=ツーペア以上）。

## 案3：章ごとの3つ星課題

### 遊び方
- 章を選ぶ画面で、各章に ☆☆☆ と課題3つを表示。クリア条件は今のまま。課題は任意。
- 星は**見た目と称号だけ**。チップも難しさも変わらない。

### 課題の例（`STARS` データ）
| 章 | ★1 | ★2 | ★3 |
|---|---|---|---|
| 1 | クリアする | 10ハンド以内にクリア | 一度もオールインせずにクリア |
| 2 | クリアする | 後ろの席から3回スチール | フォールドで5回降りる |
| 3 | クリアする | ブラフで2回勝つ | ショーダウンで一度も負けない |
| 4 | クリアする | クセを2回読む | 読み宣言を1回当てる |
| 5 | クリアする | チップ半分以下から元に戻す | 平常心を3回保つ |
| 6 | クリアする | クロウの本物のテルで取る | ゴウを熱くさせずに勝つ |
| 7 | クリアする | 平常心を一度も崩さない | 20ハンド以内にクリア |

- 判定は `endHand()` の最後で、`S` に数を数えておき、`S.result==='win'` のときにまとめて付ける。
- 保存：`shisho-stars` に `{v:1, ch:{1:[1,1,0],...}}`。
- 称号 `stars21`「全部の星」：21個集める。ジン「……もう教えることはないな」。

## 案4：裏の卓（ボスの縛りと段位）

### 開く条件
- 第7章クリア後、章を選ぶ画面に「裏の卓」が出る。本編には影響しない。

### 遊び方
- 各章のボスと、**縛りつき**で再戦する。勝つと段位が1つ上がる（最大8段）。段位が上がるほど縛りが重なる（Balatro のステーク方式）。
- 段位の縛り（重なっていく）：
  1. 相手のチップ +25%
  2. クセの出る確率 −20%
  3. 自分の持ち時間が短い（`Clock` 10秒）
  4. ボスごとの縛り（下の表）
  5. ブラインドが5ハンドごとに上がる
  6. 平常心の帯が狭い（20%）
  7. ジンのヒントなし
  8. 相手のチップ +50%
- ボスごとの縛り（`BOSS_RULE`）：
| ボス | 縛り |
|---|---|
| ゲン | 自分はプリフロップでレイズできない（コールかフォールドだけ） |
| ロク | 自分が後ろの席にいても、ロクはスチールに降りない |
| セキ | 自分の手札の1枚が、フロップまで伏せたまま |
| レイカ | 最初から逆のクセ |
| ハヤト | ずっと熱くならず、スロウロールを毎回してくる |
| クロウ | 手袋のクセが半分しか出ない |
| ジン | 傷のクセが一度だけ、わざと出る（逆のクセ） |

- 保存：`shisho-ura` に `{v:1, rank:{ボス名:段位}}`。称号 `ura8`「裏の卓の主」：どれか1人に8段で勝つ。

## 案5：一夜の周回モード（ローグライト）

### 開く条件
- 第7章クリア後。タイトル画面に「一夜（ひとよ）」。

### 遊び方
- 50,000 点で始め、**5つの卓を順に回る**（錨亭 → 銀の扉 → 月影 → 天空 → 王冠）。各卓は「目標の点数に届く」か「相手を全員飛ばす」で次へ。チップがなくなったら終わり。
- 卓の合間に、**ジンの教え3枚から1枚**を選ぶ。持てるのは最大4枚。
- 相手は各店の常連からランダムに2〜3人。ハウスルールも店ごとにランダム。

### 教え（`LESSONS`、例）
| 教え | 効果 |
|---|---|
| 顔を見ろ | クセの出る確率 +15% |
| 降りる勇気 | プリフロップで降りたとき、1周に1回だけ BB が戻る |
| 静かな手 | 平常心の帯 +15% |
| 後ろの席 | 毎卓、最初の席を自分で選べる |
| 噂好き | 卓ごとに噂を1つ聞ける（案6） |
| 二度めくり | オールインはいつでも2回めくれる（案8） |
| 赤ペン | 負けたハンドの赤ペンが毎回出る（案7） |
| 一杯おごり | 7-2で勝つと、ボーナス2倍 |

- **教えはチップでもお金でも買えない**。選ぶだけ。
- 記録：最高到達卓と最高点数（`shisho-run`）。「今日の1ハンド」と同じ形の画像で共有できる（`shareImage` を流用）。
- 1日1回の「今夜の一周」（日付で決まる同じ並び）は、あとで足してもよい。

### 作る量
- 大。`startGame` を卓ごとに呼び、終わったら教え選びの画面を挟む。章の流れ（`CHAPTERS`）は使わず、`RUN` 用の小さな設定を作る。

## 案6：噂・情報屋

### 遊び方
- 第4章以降の章の前（`showVersus` の前）に、店の人や常連から**噂を1〜2個**聞ける。
- 聞ける数：基本1個。その店の常連度★1以上で+1（`regLevel`）。
- 噂の中身は、そのボスの `TELLS` から1つ、または性格（`STYLES`）から1つ。半分は正しく、たまに（20%）**古い噂**で、もう当てはまらない。
- 噂はジンのノートの人物ページに「噂」として残る。

### 例（`RUMORS`）
- レイカ：「あの人、強いときは自分のチップを見るらしい」（正しい。ただし後半は逆）
- ハヤト：「黙って動かなくなったら、要注意だってさ」（正しい）
- クロウ：「汗をかいたら勝負手、って聞いたぜ」（わざと流させている噂）
- ゲン（再戦時）：「最近、少しは降りるようになったらしい」（古い噂）

### 実装メモ
- `GOSSIP_REG` と同じ場所に `RUMORS` を足し、`startStore` の後で `playScene` を短く1つ挟む。第1〜3章では出さない。

## 案7：ジンの赤ペン（ハンドの振り返り）

### 遊び方
- 第4章以降とフリー対戦で、**自分が BB×10 以上を失ったハンド**の後、「赤ペンを見る」ボタンが出る（押さなければ何も出ない）。
- そのハンドで**一番損だった判断を1つだけ**選び、ジンがひとこと。

### 判定（簡単なルール）
- 自分の各行動を記録：`S.myActs.push({street, type, toCall, pot, eq})`。`eq` はその時点の `equity(...)`。
- 損の大きさ：
  - コールしたのに `eq < toCall/(pot+toCall) - 0.1` → 「この額なら降りてよかった」
  - 降りたのに `eq > toCall/(pot+toCall) + 0.15` → 「ここは降りなくてよかった」
  - クセが見えていたのに逆の行動 → 「顔を見ていたか？」
- 一番差が大きいものを表示。どれもなければ「運が悪かっただけだ。打ち方は悪くない」。
- 1つの卓で3回まで（うるさくしない）。セリフはジンの口癖案に合わせる。

## 案8：ラン・イット・トワイス

### 遊び方
- 新しいハウスルール `twice`「2回めくり」。オールインで手が決まった後、残りの場札を**2回**めくり、ポットを半分ずつ分ける。
- フリー対戦のハウスルール選択に追加。第5〜7章では、オールインのときに「2回めくる？」と聞く（CPU は性格で答える。慎重な性格は受ける）。

### 物語
- 第5章の AA バッドビートの直後、同じ卓のテツが「次からは2回めくるか？」と声をかける（選べるのは次のオールインから。台本のバッドビートには使わない）。
- ジン「運を半分にしても、腕は半分にならん」。

### 実装メモ
- `HOUSE.twice={name:'2回めくり', desc:'オールインで手が決まったら、残りの場札を2回めくって、ポットを半分ずつ分ける'}`。
- `S.runout` の流れの中で、1回目の場札を `S.board1` に残し、2回目の場札を配ってから、`showdown()` の分配を半分ずつ2回行う（端数は1回目へ）。
- 表示：場札を2段に並べる（上：1回目、下：2回目）。
- 称号 `twice`「二度めくり」：2回めくって両方勝つ。ジン「二度勝ったか。ツイている夜は、それでいい」。
