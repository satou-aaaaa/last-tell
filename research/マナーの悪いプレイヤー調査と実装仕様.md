# マナーの悪いポーカープレイヤー 調査と実装仕様

依頼（2026-10-08 satou）：「マナーの悪いポーカープレイヤーについて調べて、そのような要素も入れたい」。
前提：[ストーリー練り直し案](../story/ストーリー練り直し案.md) で、第5章のボス**ハヤト**がスロウロールをすることになっている。実装先は `story/shisho.html`（担当は「ストーリーモードの企画提案」スレッド）。このファイルは仕様だけで、shisho.html は変更していない。

調べ方：ポーカーのマナーやアングルショットとしてよく語られるものを、一般的な知識から整理した。店や団体のルールは細かく違うので、ゲーム内のディーラーの裁定は「よくある扱い」にそろえている。

---

## 第1部 調査：マナーの悪いふるまい

### A. 勝ち方・負け方が悪い
| ふるまい | 中身 | 嫌われる理由 |
|---|---|---|
| **スロウロール** | 勝っているのに、わざとゆっくり手を見せる。「さあ、何だと思う？」と焦らす | 相手に一度「勝ったかも」と思わせてから落とす。最も嫌われるマナー違反の一つ |
| **勝ち誇る・煽る** | 勝つたびに大げさに喜ぶ、負けた相手を笑う | 卓の空気が悪くなる |
| **説教する** | 負けた後に「なんでそれでコールするんだ」と相手のプレイを責める | 初心者が店に来なくなる |
| **ヒット・アンド・ラン** | 大きく勝った直後に、すぐ席を立って帰る | ルール違反ではないが、取り返す機会を与えないので嫌がられる |

### B. アングルショット（ルールのすき間を使う、ずるいふるまい）
| ふるまい | 中身 | よくあるディーラーの扱い |
|---|---|---|
| **フェイクチェック** | テーブルを叩くようなしぐさで相手にチェックだと思わせ、相手が動いたあとに「まだ何もしていない」と言う | 叩いたらチェック。取り消せない |
| **ワンチップのふり** | 大きいチップを1枚だけ黙って出し、相手にレイズだと思わせる | 宣言がなければコール扱い |
| **ストリングベット** | チップを何度かに分けて出し、相手の反応を見てから上乗せする | 最初に出した分だけが有効 |
| **嘘の役宣言** | ショーダウンで「ストレートだ」と言い、相手が勘違いして手を捨てるのを狙う | 「カードがしゃべる」。見せた手で判定する |
| **順番前のアクション（わざと）** | 自分の番の前に降りるそぶりを見せ、前の人にベットさせる | 注意、くり返すとペナルティ |
| **大きいチップを隠す** | 高いチップを後ろに隠し、持ち点を少なく見せる | 見えるところに置くよう注意される |

### C. 卓の空気を壊す
| ふるまい | 中身 |
|---|---|
| **長考で時間稼ぎ** | 毎回わざと長く考える。卓の進行が遅くなる（「タイム」を取られる） |
| **ディーラーに八つ当たり** | 負けるとディーラーのせいにする、カードを投げる |
| **他人のハンドに口出し** | 降りた人が「今のは降りるべきだった」と口を出す（ワン・プレイヤー・トゥ・ア・ハンドの違反） |
| **降りた手を言う** | 勝負中に「さっき俺、Aを捨てた」と言ってしまう。残っている人の判断が変わる |

### D. 入れないもの（マナーではなく不正）
- **共謀、チップの受け渡し（チップダンプ）、イカサマ**：ゲームの仕組みとしては入れない。物語の過去話として出すのは可。
- **強い暴言・差別的な言葉**：審査や年齢区分に響くので、悪役のセリフも「感じが悪い」程度にとどめる。

## 第2部 ゲームに入れる案

### 考え方
- マナーの悪さは **「焦り」のテル** として扱う。ジンの言葉：「マナーの悪さもクセだ。焦っている奴ほど、ああなる」。これは、ジンに半人前と言われ続けて焦っていたハヤトの過去と重なる。
- マナーの悪い相手は **熱くなりやすい（ティルト）**。負けると打ち方が荒くなるので、冷静でいれば勝てる、という学びにする。
- ディーラーが裁定を下す場面で、ライブのルールを自然に教える。
- 承認済みの第1〜4章の勝負には入れない。使うのは第5章以降とフリー対戦。

### おすすめ順
1. **ハヤトのスロウロール**（第5章、決定済み）
2. **ティルト**：マナーの悪いCPUが大きく負けると、数ハンド打ち方が荒くなる
3. **ディーラーの裁定**：ハヤトのフェイクチェックやワンチップのふりを、ディーラーが止める
4. **プレイヤーの返し方**：煽られたときに「無視する／ナイスハンド」を選べる
5. **称号**：マナーにまつわる称号を足す
6. **第6章の脇役とフリー対戦の「感じの悪い客」**

---

## 第3部 実装仕様

関数名は 2026-10-08 時点の shisho.html（`showdown`、`afterAct`、`cpuAct`、`LINES`、`TELLS`、`TITLES`、`HOUSE`、`grantTitle`）を読んで書いた。作業中に変わっていたら読み替えること。

### 1. データ：`MANNERS`（`TELLS` の近くに追加）
```js
const MANNERS={
  'ハヤト':{slowroll:.8, angles:['faketap','onechip'], angleRate:.12, gloat:true, tilt:{bluff:.3,margin:-.06,hands:4}},
  // 第6章の脇役やフリー対戦の「感じの悪い客」もここに足す
};
```
- `slowroll`：自分がショーダウンで勝つときにスロウロールする確率
- `angles`：使うアングルショットの種類。`angleRate` は1回の行動で試す確率（上限：1ハンドに1回）
- `gloat`：勝ったときに煽りセリフを言う
- `tilt`：熱くなったときのスタイルの上書き

### 2. スロウロール
- `showdown()` で、勝者の中に `MANNERS[p.name].slowroll` を持つCPUがいて、プレイヤーもショーダウンに残っているとき、確率で発動。
- 流れ：
  1. プレイヤーの手を先に表にし、そのCPUの手は伏せたまま。
  2. CPUがセリフ（`LINES['ハヤト'].slowroll`）。例：「いい手だな。……勝ったと思ったか？」
  3. 2〜2.5秒待つ（`S.hold`、演出の速さ「速い」なら1秒）。プレイヤーの立ち絵は一瞬 `confident`。
  4. 1枚ずつ、ゆっくり表にする。チップの移動はそのあと。
- 今の `showdown()` は手を開いてからすぐ配分するので、**「手を開く」と「チップを動かす」を分ける**必要がある。配分の計算は今のままで、表示とポットの移動だけを遅らせる。
- 直後にジンのひとこと（`senseiLine` か cutIn）：「顔に出すな。ああいう勝ち方をする奴は、もう焦っている」
- 第5章クリア後の会話では、ハヤトが最後のハンドだけ**ふつうに手を見せる**。ジンの過去を話したあとの変化として描く。

### 3. ティルト（熱くなる）
- マナーの悪いCPUが、1ハンドで自分の持ち点の30%以上をプレイヤーに取られたら `p.tilt=MANNERS[...].tilt.hands` を入れる。
- `cpuAct` では `p.tilt>0` のあいだ、スタイルの `bluff` と `margin` を `tilt` の値で上書きする。ハンドが終わるたびに1減らす。
- 見た目：表情は `worried` か怒り顔、テルに `sweat` が出やすくなる。セリフ例：「……今のはまぐれだ」
- ジンのひとこと：「ハヤトが熱くなった。強い手で待て」
- 熱くなった相手から大きく取ると、称号「熱くなった相手から取った」。

### 4. アングルショットとディーラーの裁定
相手に**得をさせない**ようにする。ディーラーが止めるので、結果はプレイヤーに少し有利になる。新しい第5章の難易度の範囲で調整すること。

| 種類 | 発動 | 見せ方 | 結果 |
|---|---|---|---|
| `faketap` | CPUが強い手でチェックかベットか迷う場面（`rel>st.mid` で `toCall===0`） | CPUがテーブルを叩くしぐさ → 「いや、ベットだ」 → ディーラー「叩いたのでチェックです」 → CPUが舌打ち | チェックで確定 |
| `onechip` | CPUがレイズを選んだとき | 大きいチップ1枚がすべり込む → ディーラー「宣言がないのでコールです」 | コールに変わる |

- ディーラーのセリフは、今あるディーラーの声の仕組み（中央に短く出る）を使う。
- 一度出たら、ログに短い解説を出す：「ライブでは、テーブルを叩くとチェックです」。
- 第5章では、1回目にジンが「ああいうのを『アングル』と言う。ルールのすき間を使う打ち方だ」と説明する。

### 5. プレイヤーの返し方（任意）
- スロウロールされた直後や煽られたときに、小さなボタンを2つ出す：**「無視する」**／**「ナイスハンド」**。何も押さなくても進む。
- 勝敗には影響しない。
  - 「ナイスハンド」：ハヤトが一瞬止まって「……ふん」。3回で称号「大人の対応」。
  - 「無視する」：ジン「それでいい」。
- 今ある「揺さぶる」を、マナーの悪い相手に何度も使うと、ジンが「口で勝とうとするな。それはハヤトのやり方だ」と言う（1章に1回）。

### 6. 称号の追加（`TITLES` に追加）
```js
{id:'slowrolled',name:'スロウロールされた',hint:'わざとゆっくり手を見せられる',jin:'ああいう勝ち方をする奴は、いずれ客を失う。'},
{id:'tiltwin',name:'熱くなった相手から取った',hint:'熱くなった相手に勝つ',jin:'冷めた方が勝つ。覚えておけ。'},
{id:'gentle',name:'大人の対応',hint:'嫌な勝ち方をされても「ナイスハンド」と言う',jin:'それが一番効く。'},
{id:'angle',name:'アングルを見た',hint:'ディーラーがずるい打ち方を止める',jin:'ルールは守る者の味方だ。'},
```

### 7. ストーリーへの組み込み
- **第5章の導入**：地下の賭場跡に入ると、ハヤトが常連から大きく勝ち、「今日はここまでだ」とすぐ席を立とうとする（ヒット・アンド・ラン）。主人公とジンを見て、座り直す。
  - ジン「勝ち逃げか。昔から、勝つとすぐ帰る奴だった」
- **第5章の途中**：スロウロール、アングル、ティルト。最初のバッドビート演出（あるある案）のあとなので、プレイヤーはチップが少なく、ハヤトは余裕で煽ってくる。熱くなったハヤトを冷静に崩していく流れにする。
- **第5章の結末**：練り直し案どおり、ハヤトが「あの夜」を話す。最後のハンドだけハヤトがふつうに手を見せるのが、変化の合図。
- **第6章「王冠」**：クロウは**完全に紳士的**に描く（最強の相手はマナーもいい、という対比）。脇役として、ディーラーに八つ当たりする客を1人出し、店の責任者（フロア）が静かに退場させる短い場面を入れる。クロウ「この卓では、負け方も見られている」。
- **フリー対戦**：設定に「感じの悪い客を入れる」を追加（既定はオフ）。入れると、席の1つがマナーの悪いCPUになる。

### 8. 守ること
- 第1〜4章の勝負には入れない（会話の伏線は可）。
- 悪役のセリフは「感じが悪い」程度。罵倒、差別的な言葉、お酒やタバコの描写は入れない。
- `prefers-reduced-motion` のときは、スロウロールの待ち時間を短くし、1枚ずつめくる動きは省く（文字で伝える）。
- チップは点数のまま。
