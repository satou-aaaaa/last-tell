# キャラ同士の掛け合いを増やす提案（2026-10-10）

satou さんの依頼「キャラ同士の掛け合いも増やしてほしい」への提案です。ゲーム本体（story/shisho.html）は読んだだけで、変えていません。

---

## 1. 今の作り

| 仕組み | 中身 | 気になるところ |
|---|---|---|
| 掛け合い `BANTER` | 2行の会話が20組。ハンドの頭に35%で1組 | **第一部の主役どうしだけ**。新しい常連12人・船の客6人・第二部の人物はゼロ。卓で何が起きても同じ会話が無作為に出る |
| 雑談 `CHAT` / 言葉の勝負 `DUEL` / 質問 `QUESTIONS` | 主人公と相手の1対1 | キャラ同士ではない |
| 隣の卓の声・観客席・そのころ（幕間）・後日談 | 卓の外の声と場面 | 幕間は4場面、後日談は主人公への語り。卓の上の「人と人」はほぼ無い |
| 噂 `GOSSIP` / `RUMORS` | 1人の独り言 | 返事をする人がいない |

まとめると、**会話の仕組みは多いのに、キャラどうしが言葉を返し合う場面は20組・各2行だけ**です。30人に増えた常連が、卓の上ではお互いに口をきかない状態です。

ついでに見つけた小さな点（直すかは任意）:
- ケンジ「負けを取り返すんだよ」は、お金の話に近く読めます。→「さっきの続きだよ」に。
- 掛け合いは同じ組が続けて出ることがあります（重複よけが無い）。

---

## 2. 案（5つ）

### 案1　卓の全員に掛け合いを持たせる（量を増やす）
新しい常連12人・船の客6人に、つながりのある相手との掛け合いを足します。図鑑に書いた関係（ウォルターはセキの将棋仲間、アイシャはレイカと茶葉が同じ、スミンはミナの音響係……）を、卓の上で見せます。2行だけでなく **3〜4行** の組も入れます。めやす：20組 → 約70組。

```
アデ　　「ゲン、その錨、まだ外さないのか」
ゲン　　「外したら札が来なくなるだろ！」
アデ　　「つけていても、選べるわけじゃない」
ゲン　　「……うるせえ。配られた札は全部勝負だ！」
```
```
マリア　「ゲン、今の顔。四つの言葉で言えるよ。全部『しまった』」
ゲン　　「五つ目で、なんとかならねえのか」
```
```
ウォルター「セキ、今のは降りる手じゃなかった」
セキ　　　「君は、降りない手しか見ないからね」
ウォルター「だから将棋でも、君に勝てない」
```
```
スミン　「サビの前、半音上げたでしょ」
ミナ　　「気づいた？　今日は攻めたい気分なの」
スミン　「……卓でも？」
ミナ　　「卓でも」
```
```
アイシャ「その茶葉、今日も同じですね」
レイカ　「あなたもでしょう」
アイシャ「潮と同じで、変えないほうがいいものもあります」
```
```
シオン　「ボタン、動いてないよ」
ソウ　　「え、えっ！？　す、すみません！」
レイカ　「……今日、三回目よ」
```
```
テツ　　「ベンさん、ここ、昔はあんたの倉庫だったんだろ」
ベン　　「ああ。……床は、今のほうがきれいだ」
```
船の客は言葉が違うので、**マリア（通訳）** が間に入る形を作ります（マリアが同じ卓にいるときだけ）。
```
クワメ　「……（英語で、短く何か言った）」
マリア　「『この街の卓は、港でいちばん静かだ』って。褒めてるのよ」
ゲン　　「静かだあ？　俺がいるのにか！」
```
タケルはメモで返します（今のメモ表示をそのまま使う）。
```
ゴウ　　「おい、さっきから何見てんだよ」
タケル　「（メモ）あなたの手。さっきも同じ動き」
ゴウ　　「……読むなよ」
```

### 案2　卓で起きたことに反応する掛け合い ★おすすめ
今は無作為に出る会話を、**直前のハンドで起きたこと** に合わせて出します。みんなに見えたことだけに反応するので、相手の手の強さはばれません。

| きっかけ | 例 |
|---|---|
| ショーダウンでブラフが見えた | ソウ「レイカさん、今の……何も無かったんですか」／レイカ「教えたら勉強にならないって、言ったでしょ」 |
| スロウロール・マナー違反のあと | テツ「ハヤト、それやめろって」／ハヤト「勝ちは勝ちだ」／ベン「……若いな」 |
| 誰かが飛んだ | カオル「お疲れさま、ゴウさん」／ゴウ「……次は覚えてろよ」／クロウ「お待ちしています」 |
| 主人公が5回続けて降りた | ゲン「おい新入り、寝てんのか？」／アデ「待てるやつは強い。船乗りの常識だ」 |
| 大きなポットが決まった | ミナ「今の、曲よりドラマチックだった」／セキ「心臓に悪いね」 |
| 主人公が主役（ボス）からポットを取った | ハル「ロクさんから取った……！」／ロク「……数えてから喜べ」 |
| 同じ人が3回続けて勝った | ラジ「ハンナさん、また！」／ハンナ「メモどおり」／ヨシオ「今のはね……知らんけど」 |

卓が「見ている人たちの集まり」になり、同じ会話の繰り返しも減ります。

### 案3　物語が進むと変わる掛け合い（関係が育つ）
同じ二人の会話が、クリアした章によって変わります（後日談の `need` と同じ考え方）。2回目以降に店へ来た人が「あ、変わった」と気づく作りです。

```
（第2章クリア前）ロク「ハル、手札ばかり見るな」／ハル「す、すみません」
（第7章クリア後）ハル「ロクおじさん、ジンさんに会いに行った？」
　　　　　　　　ロク「……ああ。数えずに行った」
```
```
（第5章クリア後）テツ「錨亭、行ったのか」／ハヤト「……まだ、だ」
（第7章クリア後）テツ「錨亭、行ったのか」／ハヤト「……行った。カレーは、まずくなかった」
```
```
（第6章クリア後）ミナ「セキさん、この前のブラフ、すごかった」
　　　　　　　　セキ「一度きりだよ。たしなみを忘れたのは」
```
第二部では、タロウとゲン、ハヤトとハヤトの弟子の組を足します（第二部の担当と相談）。

### 案4　主人公も巻き込まれる掛け合い
二人が言い合って、最後に主人公へ振ります。答えは今の「揺さぶる」の場所に2択＋黙る、で出します（`QUESTIONS` と同じ見た目）。どれを選んでも勝ち負けや相手の強さは変わりません。選んだ側が、あとで一言だけ覚えています。第4章から。

```
ミナ　「セキさん、さっきのは絶対ブラフだった」
セキ　「さあ、どうだったかな」
ミナ　「ねえ、あなたはどう思う？」
　　　［ブラフ］［本物］［黙る］
（ブラフ）ミナ「ほらね！」／セキ「……君たちは、手厳しいね」
```

### 案5　卓の外の短い会話場面
店に入ったときや章のクリア後に、主人公のいない3〜5行の場面を足します（今の「そのころ」と同じ見た目）。例：閉店後の錨亭で店主とマリアがジンの昔を話す、王冠でクロダとカオルが看板を磨く、など。物語の厚みは出ますが、1場面ずつ書くので量は少なめになります。

---

## 3. おすすめ

**案2（反応する）を軸に、案1（全員に掛け合い）で量を足す**のがおすすめです。
- 案1だけだと「数が増えた無作為の会話」で、すぐ聞き流されます。案2で「今のを見ていた」感じが出ると、同じ量でも生きて見えます。
- 案2のきっかけは今あるデータ（ショーダウン、スロウロール、飛び、降りた回数）で判定できるので、作りが小さく済みます。
- 案3は次に入れると、何度も店に来る理由になります。案4・5は好みで。

## 4. 守ること
- **掛け合いは手の強さのヒントにならない**（見えたことにだけ反応する。テルの仕組みとはつながない）。だから第1〜3章の難しさは変わりません。
- 第7章（ジンとの一騎打ち）には掛け合いを出しません。ジンの本物のテルには触れません。
- お金の話（勝ち負けの額など）は入れない。「あの日」を使い、名前に「夜」は使わない。
- 出身で性格を決めない。カタコトにしない。全員18歳以上。
- 出すのは今と同じくハンドの合間だけ。1卓で同じ組は1回まで、2ハンド続けては出さない。
