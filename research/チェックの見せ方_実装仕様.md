## 1. 何が変わるか（遊ぶ人から見て）
- 誰かがチェックすると、その人の前のラシャに手が出て「コン、コン」と叩く。小さな波紋が出て、音がオンなら叩く音が鳴る。
- 叩き方は人ごとに決まっている（強い人は指先で静かに1回、ゲンは拳で強く2回、など）。毎回同じで、手の強さでは変わらない。
- あなたがチェックしたときも、画面の下（自分の札の手前）であなたの手が叩く。
- 全員がチェックで回ったら、ディーラーが卓を1回叩いて「チェック、アラウンド」と言ってから次の札を配る。
- ボタンや操作は増えない。

### knockCheck(i) の中身
1. `const st=checkStyle(p.name)`（データ.js）。手の位置：CPU は `$('spot'+i)` の `.mystack`（無ければ spot の中心）の少し手前。あなたは `$('mine')` の `.mystack` の左隣。
2. `#cam` の中（卓と一緒にカメラで動く層）に `div.knockhand` を作り、見本の `handSVG(k)` の手を入れる。手の大きさは `.mystack .col` の幅の約1.6倍。
3. Web Animations で「上がる → 下ろす」を `st.n` 回。1回の間隔は fist 230ms／palm 260ms／ほか 190ms（`SPEED()` を掛ける）。下ろした瞬間に `Sound.sfx(st.loud?'knockHard':'knock')` と波紋 `.knockring`（拳は大きめ、指先は小さめ）。
4. 全体で 0.5〜0.9 秒。終わったら要素を消す。
5. `st.say` がある人（ゲン・タロウ）は、**札（`p.lastAct`）を `st.say.ja` にする**。吹き出し（`p.say`）は使わない。ゲンのテル「talk（しゃべる）」と見分けがつかなくなるのを防ぐため。
6. `reducedMotion()` のときは手と波紋を出さず、音だけ。

### checkAround() の条件と中身
- 条件：`!S.runout && S.street!=='preflop' && S.currentBet===0` かつ、手に残っている全員（`inHand`）が、オールインでない人はこの通りでチェックした（`p.lastAct==='チェック'`）。
- 中身：ディーラーの位置（卓の中央の上、`#dcall` の近く）で手のひらを1回叩く＋`dealerSay(CHECK_AROUND.ja)`＋`log('ディーラー：全員チェック')`。`S.hold=Math.max(S.hold||0,500*SPEED())` で次の札を少しだけ待つ。
- リバーで全員チェックのときも出す（そのあと今まで通りショーダウン）。

## 5. 守ること
- 第1〜3章の難しさを変えない：CPU の判断（`cpuDecide`）と考える時間（`wait`）には触れない。叩く動きは `act()` のあと（`afterAct`）に始める。`fast` テルの速さは今のまま。
- 第7章のジンの本物のテル（`release`、あごの傷）に触れない：手は卓の上だけ。カメラが顔に寄っているときも、叩く手は顔の範囲に入らない。
- 叩き方は人ごとに1つ。乱数・手の強さ・ブラフ・テルの有無で変えない。
- 声（ゲン・タロウ）は札の文字だけ。吹き出しは使わない。
- 「夜」を使わない／セリフにお金の話を入れない。
- 動きを減らす設定では手を出さない。
- 吹き出し・`#dcall`・名札と重ならないこと（UI確認で見る）。

## 6. 「できた」の条件（自動検証に足せる形）
- フリー6人で 300 ハンド回して、チェックのたびに `.knockhand` が1回だけ出る（チェックの回数＝出た回数）。
- 同じキャラの叩き方（k と n）は、手の強さ（`p.lastState`）が strong／bluff／普通のどれでも同じ。
- 第1〜3章の autoplay の勝率が、入れる前と同じ（qa/checks/winrate.js の幅の中）。
- CPU が行動を決めてから `act()` が呼ばれるまでの時間の分布が、入れる前と同じ（`wait` に手を入れていない）。
- 全員チェックで回った通り（プリフロップ以外）では、毎回 `dealerSay('チェック、アラウンド')` が1回呼ばれ、ベットがあった通りでは0回。
- ゲンとタロウのチェックは、`p.say` を作らない（吹き出し0回）。
- `reducedMotion()` が真のとき、`.knockhand` は0回。
- 新しい日本語の文字列は全部 EN_DICT にある（qa/checks/text.js）。
- 目で見る：スマホ縦・スマホ横・PC で、叩く手が顔・名札・吹き出し・ボタンにかぶらない。テルに寄ったカメラのときも同じ。
- 目で見る：ハヤト／ゴウの faketap で、叩く手が見えてからディーラーの裁定が出る。
