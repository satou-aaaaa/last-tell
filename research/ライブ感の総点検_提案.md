## 2. 案（5つ。1つずつでも組み合わせても入れられます）

### 案1 卓から数字を減らす（#1〜7）　★1.0
- 卓の上の金額の数字、名札に残る行動の札、「考え中…」、「◯◯の番です」、上の行のハンド番号と通りの札を消す。
- 行動はディーラーの声（今もある「レイズ、6,000」）と、名札が一瞬光るだけにする。
- ポットの数字は、相手の持ち点と同じ設定「だいたい／正確」に従う（第4章以降とフリーは「約1万2千」、タップでディーラーが数える。第1〜3章は今のまま正確な数字）。
- 勝った額の札と「◯◯の勝ち（+15,000）」をやめ、ディーラーの「ポットは◯◯さんへ」とポットが動くだけにする。

### 案2 ディーラーが進める　★1.0（ディーラーの手は公開後）
- 手札をSBから時計回りに1枚ずつ2周配る（6人卓で約1秒。「速い」なら0.5秒）。
- 場札の枠を消す。バーンを伏せて置き、フロップは伏せた3枚を一度にめくって広げる。
- ハンドの始まりに、SB・BBの人がチップを前に出す。
- ハンドの合間に、カードを集めてシャッフル（音と短い動き）、ボタンが次の席へ滑る。
- 公開後: 卓の奥の縁からディーラーの手が出て、配る・ポットを押す・賭けを集める（キャラ絵と同じ作り方で手だけ描く）。

### 案3 テレビ中継の演出を外す　★1.0
- オールイン中の「勝率◯%」を消す。代わりに、残っている人の小さな反応（「頼む……」、立ち上がる、腕を組む）と、隣の卓のざわめき。勝率はハンドのあと、記録とジンの振り返り（プロ目線 A5 の「ターンの時点で約80%だった」）では使う。
- 英語の帯（RAISE/ALL IN/CALL）をやめ、ディーラーの声だけにする。ボスのオールインのカットインは、章ごとの山場（1章に1回）だけ残す。
- 役の札をやめ、ディーラーが勝った手だけ読み上げる（「フルハウス、9と6」）。負けた手はディーラーが伏せて集める。
- 打っている最中の自分の役の表示は、第1〜3章だけ残す（練習の手助け）。第4章からは出さない。設定で戻せる。
- 音: 番の「ピンポン」→ 消す（振動も消す）。勝ちのファンファーレ → チップが滑ってくる音。心音 → 卓が静まって、誰かがチップをいじる音だけ（今の「静まり返る」の音を使う）。
- 設定「テレビ風の表示（勝率・役の札）」を足し、既定はオフ。戻したい人は戻せる。

### 案4 時間と流れをライブにする　★1.0
- 持ち時間のバーをやめる。あなたが長く考えると（大きな勝負で25秒）、そのハンドに残っていない客が「クロック、お願いします」と言い、フロアが「1分です」。最後の10秒だけディーラーが「10秒」と声で数え、0で今と同じくフォールド（またはチェック）扱い。
- 第1〜3章は今と同じく、時間切れにはならない（ジンが「そろそろ決めろ」と言うだけ）。
- 「先に選ぶ」（チェック/フォールドなど）は、既定をオフにする。設定の「くわしい設定」に「先に選ぶ（オンライン式）」として残す。

### 案5 人の出入り　公開後
- 飛んだ相手は立って帰る（席が空く）。フリー対戦では数ハンド後に新しい客が座り、「BBを置いてから入ります」。
- 補充は、フロアがチップのラックを持ってくる短い動き。
- 大会（第6章・第二部）: 休憩、カラーアップ、テーブル移動の場面。

## 3. おすすめ
**案1＋2＋3＋4を1.0に（ディーラーの手と案5は公開後）。**
21か所のうち19か所が直ります。どれも「表示を消す・動きの順番を変える・音を差し替える」で、CPUの考え方には触らないので、第1〜3章の難しさは変わりません。案3の設定があるので、オンラインの表示が好きな人も困りません。

1.0の範囲が広がるので、入れる順番は「案1 → 案3 → 案4 → 案2」をおすすめします（案1と案3はほとんど表示を消すだけで、UI案3の片付けと同じ場所を触るので一緒に入れられます）。

## 4. 守ること（テルにならないように）
- 配る・シャッフル・ブラインドを置く動きは、手札の強さに関係なく、全員いつも同じ速さ・同じ順番。
- 「クロック」を呼ぶのは、そのハンドに残っていない客（またはフロア）だけ。CPUが考える時間や判断は変えない。
- 案3の反応（「頼む……」など）はオールインで手が開いたあとだけ出す（手が開く前には出さない）。台詞にお金の話は入れない。
- 第7章のジンの本物のテル（顎の傷）、カットイン「最後のクセ」はそのまま。第7章では隣の卓の声も出さない（今と同じ）。
- reducedMotion のときは、配る・シャッフルの動きを省き、今と同じ速さで出す。
- 第1〜3章: ポットの正確な数字と自分の役の表示を残す。CPUの判断は変えない（qa の winrate で確認）。
