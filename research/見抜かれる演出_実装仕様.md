## 0. いまの作り（shisho.html）

- `selfRecord(p,type,to)`：あなたがレイズしたときに、額（big）・速さ（fast/slow）・チップを見る（body）を `S.myLastBet` に記録。
- `selfLearn()`：ショーダウンで、強い手（`score[0]>=2`）か弱い手かを `S.selfMem` に数える。
- `selfAdj(p)`：`cpuDecide` の中で呼ばれ、読める相手（`selfReader`）なら降りやすさ `margin` を ±最大0.08 変える。
  - adj>0＝「強い」と読んだ（降りやすくなる）。adj<0＝「弱い」と読んだ（コールしやすくなる）。
  - 吹き出し `SELF_SAY` は、相手1人×クセ1種類につき1回だけ。強い・弱いのどちらと読んだかは言わない。
- 出す範囲：第5章以降・裏の卓・一夜（ランク4以上）、フリー対戦（ランク2以上）。第1〜4章では出さない。**この範囲と読む強さは変えない。**

## 1. 第1段：案1「視線と寄り返し」

### 1-1. 流れ（相手が、あなたのクセで読んだ手番だけ）

| 時間 | 画面 | カメラ（カメラ演出 案2 が入っている場合） |
|---|---|---|
| 0 | 読む相手の手番。今どおり「考え中」 | その席へミドル |
| +0.4秒 | 相手の目線があなたのほうへ下りる（chars.css の `.pupils` を下へ 2.6px、新しいクラス `.bust.look`）。席からあなたの賭けたチップへ、細い水色の線（視線）が伸びる | そのまま |
| +0.9秒 | 「じっ」の擬音（水色）。あなたの手元に札「◯◯が、あなたの賭けた額を見ている」 | **あなたの手元（`#mine` の上、賭けたチップ）へ寄り返す**。0.32秒 `cubic-bezier(.3,.9,.3,1)`。周りを暗くする |
| +2.3秒 | 擬音と札を消す | 相手へミドルで戻る |
| +2.7秒 | 相手が結論を言う（下の表）。表情は `think` | ミドルのまま |
| 吹き出しのあと | 相手がアクション（今どおり）。あなたの手元に小さな札「読まれた：賭ける額」を、そのハンドの終わりまで残す（今の `#myTell` を使う） | 今どおり |

- 合計で約2.5秒、相手の手番が長くなる。`SPEED()` が fast のときは半分。
- カメラ演出 案2 がまだ入っていない場合や、設定でカメラがオフ／控えめのときは、寄り返しをしない。目線・視線の線・擬音・札・結論のセリフだけ出す。
- 「チップを見た（body）」で読まれたときは、視線の線の先をあなたの手札（`#mine` のカード）にし、札は「◯◯が、あなたの目線を見ている」。
- 「考える時間（fast/slow）」で読まれたときは、線は出さず、擬音を「……」にし、札は「◯◯が、あなたの間（ま）を計っている」。

### 1-2. 結論のセリフ（`SELF_READ[why][dir]`。dir は adj>0 なら 'strong'、adj<0 なら 'weak'）

| why | 強いと読んだ | 弱いと読んだ |
|---|---|---|
| size | その額……強いときの額だ | その額……前に外したときと同じだ |
| fast | 迷わず賭けたな。持ってる顔だ | 早すぎる。持ってないときの早さだ |
| slow | 長く考えてから大きく来た。本物だな | 迷いが長い。自信がないんだろう |
| body | 今、チップを見た。いい手が来たな | （body は 'strong' だけ） |

- 吹き出しの下に小さく「読み：賭ける額 → 強い」のような1行を添える（見本どおり）。
- キャラごとの口調（口癖案・キャラ作りこみ案の一人称/語尾）に合わせて、ハヤト・クロウ・レイカ・ゲン・ロク・セキ・ジンだけは言い回しを変えてよい（ハヤトは「二代目」と呼ぶ、など）。ただし**読んだ中身（何を見て、強い／弱いのどちらか）は必ず言う**。
- ジンのひとこと（`SELF_JIN`）は今どおり、種類ごとに1回だけ。

### 1-3. 出す回数

- 今の「相手1人×種類ごとに1回」をやめ、**1ハンドに1回まで**（`S.readShownHand===S.handNo` なら出さない）。同じ相手・同じ種類でも、3ハンド空ければまた出してよい。
- 吹き出しを出さずに読んでいるとき（1ハンドに2回目以降）も、`#myTell` の札「読まれた：◯◯」だけは出す。
- 第7章のジンは今どおり読む（`selfReader` の範囲）。ジンの本物のテル（顎の傷 `release`）とは別の仕組みなので、そちらは一切触らない。

### 1-4. 作り方

1. `selfAdj` の吹き出し部分を、`S.readShow={i,why,dir,hand:S.handNo}` を立てるだけにする（`p.say` は付けない）。
2. CPUの手番の処理（`cpuDecide(i)` を呼んでいる所、3250行あたり）で、`S.readShow` が立っていたら、アクションの実行を約2.5秒遅らせ、上の流れを `readSeq(i)` で順に出す。
   - `S.stare`（大きな賭けの前の沈黙）と重なったら、`readSeq` を先に出してから沈黙に入る。
   - 手番が変わる・ハンドが終わる・`S` が入れ替わったら、タイマーを消す。
3. 視線の線と擬音は `#table` の直下に置く（カメラの `#cam` の外）。線の位置は、読む人の `.bust` の目の位置と、`#mine` の賭けたチップ（`.mybet`／`#mine` 上端）の位置から計算する。
4. カメラ演出 案2 の `camTo(i,kind)` に kind `'me'`（あなたの手元へ寄る）を足す。倍率はクローズと同じ（スマホ縦 2.7／横 2.2／PC 2.4）。ただし `#mine`・ボタンは `#cam` の外なので拡大されない。寄る先は卓の手前（あなたの賭けたチップが置かれる所）。
5. 英語版の辞書（実行時翻訳）に、新しいセリフ・札・「読み：」を足す。

## 2. 第2段：案3「逆手に取る」

### 2-1. 流れ

1. 相手があなたのクセで「強い」と読んで降りた → そのハンドで、あなたが手を見せる（今のショー／マック）。見せた手が弱い（`score[0]<2`）。
   - または、相手が「弱い」と読んでコールした → ショーダウンであなたが強い手。
2. 相手の表情を `lose` にし、セリフ「……わざとか」（ハヤト「……わざとかよ、二代目」、クロウ「……お見事。拝見しました」など。クロウは口癖を壊さない）。
3. 卓の中央に金色の判「引っかけた」（0.25秒で押される）。1.4秒で消す。
4. あなたの手元の札を「◯◯は、もう額では読まない」に変える。
5. ジンのひとこと（1回だけ）：「読ませてから、裏をかく。それが本当のテルの使い方だ」。

### 2-2. 読み直すまで

- 引っかけられた相手は、そのクセ（why）で **8ハンド読まない**（`S.selfFooled[name+why]=S.handNo+8`）。`selfAdj` の先頭で見る。
- ランク5（クロウ）は4ハンドで読み直す。読み直したら、次に読むときのセリフを1回だけ「今度は……本物か？」にする。
- `S.selfMem` は今どおり数える（弱い手を見せれば自然に「混ざった」扱いになる）。
- 手を見せずに勝った場合（相手が降りて、あなたがマック）は何も起きない。見せるかどうかは今のショー／マックの選択に任せ、**ボタンは増やさない**。
- 自分から見せた手が `selfLearn` に入らない作りなら（`me.score` が無いなど）、見せた手も評価して入れる。

### 2-3. 称号（任意）

- 「わざと見せた」…読まれたクセで、はじめて相手を引っかけた。今の称号の仕組み（`shisho-titles`）に1つ足す。

## 3. 守ること

- 第1〜4章では出さない（今の `selfOn` のまま）。第1〜3章の難しさ・CPUの打ち方は変えない。
- 読む強さ（±0.08）は変えない。案1は見せ方だけ、案3は「引っかけた相手がしばらく読まない」だけを足す。
- 第7章のジンの本物のテル（`release`）、フラッシュバック（`CFG.flashback`）、最後のハンド（`S.finalHand`）には出さない（今の `selfOn` のとおり）。
- ボタンや操作は増やさない（平常心のような仕組みは入れない）。
- 画面チェック（毎回のルール）：スマホ縦 390×844、横 844×390、PC 1280×800 で、次の場面のスクリーンショットを撮る。
  - 視線の線が伸びたところ／あなたの手元へ寄り返したところ／結論の吹き出し／「引っかけた」の判
  - 確かめること：吹き出し・札・判が、手札・ボタン・ボード・ポットの表示に重ならないか、画面からはみ出さないか。
- 自動対戦（フリー対戦4人・6人、第5〜7章、裏の卓、一夜）でエラーがないこと。テストでは設定 `quiz:false` にする。
