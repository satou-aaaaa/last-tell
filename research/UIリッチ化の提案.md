# UIをリッチにする提案（2026-10-09）

- 見本: research/UIリッチ化_見本.html（Artifact で公開）
- 全案が同時に動く動画: research/UIリッチ化_全案.mp4
- 対象: story/shisho.html（読むだけで、編集はしていない）

## いまの画面がリッチに見えない理由
- 面がどれも平らな塗りになっている。
  - 卓（`.felt`）は緑の放射グラデーション1枚に、`inset box-shadow` で茶色と金の線を重ねただけ。
  - カード（`.card`）は白のグラデーション。チップ（`.chip`）は単色の楕円。
  - ボタン（`button.act`）は単色の平行四辺形。
- 光の向きがない。ランプの光、影の落ち方、素材のざらつきがないので、「画面に描いた図形」に見える。
- 名札（`.plate`）とポット表示は、半透明の黒い四角だけ。

## 案（色・配置・操作は変えない。素材と光と動きを足す）
| 案 | 内容 | 主に変わるところ |
|---|---|---|
| 案1（おすすめ） | 卓の素材と光。フェルトの毛並み（ノイズの質感）、真上のランプで中央を明るく、革張りのパッド付きレールとステッチ、ロゴの薄い刷り込み、煙のような薄いもや | `.felt`、`.felt-wrap` にレール用の要素を追加、背景 |
| 案2（おすすめ） | カードとチップの質感。紙のざらつき、内側の印刷線、明朝体の数字を四隅に、裏面は深紅に金の格子とエンブレム＋ときどき光が走る。チップは縁にインサートの入ったクレイチップ | `.card`、`.card.back`、`.chip` |
| 案3 | ボタンと名札の質感。光沢と下の影、金額は金色、押すと沈んで光が流れる。バーは金の細い縁＋赤のにじみ。名札とポット表示は角を切った黒い板に金の縁、名前は明朝体 | `button.act`、`.actionbar`、`.plate`、`#potSign` |
| 案4 | 動きの手ざわり。手番の名札の周りに持ち時間の光の輪、ポットの数字が増えるとふくらんで光る、勝ち札が浮いて光が走り役名が金の札で出る、ハンド終わりに赤い斜めの線で画面をぬぐう | 演出のみ（チップの着地とカメラは実装済みなので含めない） |
| 案5 | タイトル画面。ネオン管の看板のような「LAST TELL」（1文字がたまにまたたく）、背景にバーの酒棚の灯り、右にカードの扇 | `#title` |

## おすすめ
案1＋案2。プレイ中に一番長く見ている卓・カード・チップが本物らしくなるので、全体の印象が一番変わる。見た目だけの変更で、ルール・操作・難しさには触れない。次に足すなら案3。

## 注意
- キャラの絵は「キャラの見た目をリアルに」スレッドの担当なので触れていない。
- 重なりやはみ出しの修正は「ゲームの問題点と改善点」スレッドの担当なので、ここでは扱わない。
- 質感は CSS のグラデーションと、小さな SVG ノイズ（data URI）だけで作る。画像ファイルは増えない。
- `prefers-reduced-motion` では動き（もや、光の走り、またたき）を止める。
- 見本はスマホ縦（390×844）、スマホ横（844×390）、PC（1280×800）で、横スクロールや重なりがないことを確認済み。
