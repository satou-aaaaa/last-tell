# カメラ演出 案2「寄る＋ピント送り、テルの瞬間に寄り直す」実装仕様

- 決定：2026-10-09 satou さん（「かなり良いです」）
- 見本：https://claude.ai/artifact/CR28D5jqVYYiCK6UniqSdZ の「2」（ソースは research/カメラ演出B改_見本.html）
- 動画：research/カメラ演出B改_全案.mp4
- 経緯：最初の5案（research/カメラ演出_見本.html）から B「寄る＋ピント送り」が選ばれた。そのあと「顔しか映らずテルが分かりにくい」という指摘を受けて、顔からチップまで入る構図にし、テルの瞬間に寄り直す形に直した。
- 注意：キャラに胴体や腕は描き足さない（satou さんが「元のほうがよい」と判断）。キャラの絵は今のまま使う。

## 1. 動き（1回の手番）

| 場面 | カメラ | ほかの演出 |
|---|---|---|
| CPUの手番が来た（考え中） | その席へ寄る（ミドル）。顔からその人のチップの山までを1画面に入れる | 手番の人以外の席と卓を少しぼかして暗くする（ピント送り）。周辺を暗くする |
| テルが出た（`showTell` で `p.tell` が付いた瞬間） | テルの場所へ寄り直す（クローズ）。約1.3秒たったらミドルに戻る | 今の擬音の札（`#cue{i}`、「ちらっ」など）はそのまま出す |
| CPUがアクションした | ミドルのまま | レイズ／オールインのときだけ、上下に黒い帯（高さ9%）と英語の大きな文字（RAISE / ALL IN と金額）。コールとフォールドは小さな文字だけ |
| あなたの手番・ショーダウン・ハンドの終わり | 全体に戻る | ぼかし・帯を消す |

## 2. 倍率と位置

- ミドルの倍率：スマホ縦 1.5 ／ スマホ横 1.3 ／ PC 1.4
  - 置き方：席の中心x、顔とチップの中間（顔の中心から約0.07H下）を、画面の (50%, 34%) に置く
- クローズの倍率：スマホ縦 2.7 ／ スマホ横 2.2 ／ PC 2.4
  - 置き方：下の「テルの場所」を画面の (50%, 40%) に置く
- はみ出し：卓の外が見えないように、端で止める。tx は [W−W·z, 0] の範囲に収める。ty は [H−H·z, 0.1H] の範囲に収める（上だけ少し余白を許す）
- 動きの速さ
  - ミドルへの移動・全体へ戻る：0.7秒 `cubic-bezier(.22,.9,.24,1)`
  - クローズへの寄り：0.32秒 `cubic-bezier(.3,.9,.3,1)`（スッと速く）

## 3. テルの場所（寄る先）

`CUE_LABEL` の各キーについて、席の中で寄る場所を決める。

| cue | 寄る先 | 見え方 |
|---|---|---|
| glance（チップを見る） | 顔とチップの山の中間（チップ寄り） | 目線が下がる（chars.css の `.pupils`）＋チップの山が一瞬光る |
| fast（すぐ賭ける） | チップの山 | 賭けるチップがサッと前に出る（0.4秒×2回） |
| sweat | 額 | `.t-sweat` |
| smile / talk / stare | 口・目 | 今の `.bust.cue-*` のアニメ |
| still | 顔全体（クローズの倍率を2.0に下げる） | 今の `.cue-still` |
| glove（クロウ） | 手袋の指先（絵の中の手の位置） | chars.js の `opts.tell:'hidden'` |
| scar / release（ジン） | 顎の傷 | chars.js の `opts.tell` |

ジンの本物のテル（第7章の release）も、ほかのテルと同じ寄り方にする。特別に強調しない。強調すると答えが分かってしまうため。

## 4. 作り方（shisho.html）

1. `#table` の中の `.busts` `#busts`、`.felt-wrap`、`#plates` を、新しい `<div class="cam" id="cam">` で囲む。
   - カメラは `#cam` の `transform` だけで動かす。
   - `.hud`、`#potSign`、`#mine`、`.needlerow`、`#cutin`、`.dcall`、`#toast`、`#quiz` は `#cam` の外に置いたままにする。
   - こうすると、自分の手札・ボタン・吹き出しは拡大されない。
2. 新しく `camTo(i, kind)` を作る（kind は 'mid' / 'tell' / 'wide'）。
   - `render()` の最後で、`S.toAct` と `!p.human` から 'mid' か 'wide' を決める。
   - `showTell` で `p.tell` を付けたあと、`camTo(i,'tell')` を呼ぶ。1.3秒後に 'mid' へ戻す。
   - 戻すタイマーは手番が変わったら消す。
3. ぼかしは、`#table` に `.focusing` を付けて行う。
   - 中身：`.bust:not(.turn)`、`.felt` に `filter: blur(1.5px) brightness(.6)`。
   - 古い端末では重いので、`SETTINGS.depth===false`（立体化オフ）のときはぼかしを使わず、暗くするだけにする。
4. 帯と英語の大きな文字は `#table` 直下に置く。レイズとオールインで出す。
   - 今の `#cutin` とは別のものにする。
   - 同時に出る場合は、`#cutin` のほうを優先して帯を出さない。
5. 設定に「カメラ演出：強め／控えめ／オフ」を足す。保存先は `SETTINGS.cam`、初期値は '強め'。
   - 控えめ：ミドルだけ（テルで寄り直さない、帯なし）。
   - オフ：今と同じ。
   - `prefers-reduced-motion` のときは、初期値を「控えめ」にして、移動を瞬間切り替えにする。
6. 速さの設定 `SETTINGS.speed==='fast'` のときは、移動時間を半分にする。
7. カメラは、6人卓・4人卓・ストーリーの全章で同じように動かす。
   - ヘッズアップ（第7章）は相手が1人なので、ミドルの倍率を下げる（×0.85）。

## 5. 守ること

- 第1〜3章の難しさ・CPUの打ち方・テルの出る確率は変えない。演出だけの変更にする。
- テルが出ていないときは寄り直さない（寄ること自体がヒントになりすぎないように）。
- あなたの手番では必ず全体に戻す。手札・ボタン・揺さぶるボタンを隠さない。
- 画面チェック：スマホ縦 390×844、横 844×390、PC 1280×800 で、次の3つの場面のスクリーンショットを撮って確かめる。
  - ミドル
  - テルのクローズ
  - オールインの帯
  - 確かめること：重なり・はみ出し・手札やボタンが隠れていないか。自動対戦でエラーがないことも確かめる。
