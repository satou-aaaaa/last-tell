# ライブポーカー「あるある」調査

目的：実際のテーブルでよくある出来事や人のクセ（あるある）を、ゲームの要素として入れる。すでに決まっている **テル、テーブルトーク、店ごとのハウスルール、ディーラー演出**（[実装仕様](ライブ要素実装仕様.md)）と重ならないものを中心に集めた。

調べ方：ライブポーカーの経験談やポーカー用語としてよく語られるものを、一般的な知識から整理した。Web検索では日本のアミューズメントポーカー店の「あるある」をまとめた信頼できる記事は見つからなかったので、個々の項目は**よく言われること（推測を含む）**として扱う。

前提：チップは点数のまま。現金や景品につながるもの（バッドビート・ジャックポット、換金、サテライト）は入れない。

## 1. あるある一覧

### A. ツイてない・ツキすぎ系
| あるある | 中身 |
|---|---|
| **バッドビート** | AAなど圧倒的に強い手が、リバーの1枚で逆転される |
| **クーラー** | 強い手同士がぶつかり、どちらも降りられない（フルハウス対フォーカードなど） |
| **カードが来ない夜** | 何十ハンドも弱い手しか来ない |
| **7-2で勝つ** | 一番弱いと言われる手で勝ってしまい、盛り上がる |
| **バッドビート話が長い人** | 「さっきさ、AAでさ……」と同じ話を何度もする |

### B. 人のクセ・ふるまい
| あるある | 中身 |
|---|---|
| **長考して降りる** | さんざん考えた末にフォールド。周りが脱力する |
| **スロウロール** | 勝っているのにわざとゆっくり手を見せる。マナー違反として嫌われる |
| **自分の手を読み間違える** | フラッシュに気づかず捨てかける。「カードがしゃべる」（見せた手で判定する）ルールがある |
| **何度も手札を見返す** | 配られた2枚を、角だけそっとめくって何度も確認する（スクイーズ） |
| **カードプロテクター** | 自分の手札の上に、お守りのチップや小物を置く |
| **縁起かつぎ** | 「この席は勝てる」「このプロテクターじゃないと」と言う |
| **チップを指で回す** | チップトリック。うまい人ほどさりげない |
| **机を叩いてチェック** | 「チェック」と言わずにテーブルを2回トントンと叩く |
| **トイレ中にブラインドが溶ける** | 席を外しているあいだにブラインドだけ払い続ける |
| **負けると無口になる** | スタックが減るにつれて口数が減る |
| **「ナイスハンド」** | 負けた側が勝った側に声をかける。気持ちのいい文化 |

### C. 店・夜の空気
| あるある | 中身 |
|---|---|
| **「あとワンハンドだけ」** | 終電の時間なのに帰れない |
| **夜が深くなると卓が荒れる** | 遅い時間ほど参加が増え、オールインが増える |
| **常連の噂話** | 「あの人、昔プロだったらしい」 |
| **隣の卓の歓声** | 大きな手が出ると店中がざわつく |
| **店の名物メニュー** | カレーや唐揚げなど、卓で食べる定番がある |
| **優勝者の写真が壁に貼られる** | 店の壁やSNSに勝者が載る |
| **席待ち・新卓が立つ** | 待っていると新しいテーブルが開く |

### D. トーナメントあるある（最終章向け）
| あるある | 中身 |
|---|---|
| **バブル** | 入賞直前になると全員が急に慎重になる |
| **バブルがはじけた瞬間** | 入賞が決まると一気にオールインが増える |
| **ショートスタックの粘り** | 少ないチップで何度もオールインして生き残る（第5章「逆転」と相性が良い） |

## 2. ゲームでの使い方（おすすめ順）

### おすすめ1：「あるある」実績（称号）
- 起きたら自動で記録される称号にする。勝ち負けに影響しないので、承認済みの第1〜3章にも入れられる。
- 例：「7-2で勝った」「AAで負けた（バッドビート）」「長考の末に降りた」「ブラインドで溶けた」「ワンハンドだけ、のつもりが10ハンド」
- 師匠がひとことコメントする。「AAで負けたか。それもポーカーだ」
- 称号一覧を章選択画面に置くと、また遊ぶ理由になる。

### おすすめ2：カードプロテクターと縁起かつぎ
- 章クリアのごほうびに、各店の看板にちなんだプロテクター（錨、銀の鍵、月のコインなど）を手札の上に置ける。
- 見た目だけのアイテムなので、収益化方針の「売るのは見た目だけ」にそのまま合う。
- 縁起かつぎのセリフ（「このプロテクターじゃないとな」）を常連キャラに言わせる。

### おすすめ3：手札をめくって見る（スクイーズ）
- 手札を最初は伏せておき、タップや長押しで角からめくる。ライブらしい緊張感が出る。
- 設定で「いつも表で見る」に切り替えられるようにする。

### おすすめ4：ストーリーに入れるあるある
- **バッドビート／クーラーを物語で起こす**：第5章「少ないチップからの逆転」の冒頭で、決まった配り方のハンドを1回だけ見せ、AAで負けてチップが減った状態から始める。ジンの「あの夜」の話（引退の理由）につなげられる。
- **スロウロールする悪役**：マナーの悪い相手を出し、ジンがたしなめる。ライブのマナーを自然に教えられる。
- **ゲンが自分の手を読み間違える**：第1章の会話で、ゲンがフラッシュに気づかず捨てかける小ネタ（勝敗には影響させない）。
- **「あとワンハンドだけ」**：章クリア後に終電の時計を出す演出。最終章「錨亭、閉店後」で時間が朝に近づいていく。

### おすすめ5：店の空気
- ハンドの合間に、卓にいない常連や店主が噂話をする（「あの人、昔は……」）。テーブルトークとは別で、勝負に関係ない雑談。
- 夜が深くなる演出：ハンド数が進むと照明が少し暗くなり、CPUの参加率がほんの少し上がる（第4章以降のみ）。
- 章クリアで、その店の壁に主人公の写真（立ち絵）が貼られる。今の「看板を受け取る」演出と組み合わせる。

### その他（小さく足せるもの）
- 机を2回タップでチェック（操作のおまけ。誤操作に注意）。
- 長考して降りるCPUの演出（テルのタイミングと少し重なるので、笑いどころとして控えめに）。
- 負けた相手の「ナイスハンド」セリフ。
- 最終章のバブル演出。

## 3. 入れないもの
- **バッドビート・ジャックポット**（実店舗で、バッドビートに賞金が出る仕組み）：お金の要素が強いので、称号だけにする。
- **サテライト（大会の参加権が当たる）**：実際の大会につながると価値が生まれるので入れない。
- **飲酒やタバコの描写**：AdSenseやポータル審査で不利になりうる（推測）。「ドリンク」は中身をぼかす。

## 決めてほしいこと
- まず「あるある実績（称号）」と「カードプロテクター」から入れる方向でよいか（おすすめ）
- 第5章の冒頭で、決まった配り方でバッドビートを起こす演出を入れてよいか
