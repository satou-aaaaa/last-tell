# 名札が顔にかぶる問題の修正（2026-10-10）

satou さん：「顔にチップの表示がかぶっていることがあります」

## 原因
相手の名札（名前・チップ）は卓のふちから**上へ**伸びる作り（相手の手札を隠さないため）。
D・アクション・勝率・役名・言葉の札がそれぞれ1行ずつ積み上がり、6人卓のスマホ縦では口・鼻・目まで隠れていた。端の席は名札が細くなって行がさらに増えていた。

## 直し方（CSS だけ・新しいファイル `src/01b_style_plate.css`）
- D は名札の上の角に小さく重ねる（1行使わない）
- 行は「名前・チップ・ようす1行」まで：勝率が出ている間は古いアクションを、役名が出たら負けた側の古いアクションを隠す
- 4人以上の卓：名前と言葉の札を1行に、アクションの額は卓のチップの札にもあるので名札では省く。勝った人はそのハンドの間だけチップの行の代わりに「勝ち +額」と役名
- 端の席でも名札の幅を中身に合わせる。スマホ縦の4人以上は星を省く（6人卓と同じ）

## 本線へ
`src/order.json` の `"01b_style_camlite.css"` の直後に `"01b_style_plate.css"` を足す。ほかのファイルは変えていない。
