# 「できた」の条件と公開の基準

開発と設計のベストプラクティス 案13・14（2026-10-10 satou 決定）。今まで README・qa/README・ひな形・メモに分かれていた決まりを1枚にまとめたものです。新しい決まりは足していません（案1〜5・8・11 で決まった書き方を除く）。

## 1. 変更が「できた」と言える条件（全部のスレッド）
ゲームを変えたら、次を全部満たしてから「できた」と報告する。

### 作るとき
- [ ] 自分の担当ファイルだけを変えた（[並行作業の分担.md](並行作業の分担.md)）。書き戻しは `lane.py writeback`
- [ ] 本体の関数を包み直していない。節目の処理は `LT.on('startHand', …)` などの合図に登録した（js/00b_hooks.js）
- [ ] 新しい状態は `S.<自分の機能>` の下にだけ置き、自分の合図の中で消している
- [ ] 保存は `saveGet` / `saveSet`（js/16a_store.js）。新しいキーは SAVE_KEYS にも足した。形を変えたら版を上げて SAVE_MIGRATE を書いた
- [ ] 乱数で配る札を作るときは `LT.rand()`（js/19a_seed.js）
- [ ] 新しい台詞は `{ja, en, who}` を並べたデータで持ち、英語のない行は入れていない
- [ ] 「夜」を題名・名前に使っていない。「あの日」。セリフにお金の話がない
- [ ] 第1〜3章の難しさ、第7章のジンの本物のテルに触れていない

### 確かめるとき
- [ ] `python3 dev/tools/build.py <src> <out.html>` が ✅（文法の間違いがあると止まる。書き方の error が 0件）
- [ ] 検査は GitHub の CI で回す（2026-10-14）：途中・書き戻す前は `sh qa/ci_check.sh <out.html> <名前>`、公開は publish-v<版> のプルリクエスト（自動で長い版）。結果は CI の知らせのあと `sh qa/ci_result.sh <番号>` で読む。手元で回すのはブラウザを使わない数秒の検査（`node qa/unit/run.js`）だけ
- [ ] スマホ縦 390×844・スマホ横 844×390・PC 1280×800 で、重なり・はみ出し・隠れ・文字切れを見た（英語版の画面も1つ）。CI の画面の一覧3枚（`ci_result.sh <番号> --shots`）と、前の版から変わった画面で見る。自分で撮り直さない
- [ ] 報告に、検査の結果と画面の確認結果を書いた

### 版を出すとき（本線）
- [ ] 下の「公開の基準」を満たす
- [ ] `snapshot.py save src vNN`
- [ ] 版ごとのクリエイター目線・UI/UX・交代レビューのスレッドが始まる（まとめ役）
- [ ] [決めたこと.md](決めたこと.md) に、その版で決まったことが1行ずつある

## 2. 不具合の重さ（3段階）
| 重さ | 例 | どうするか |
|---|---|---|
| **重い** | 進めなくなる・止まる／画面が真っ白／保存が消える・壊れる／チップの合計が合わない／ルールの間違いで勝ち負けが変わる／第1〜3章の難しさが変わる | **1件でもあれば出さない。** 見つけたらほかの作業より先に直す |
| **中** | 見た目が崩れるが操作はできる／ボタンや手札が一部隠れる／英語が抜けて日本語が出る／決めごと（「夜」・お金の話）に反する台詞 | 公開の前に直す。間に合わないときは数と中身を書いて残し、次の版で直す |
| **軽い** | 言い回し・小さなずれ・好みの問題 | 公開後でよい。まとめて直す |

- 自動検査の ❌ は、中身を見て重い・中のどちらかに分ける（qa の結果は ❌ / ⚠️ / 🟡 のまま）。
- テスターからの報告（GitHub の報告フォーム、ゲームの「不具合を報告」）にも、この3段階を付ける。フォームへの欄の追加はテストサイトのリポジトリ担当に頼む。

## 3. 公開の基準（出してよいか）
テストサイトに出す版も、ストアに出す版も、次を全部満たしたら出す。
1. **重い不具合が 0件**
2. 自動検査（全部、`--changed` なし）に ❌ がない。あるときは「中」として理由を書いて残す
3. 中の不具合で残すものは、数と中身を版の報告に書いてある
4. 画面3種の確認をした
5. ストアに出す版だけ：節目レビュー（qa/交代レビューと節目レビューの手順.md）を通した

公開した版で重い不具合が見つかったら、すぐ直した版を出す。
