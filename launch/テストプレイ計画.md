# LAST TELL テストプレイ計画（2026-10-08）

Google Play の「12人×14日間」のクローズドテストを確実に通すための計画です。iPhone 版（TestFlight）も同じ人に頼めるようにしておきます。
元にしたもの：[モバイルアプリ化調査.md](../mobile/モバイルアプリ化調査.md)、[リリースに必要なシステム.md](../prerelease/リリースに必要なシステム.md)。
感想の聞き方は [テスト感想アンケート.md](テスト感想アンケート.md) にあります。

※ 外部への投稿・送信はまだしていません。募集文は案です。

---

## 1. 結論

1. **20人を目標に集める。** 条件は「12人が14日間連続で参加」なので、途中でアンインストールする人が出ても下回らないよう、2倍近く集めておく。
2. **集め方は3段構え。** ①家族・友人・同僚（8〜10人）、②ポーカー好き・ゲーム好きの知り合い（5人）、③開発者同士のテスト交換コミュニティ（5〜10人）。
3. **テスターは18歳以上に限る。** アプリは18+ の想定（模擬ギャンブル）なので、募集文とアンケートで年齢を確認する。
4. **テスト用のメーリングリストは Google グループで作る。** 参加・退出を自分で管理でき、Play Console に1つ登録するだけで済む。
5. **14日間で「ただ入れてもらう」だけで終わらせない。** 1日目・7日目・14日目にアンケートを送る。本番公開の申請時に Google から「テストで何を集め、何を直したか」を聞かれるので、その答えにもなる。

---

## 2. 必要な条件（再確認）

| 項目 | 内容 |
|---|---|
| 対象 | 2023年11月13日以降に作った**個人の**デベロッパーアカウント |
| 条件 | クローズドテストに**12人以上**が**14日間連続**でオプトイン（参加）していること |
| 数え方 | テスターが「テストに参加」してから、アプリを入れたまま14日続くこと（途中で抜けた人は数えない、と言われている） |
| その後 | Play Console から「製品版へのアクセス」を申請。テスト内容についての質問に答える。審査は通常7日以内 |
| 出典 | [Google Play ヘルプ：新しい個人デベロッパーアカウントのテスト要件](https://support.google.com/googleplay/android-developer/answer/14151465) |

規約は変わりやすいので、Play Console に登録した時点の表示で人数と日数を確認すること。

iPhone 版（TestFlight）には人数・日数の条件はありません。外部テスターは最大1万人、最初のビルドだけ Apple の簡単な審査があります。

## 3. 日程（目安）

| 時期 | やること |
|---|---|
| テスト開始の2〜3週間前 | 募集を始める（下の4章）。Google グループを作る。アンケートのフォームを作る |
| 1週間前 | 参加を表明した人に、手順の案内（5章）を送る。Android を持っているかを確認 |
| **0日目** | クローズドテストを公開。テスターに参加リンクを送る |
| 1日目 | アンケート①（第一印象）。参加人数を Play Console で確認 |
| 3日目 | 参加人数が15人未満なら追加募集（コミュニティで補充） |
| 7日目 | アンケート②（中間）。ここまでの不具合を直した版を出す |
| 10日目 | お礼と「あと4日、アンインストールしないでください」の連絡 |
| 14日目 | アンケート③（最終）。12人以上が14日続いていることを確認 |
| 15日目以降 | 製品版へのアクセスを申請（7章の答え方を使う） |

テスト中に新しい版を出すのは問題ありません。テスターは自動で新しい版に更新されます。

## 4. テスターの集め方

### ① 身近な人（目標8〜10人）
- 家族、友人、同僚、学生時代の知り合い。一番抜けにくい。
- Android を持っていない人は iPhone 版（TestFlight）のテスターとして頼む（人数には数えられないが、感想は役に立つ）。

### ② ポーカー・ゲーム好き（目標5人）
- 地元のアミューズメントポーカー店の知り合い、ボードゲーム仲間、Discord のゲーム仲間。
- ルールに詳しい人の感想は、テルや店ルールの調整に効く。
- **注意：** ポーカー店にお願いする場合も、アプリ内のチップや勝ちを店の特典と結びつける話はしない（プロジェクトの方針）。

### ③ 開発者同士のテスト交換（目標5〜10人）
- 個人開発者が「お互いのアプリをテストし合う」コミュニティ。こちらも相手のアプリを14日間入れる必要がある。
  - X のハッシュタグ（例：#相互テスト、#個人開発、#クローズドテスト）
  - Reddit の r/AndroidClosedTesting、r/TestMyApp
  - Discord の個人開発者サーバー
- 感想の質は低めになりがち。人数の保険と考える。

### 有料のテスター代行について
- 「12人を14日間用意します」という有料サービスもある。使うかどうかは任せるが、**おすすめはしない**。Google は「本当にテストをした」ことを求めており、本番申請の質問で中身のなさが目立つと却下される例がある（各社のブログでの報告。公式の明言は未確認）。

## 5. テスターへの案内文（案）

### 募集文（LINE・メッセージ用）
```
【お願い】ポーカーのスマホゲームを作っています

「LAST TELL ‐ 師匠とホールデム」という、
1人で遊べるポーカー（テキサスホールデム）のゲームを作っています。
引退した伝説のプレイヤーに弟子入りして、街のクラブを一軒ずつ回るストーリーものです。

Google Play で公開するには、12人以上に14日間テストしてもらう必要があります。
Android のスマホをお持ちの方、手伝ってもらえませんか？

・やること：アプリを入れて、14日間アンインストールしないでいただくだけ
　（遊んでもらえたら、なおうれしいです）
・感想アンケート：3回（各3分ほど、任意）
・料金：かかりません。課金もありません
・条件：18歳以上の方

協力してもらえる方は、Google アカウントのメールアドレス（Gmail）を教えてください。
```

### 参加の手順（参加表明した人に送る）
```
ありがとうございます！手順はこの3つです。

1. このグループに参加してください（テスター用の名簿です）
   → [Google グループのURL]
2. このリンクを開いて「テスターになる」を押してください
   → [Play Console のオプトインURL]
3. Google Play からアプリをインストールしてください

★ お願い：14日目（[日付]）までアンインストールしないでください。
   途中で消すと、人数に数えられなくなってしまいます。
★ 不具合や感想は、いつでもこの連絡先に送ってください。
```

### 10日目のリマインド
```
テストに協力いただきありがとうございます。あと4日です！
[日付]までアンインストールしないでいただけると助かります。
最終アンケートは14日目に送ります。
```

## 7. 本番申請の質問への答え方（下書き）

製品版へのアクセスを申請するとき、Play Console でテストについて聞かれます（項目は変わることがある）。アンケートの結果を使って埋めます。

| 聞かれること（例） | 答えの下書き |
|---|---|
| テスターをどう集めたか | 家族・友人、ポーカー愛好家の知人、開発者コミュニティから約20名を募集。全員18歳以上 |
| テスターはどう使ったか | 14日間、ストーリーモード第1〜4章とフリー対戦を中心にプレイ。3回のアンケートで感想を収集 |
| どんな感想があったか | （アンケート結果から：例「ルール説明が分かりやすい」「テルの見分けが難しい」「文字が小さい」） |
| 何を直したか | （例：文字サイズの拡大、第1章のヒント追加、○○端末での表示崩れの修正） |
| 対象ユーザー | 18歳以上のポーカー初心者〜中級者。ストーリーを楽しみたい1人用ゲームのユーザー |
| 製品版の準備ができている理由 | クラッシュ報告がなく、主要な不具合はテスト中に修正済み |

## 8. テスト中に見ること

- **Play Console の「リリース前レポート」**：クローズドテストに上げると Google が実機で自動起動して不具合を報告してくれる（無料）。
- **Android Vitals**：クラッシュ・応答なし。
- **アンケートの結果**：とくに「途中でやめた理由」「どの章で止まったか」。
- テスト用の広告ID になっているか（本番広告をテスターに押させない）。
