仕様: research/改善提案_2026-10-14b_実装仕様.md §4。元の質問: launch/テスト感想アンケート.md、launch/観察テストの手順.md。

## 作り方（2分）
1. https://script.google.com を開き「新しいプロジェクト」
2. 中身を消して [フォームを作るスクリプト.gs](フォームを作るスクリプト.gs) を全部貼る
3. ▶「実行」を押す → Google の許可画面で自分のアカウントを選び「許可」（「安全ではない」と出たら「詳細 → 移動」。自分で作ったスクリプトなので大丈夫です）
4. 下の「実行ログ」に出る **回答用URL**（…/viewform）を Claude に送る

これでフォームと、回答がたまるスプレッドシートが satou さんの Google ドライブにできます。メールアドレスは集めません。
