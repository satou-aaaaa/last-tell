# 手で作る用（コピペ表）

https://forms.new を開いて、上から順に作ります。
**選択肢は、下の枠の中を全部コピーして1つ目の選択肢の欄に貼ると、1行ずつ別の選択肢になります。**
設定（⚙）：「メールアドレスを収集する」は「収集しない」。

---

**タイトル**
```
LAST TELL テスト版 感想 / Playtest feedback
```
**説明**
```
テストに参加していただきありがとうございます。3分ほどで終わります。回答はゲームの改善だけに使います。名前やメールアドレスは聞きません。
Thank you for playtesting! This takes about 3 minutes. Answers are used only to improve the game. We do not ask for your name or email.
```

---

### 1. ラジオボタン・必須
```
18歳以上ですか / Are you 18 or older?
```
```
はい / Yes
いいえ / No
```

### 2. ラジオボタン・必須（「その他」を追加）
```
遊んだ言葉 / Language you played in
```
```
日本語 / Japanese
English
```

### 3. ラジオボタン・必須
```
ポーカー（テキサスホールデム）の経験 / Poker (Texas Hold'em) experience
```
```
初めて / Never played
ルールは知っている / I know the rules
アプリでよく遊ぶ / I play apps often
お店や大会で遊ぶ / I play live or in tournaments
```

### 4. ラジオボタン・必須
```
どこまで進みましたか / How far did you get?
```
```
第1章の途中 / Partway through Chapter 1
第1〜3章 / Chapters 1-3
第4〜6章 / Chapters 4-6
第一部クリア / Finished Part 1
第二部まで / Reached Part 2
```

### 5. 均等目盛・必須（1〜5）
```
全体として、おもしろかったですか ★ / Overall, how fun was it?
```
1のラベル `つまらない / Not fun`　5のラベル `とてもおもしろい / Very fun`

### 6. 均等目盛・必須（1〜5）
```
続きを遊びたいですか ★ / Do you want to keep playing?
```
1のラベル `思わない / No`　5のラベル `とても思う / Definitely`

### 7. ラジオボタン・必須
```
相手の「テル（クセ）」は読めましたか ★ / Could you read the opponents' tells?
```
```
読めて勝てた / Yes, and it won me hands
ときどき / Sometimes
全然わからない / Not at all
まだ出てきていない / Haven't seen them yet
```

### 8. チェックボックス（「その他」を追加）
```
困ったところ（いくつでも）/ What got in the way? (choose any)
```
```
ルールがわからない / Didn't understand the rules
何を押せばいいかわからない / Didn't know what to tap
会話が長い / Too much dialogue
負けが続いた / Kept losing
文字やボタンが小さい / Text or buttons too small
画面が切れる・重なる / Things cut off or overlapping
動きが重い / Slow or laggy
英語が不自然 / English felt unnatural
特になし / Nothing
```

### 9. 段落
```
一番おもしろかった瞬間 / Your best moment
```

### 10. 段落
```
わかりにくかった所・うまく動かなかった所（どの画面か）/ What was confusing or broken? (which screen)
```

### 11. 記述式
```
このゲームを友だちに一言で説明すると？ / Describe this game to a friend in one line
```

### 12. 段落（説明を付ける）
```
遊んだ記録 / Play record
```
説明
```
ゲームの「その他 → 感想を送る → 遊んだ記録をコピー」を貼ってください。章・ハンド数・画面の大きさだけが入っています。名前や手札は入りません。
Paste from Other → Send feedback → Copy play record. Only chapter, hand count and screen size. No names or cards.
```

---

**最後に**：右上の「送信」→ リンクのマーク → 「URLを短縮」→ コピーして、スレッドに貼ってください。
（18歳未満で終える分岐は省いてOKです。1問目の「いいえ」の人の回答は集計で外します。）
