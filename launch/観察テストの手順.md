# 観察テストの手順（黙って見るテスト）2026-10-10

ねらい: 作った人以外が、**どこで迷い、どこで面白がり、どこでやめるか**を見る。アンケートより先にやる（人は「わかりやすかった」と答えても、実際には迷っていることが多いため）。
[テストプレイ計画.md](テストプレイ計画.md)（ストア審査のための12人×14日）とは別に、その前に行う小さなテストです。
元の調査: [research/プロのゲームクリエイター目線_調査と改善点.md](../research/プロのゲームクリエイター目線_調査と改善点.md)

※ 外部への連絡・募集はまだしていません。声をかけるのは satou さんです。

---

## 1. 人と回数

- **3〜5人**。ポーカーを知らない人を最低2人、知っている人を1人入れる。
- 1人 **20〜30分**。直接会うか、ビデオ通話で画面を共有してもらう。
- 1回目のテストのあと直してから、別の人で2回目をすると効果が大きい。

## 2. 準備

- テストする人のスマホで https://satou-aaaaa.github.io/last-tell/ を開いてもらう（セーブがない状態から）。
- 下の「記録用紙」を1人1枚。時計（ストップウォッチ）。
- 録画できるなら、画面と声を録画させてもらう（本人の同意を取る）。

## 3. 最初に伝えること（このまま読む）

> 「今日はゲームのテストです。あなたをテストするのではなく、ゲームの悪いところを探すのが目的です。思ったことをそのまま声に出しながら遊んでください。私は基本的に口を出しません。やめたくなったら、いつやめてもかまいません。」

## 4. やってもらうこと

1. タイトル画面から、自由に遊んでもらう（「ストーリーを遊んで」とは言わない。何を押すかも見たいため）。
2. 20分たったら、きりのいいところで止める。
3. 最後に5つだけ質問する（下の5）。

## 5. 見ている側のルール

- **教えない。助けない。** 止まっても30秒は待つ。それでも進めないときだけ「今、何をしようとしていますか？」と聞く。
- 「どうですか？」と聞かない（感想は最後にまとめて聞く）。
- 表情・声・手の動きをメモする（ため息、笑い、画面を連打、スマホを置く、など）。

## 6. 記録用紙

| 時刻 | 画面 | 起きたこと（迷った／笑った／声が出た／連打した／やめかけた） | メモ |
|---|---|---|---|
| 0:00 | タイトル | | |
| | | | |

必ず書く数字:
- 「はじめる」から**最初に自分で判断するまでの時間**（秒）: ____
- 最初の **「降りる」を自分の意思で押したか**（ジンの助言どおりか、自分で考えたか）: ____
- **会話をスキップした回数**: ____
- 第1章をクリアできたか／何ハンドかかったか: ____
- 20分の中で、**やめたくなった瞬間**（本人が言った、またはスマホを置いた）: ____

## 7. 最後の質問（5つだけ）

1. このゲームを友だちに一言で説明すると？（核が伝わっているかを見る。「クセを読む」「師匠」が出れば成功）
2. 一番おもしろかった瞬間は？
3. 一番わかりにくかった・面倒だった瞬間は？
4. 続きを遊びたいですか？（はい／どちらでもない／いいえ）
5. ジンはどんな人だと思いましたか？

## 8. 終わったら

- 用紙を写真に撮って、このプロジェクトに送る（Claude がまとめて、直すところを優先度つきで出します）。
- ゲーム内の記録（どの章で何回負けたか）は、「その他 → 引き継ぎコードを出す」のコードを送ってもらうと見られるようにする予定です（実装仕様 B1）。
- 同じ所で2人以上が迷ったら、それは「人のせい」ではなく「ゲームのせい」として直す。
