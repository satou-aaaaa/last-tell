# Web で公開して、スマホにインストールできる形（PWA）の整理

作成：2026-10-09。結論から書きます。

## 結論

- **できます。** 今の GitHub Pages のテストサイトに、ファイルを4種類足すだけで「ホーム画面に追加 → アプリのように全画面で起動、オフラインでも遊べる」形になります。ストアの審査・登録費・年齢区分の申請は要りません。
- **おすすめは「PWA を先に出し、ストア版はあとから」**。同じ `shisho.html` をそのまま使うので、二度手間になりません。PWA で反応を見ながら、並行して Google Play の12人×14日テストを進められます。
- ただし本格公開の前に、**自分のドメインに移すこと**を強くおすすめします（理由は「注意点」の1つ目）。

## ストア版との比較

| | PWA（Web） | ストア版（Capacitor） |
|---|---|---|
| 出すまでの手間 | 小。ファイルを置くだけ。審査なし | 大。登録費（Apple 年12,980円、Google 25ドル）、審査、Play の12人×14日テスト |
| 更新 | すぐ反映（次の起動で新しい版） | 毎回ストア提出・審査 |
| インストール | Android：Chrome が「インストール」を出す。iPhone：Safari の共有ボタン →「ホーム画面に追加」を自分で選ぶ（案内が必要） | ストアから普通に入れる |
| 見つけてもらう | ストア検索に出ない。SNS・検索・口コミ頼み | ストア検索・おすすめに出る |
| 広告 | **AdMob は使えない**。AdSense の「H5 Games Ads」（ゲーム向け、審査あり）など Web 向け広告になる。単価はアプリより低め（推測） | AdMob（リワード広告など） |
| 年齢区分・審査 | ストアの年齢区分は不要。自分で「18歳以上向け・模擬ギャンブル」と表示しておく | Apple 18+ の見込み、IARC の質問票など |
| 同意画面（EU） | 広告や計測を入れるなら、Web でも Google 認定の同意画面が必要（AdSense の「プライバシーとメッセージ」で用意できる） | 同じく必要（AdMob 側で用意） |
| セーブ | ブラウザの保存領域。サイトの住所（ドメイン）ごとに分かれる | アプリ内に保存。端末バックアップも効く |
| iPhone の制限 | プッシュ通知はホーム画面に追加した場合のみ（iOS 16.4 以降）。Safari で開いているだけだと、しばらく使わないと保存データが消されることがある（ホーム画面に追加した場合は対象外） | 制限なし |
| オフライン | Service Worker で可能 | 可能 |

## 注意点

1. **セーブとドメイン。** 今の `satou-aaaaa.github.io` は、satouさんの GitHub Pages の全サイトで同じ「住所」を共有しています。保存データの置き場所も共有になり、あとで自分のドメインに移すと**セーブが引き継がれません**。本格公開の前にドメインを決め、そこから公開するのが安全です（公式サイト用に取る予定のドメインと同じものでよい）。移す場合に備えて、引き継ぎコードは先に入れておきます（[ゲームに入れる分_実装仕様.md](ゲームに入れる分_実装仕様.md) で作成中）。
2. **フォントを同じサイトに置く。** 今は Google Fonts をネットから読み込んでいるので、オフラインだと文字の見た目が変わります。フォントファイルを一緒に置けば解決します（OFL なので可）。
3. **更新の出し方。** オフライン用に保存した古い版が残るので、「新しい版があります → 再読み込み」の小さな表示を入れます。
4. **H5 Games Ads は申し込みと審査が必要**で、模擬ギャンブルのゲームが通るかは申し込んでみないと分かりません（未確認）。広告なしで先に公開し、反応を見てから申し込む順番が無難です。
5. 広告や計測を入れた時点で、プライバシーポリシーと EU 向けの同意画面が必要になります（このスレッドで文面を作成中）。

## 今のテストサイトに足すもの

| ファイル | 中身 |
|---|---|
| `manifest.webmanifest` | アプリ名「LAST TELL」、縦向き、全画面表示、背景色、アイコンの場所 |
| `sw.js`（Service Worker） | ゲームとフォントを端末に保存して、オフラインで起動できるようにする。版が変わったら入れ替える |
| アイコン | 192×192、512×512、余白付き（maskable）512×512、iPhone 用 180×180 |
| `index.html` の頭に数行 | manifest へのリンク、iPhone 用の設定（全画面・アイコン）、Service Worker の登録、「インストール」案内ボタン |

`index.html` はゲーム本体（`shisho.html`）のコピーなので、頭に足す数行はゲームのスレッドに頼み、ほかの3つは公開用リポジトリに置くだけで済みます。

## PWA を先に出す場合の順番

1. ドメインを決めて取得し、GitHub Pages をそのドメインで公開（年1,000〜2,000円程度、推測）
2. 引き継ぎコードとフォントの同梱を入れる
3. manifest・Service Worker・アイコンを足して、Web 版として公開（広告なし）
4. 反応を見ながら、Play のクローズドテストを並行して進める
5. 広告を入れるなら、その前にプライバシーポリシーと同意画面を用意して H5 Games Ads に申し込む
