# PC版（Steam）で公開するための調査

作成：2026-10-09。登録・支払いなど取り消せない操作はしていません。調べただけです。
「（推測）」と書いたところは公式資料で確かめられなかった部分です。

## 結論

- **出せます。** CPU相手の、お金に換えられないチップのポーカーは Steam に普通にあります（例：[Prominence Poker](https://store.steampowered.com/app/384180/Prominence_Poker/) は「Gambling」タグ付きで販売中）。Steam の禁止リストにギャンブルの項目はなく、問題になるのは「現実の価値に換えられる賭け」です。LAST TELL はチップを現金で売らない方針なので当てはまりません。
- **いちばん大きな違いは広告です。** Steam は「広告で稼ぐゲーム」を禁止しています（2025年2月に明記）。リワード広告も不可。だから **Steam 版は「買い切り・広告なし」** にするのが基本です。スマホ版・Web版（無料＋広告）とは売り方を分けることになります。
- **作り方は Electron がおすすめ。** 今の `shisho.html` をほぼそのまま包めて、Steam の実績・オーバーレイをつなぐ部品（steamworks.js）が Electron 向けに用意されています。
- **お金：登録料 100ドル（約1.5万円）／1本。** 売上が1,000ドルに届けば返ってきます。売上の取り分は Steam 30%。
- **時間：支払いから最短でも3〜4週間＋「近日公開」ページを2週間以上。** 実際はウィッシュリストを集めるため、発売の数か月前に「近日公開」ページを出すのが普通です。

## 2. 規約（ギャンブル・広告・AI）

### ギャンブル系
- Steam の「出してはいけないもの」15項目に、ギャンブルそのものは入っていません。該当しうるのは「販売地域の法律違反」と「決済会社の基準違反」の2つ。
- 現実の価値に換えられる賭け（チップの現金販売・換金、アイテム賭博）は避ける。LAST TELL の方針（チップは売らない・換金しない）のままなら問題なし。
- ストアでは「Gambling」「Card Game」「Poker」タグを付けるのが自然です。

### 広告（ここが最重要）
- 禁止項目に「**広告を収益源にするアプリ**」があります（[オンボーディング](https://partner.steamgames.com/doc/gettingstarted/onboarding)、2025年2月の明確化：[報道](https://mp1st.com/news/valve-bans-forced-advertisements-and-advertising-based-business-models-on-steam)）。
  - 不可：プレイ中の広告、広告を見ないと続けられない作り、**広告を見るとごほうび（リワード広告）**。
  - 可：ゲーム同士の相互宣伝、自然な商品配置。
- → Steam 版のビルドでは **広告のコードを丸ごと外す**。ゲーム側に「Steam 版かどうか」のスイッチを1つ入れて、広告・同意画面・計測を切り替えます。

### AI の使用申告
- 内容アンケートで、開発に AI を使った場合は申告が必要（[Content Survey](https://partner.steamgames.com/doc/gettingstarted/contentsurvey)）。LAST TELL はコード・絵（CSS/SVG）・文章を AI と作っているので「事前に作ったコンテンツに AI を使用」として正直に書きます。ゲーム中にその場で AI が文章を作るわけではないので、追加のガードレール説明は不要（推測）。

## 3. 年齢区分

- Steam では、日本の CERO や米国の ESRB は **不要**。発売前に Steam の **内容アンケート** に答えれば済みます。
- **ドイツ**：2024年11月15日以降、年齢区分のないゲームはドイツで表示されない。内容アンケートに答えると Steam がドイツ向け区分を出してくれる（[ドイツ向け説明](https://partner.steamgames.com/doc/gettingstarted/contentsurvey/germany)）。EU を外さない方針なので必ず答える。
- 模擬ギャンブルがあるので、各国の区分は高め（12〜18歳以上）に出る見込み（推測）。成人向けの性・暴力表現はないので、Steam の「成人向けコンテンツ」年齢確認ゲートは付かない見込み（推測）。
- スマホ版と同じく、子ども向けにはしない。ストア説明に「実際のお金は賭けません」と明記。

## 4. HTML ゲームを PC 版にする方法

| | Electron | NW.js | Tauri |
|---|---|---|---|
| 中身 | Chromium を同梱 | Chromium を同梱 | OS の WebView を使う |
| サイズ | 大（配布 約100MB前後、推測） | 大（同程度） | 小（数MB〜） |
| 見た目のずれ | なし（どの PC でも同じ Chromium） | なし | **あり**（Windows=Edge、Mac=Safari系）。3つの OS で確認が必要 |
| Steam 連携 | **steamworks.js が Electron 向けに手順あり**（実績・オーバーレイ） | steamworks.js は対応をうたうが手順なし。RPGツクール・Construct 製の Steam ゲームで実績多数 | Rust で書く必要あり |
| セーブの書き出し | 少し手間（裏側のプロセス経由） | 簡単 | Rust 経由 |
| 総合 | **おすすめ** | 次点 | 今回は不向き |

参考：[steamworks.js](https://github.com/ceifa/steamworks.js)、[JS ゲームを PC 向けに包む比較](https://jslegenddev.substack.com/p/the-struggle-of-wrapping-a-javascript)

### Electron にする場合の作業
1. Node.js のプロジェクトを作り、`shisho.html` とフォントファイル（PWA 版と同じく同梱。OFL なので可）を入れる。
2. 起動時はウィンドウ 1280×800 前後、F11／設定で全画面切り替え。メニューバーは消す。
3. Google Fonts などネット読み込みをなくし、**オフラインで完結** させる。
4. steamworks.js をつなぐ（Steam 起動中かの確認、実績、オーバーレイ）。オーバーレイは Electron で動かすのに設定が要る。
5. Windows 版をまず出す。**Steam Deck は Windows 版がそのまま Proton で動く** ことが多い。Mac 版は Apple の公証（Apple Developer 登録が必要）が要るので後回し。
6. Windows の「発行元不明」警告は、Steam 経由のインストールなら通常出ない（推測）。

## 5. Steam の機能

### 実績
- steamworks.js で `achievement.activate('名前')` を呼ぶだけ。候補：各章クリア、看板5つ、王冠（6つ目の看板）、第一部／第二部クリア、テルを初めて見抜く、相手の穴を突いて勝つ、顔なじみ帳コンプリート など。数は 20〜40 個が目安（推測）。

### クラウドセーブ
- **Steam Auto-Cloud** は、保存フォルダとファイル名の形を Steamworks の画面で指定するだけで、起動時・終了時に自動同期してくれる（[Steam Cloud](https://partner.steamgames.com/doc/features/cloud)）。
- ただし今のセーブはブラウザの保存領域（localStorage）にあり、Electron ではそれがデータベース形式のフォルダになるため、同期対象として扱いにくい。→ **Steam 版ではセーブを `save.json` という普通のファイルにも書き出す** 小さな変更を入れる。保存キー（progress / settings / notes）と、リリース前に入れる予定の版番号 `v` はそのまま使う。

### Steam Deck
- 縦横比 16:10、1280×800。これまでの UI チェックで PC 1280×800 を見ているので、画面の土台はある。
- 「Verified（動作確認済み）」を取るには、コントローラーだけで全操作できることと、文字が小さすぎないことが求められる（推測を含む）。最初は「Playable」でも販売はできる。

## 6. 値段と売り方

- 売上の取り分：Steam 30%（1,000万ドルを超えると 25%、5,000万ドル超で 20%）。
- 値段は自由（最低 0.99 ドル相当）。地域ごとに通貨別の値段を決める。発売後30日は値段を変えず、セールもできない。値上げすると30日セール不可。（[価格の決まり](https://partner.steamgames.com/doc/store/pricing)）
- 目安：ストーリー付きの小規模インディーなら **800〜1,500円** あたりが多い（推測）。最初のセール（発売記念割引）は発売日から入れられる。
- **体験版**：Steam は本編に紐づく無料の体験版を追加料金なしで出せる。第1〜3章を体験版にすると、Steam Next Fest（年3回の体験版イベント）に出られ、ウィッシュリストを集めやすい。

## 7. Web版・スマホ版とどう両立するか

| | Web（PWA） | スマホ（Google Play / App Store） | **PC（Steam）** |
|---|---|---|---|
| 売り方 | 無料＋広告 | 無料＋広告（リワード広告） | **買い切り・広告なし** |
| 中身 | 同じ `shisho.html` | 同じ（Capacitor で包む） | 同じ（Electron で包む） |
| 違う部分 | 同意画面・AdSense | 同意画面・AdMob | 広告と同意画面を外す、実績、`save.json` |
| セーブの引き継ぎ | 引き継ぎコード | 引き継ぎコード | 引き継ぎコード（**全版共通にできる**） |

- 心配な点：「Web で無料で遊べるのに Steam で買う理由」。考えられる答えは2つ。
  - **案1（おすすめ）**：Steam 版は「広告なし・実績・クラウドセーブ・大画面」の完全版として売る。無料版は広告ありのまま。スマホゲームでよくある形。
  - **案2**：Web 版を第1〜3章の体験版にして、全章は Steam とスマホで。Web の入口が狭くなる。
- ゲーム本体は1つのまま、ビルドのときに「web / android / ios / steam」を切り替える形にすると、更新が1回で済みます。

## 8. 出すまでの順番（例）

1. PWA 版を先に出す（今の方針どおり）。
2. Steam 版のスイッチ（広告オフ・`save.json`・実績）をゲームに入れる。
3. Electron で Windows 版を作り、手元で動作確認。
4. Steamworks に登録（ここで 100ドル。**satouさんの判断が必要**）→ 税・銀行・本人確認。
5. ストアページ（画像・紹介文・トレーラー）を作って「近日公開」で出す。ウィッシュリスト集め開始。
6. 体験版を出す → 可能なら Next Fest に参加。
7. 製品版を審査に出す → 発売（近日公開2週間以上・支払いから30日以上たっていること）。

### ストアページ用に新しく要る素材（推測を含む、登録後に最新の寸法を確認）
- カプセル画像 数種（ヘッダー 920×430、メイン 1232×706、縦長 748×896、小 462×174 など）
- ライブラリー用画像（600×900、背景 3840×1240、ロゴ）
- スクリーンショット 5枚以上（16:9。PC 画面で撮り直し）
- トレーラー動画（任意だが強く推奨。`launch/紹介動画絵コンテ.md` を流用できる）
- 既存の `launch/store_images/` はスマホ向けなので、PC 向けに撮り直しが必要。
