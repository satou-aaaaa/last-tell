このページは、ゲーム「LAST TELL（最後のテル）」（以下「本ゲーム」）が、遊ぶ人の情報をどう扱うかを説明します。本ゲームには Web 版（ブラウザで遊ぶ版・ホーム画面に追加して遊ぶ版）と、App Store・Google Play で配信するアプリ版があります。

1. 運営者

satou（個人）
お問い合わせ：サポートページに記載のメールアドレス

2. 運営者が集める情報

運営者は、あなたの名前・メールアドレス・位置情報などの個人情報を集めません。本ゲームにはアカウントやログインはなく、運営者のサーバーもありません。

進み具合・設定・メモ・呼び名などのセーブデータは、あなたの端末の中だけに保存され、運営者には送られません。セーブデータは、ゲーム内の「その他 → セーブを消す」、アプリの削除、またはブラウザのサイトデータの削除で消せます。

お問い合わせのメールをいただいた場合は、そのメールアドレスと内容を、返信と不具合の調査のためだけに使います。

3. 外部のサービスに送られる情報

本ゲームは、次の外部サービスを使います。これらのサービスには、あなたの端末から直接、下の情報が送られます。各サービスでの扱いは、それぞれのプライバシーポリシーに従います。

サービス（送信先）使う版送られる主な情報目的

GitHub Pages（GitHub, Inc.）Web 版IPアドレス、アクセスした日時・ページWeb 版の配信（サーバーの記録）

Google によるデータの使い方は「Google のサービスを使用するサイトやアプリから収集した情報の Google による使用」をご覧ください。GitHub については GitHub のプライバシーに関する声明 をご覧ください。

4. 広告と同意

  • 欧州経済領域（EU など）・英国・スイスでは、アプリの起動時に同意の確認画面を出し、同意した範囲でだけ広告と計測を使います。同意はゲーム内の「その他 → プライバシー設定」からいつでも変えられます。
  • iPhone・iPad では、他社のアプリやサイトをまたいだ追跡（トラッキング）を許可するかを OS の画面でたずねます。許可しない場合、広告IDは使われません。後から「設定 → プライバシーとセキュリティ → トラッキング」で変えられます。
  • Android では「設定 → Google → 広告」（機種によって異なります）で、広告IDの削除やリセットができます。
  • 本ゲームはギャンブル（実際のお金を賭けるもの）の広告を出しません。

5. 欧州（GDPR）・英国の利用者の方へ

  • 運営者が自ら保持している個人データは、お問い合わせのメールだけです。
  • 広告と計測のための処理は、あなたの同意に基づきます。クラッシュの報告は、ゲームを動く状態に保つという正当な利益に基づきます。
  • データは Google LLC などにより、米国を含む欧州域外で処理されることがあります。Google は EU 標準契約条項や EU-米国データプライバシーフレームワークなどの仕組みを使っています。
  • あなたには、アクセス・訂正・削除・処理の制限・異議・データポータビリティ・同意の撤回の権利と、お住まいの国の監督機関に苦情を申し立てる権利があります。運営者が保持していないデータ（Google のサービスが扱うデータ）については、各サービスの窓口もご利用ください。

6. 年齢について

本ゲームは、ポーカーを題材にした模擬ギャンブルを含むため、18歳以上の方を対象にしています。子ども向けの設定で広告を配信することはありません。18歳未満の方の情報と知りながら集めることはありません。

7. 現金・景品について
