FAQ

Does it cost money?

The Game is free to play. There is no way to buy chips. Chips are points only and cannot be exchanged for money or prizes.

Can I play offline?

Yes. After the web version has been opened once, it starts without an internet connection.

How do I add it to my home screen?

Android (Chrome): menu at the top right → "Install app" or "Add to Home screen".
iPhone / iPad (Safari): Share button → "Add to Home Screen".

Can I move my save to a new phone?

Use "More → Show transfer code" in the Game, then paste the code into "More → Enter transfer code" on the new device. This works between iPhone and Android, and between the web and app versions.

How do I start over or delete my data?

"More → Delete save data" erases all save data on your device. This cannot be undone, so copy a transfer code first if you may want it back. We hold no data on any server, so there is nothing else to delete.
