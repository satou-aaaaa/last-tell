## 1. 作品の概要

**LAST TELL（最後のテル）** は、スマホとブラウザで遊ぶテキサス・ホールデム（ポーカー）のゲームです。プレイヤーは負けの込んだ新人。港のバーで出会った老人「ジン」に弟子入りし、街のカードルームを一軒ずつ回って看板を集めます。

- 「テル」とは、ポーカーで手の強さが表に出てしまう**クセ**のこと（汗をかく、口元が緩む、など）。このゲームでは相手のテルを見て、ブラフ（はったり）かどうかを読むのが遊びの中心です。
- **絵の最大の役割は「テルが目で見てわかること」**です。表情としぐさは、スマホの小さな画面でも読み取れる大きさで描いてください。
- 物語の芯は、15年前の「あの夜」。ジンは一番弟子のハヤトにクセを敵（クロウ）へ売られ、大勝負に負けてカードを置きました。最終章で、ジンは弟子（プレイヤー）にだけ本物のクセを見せます。これがタイトルの「最後のテル」です。
- 賭けるのは看板と名誉で、お金ではありません。ギャンブルをあおる表現（札束、現金、カジノの派手な演出）は避けてください。

## 2. 絵柄の方針

### 2-1. 全体

- **かっこいい系。** 落ち着いた大人の雰囲気、夜のカードルームに合うやや渋めの塗り。
- **明るいポップなアニメ調は使いません**（一度試して不採用になりました）。
- 画面の基本色は、ほぼ黒の背景 `#0d0e13`、文字の生成り `#f1ede4`、金 `#e2b65b`、赤 `#d7263d`。キャラはこの暗い画面に置かれます。輪郭がつぶれないよう、髪や服が暗い色のキャラは**縁の光（リムライト）**を入れてください。

### 2-2. 強さで描き分ける（大事）

**強いキャラほどかっこよく、弱いキャラほどかわいく**描きます。ゲーム内の強さ（★の数＝ rank）がそのまま絵の方向を決めます。

| ★ | 方向 | 頭身・線の目安 | 該当キャラ |
|---|---|---|---|
| 1 | かわいい | 低め（6頭身前後）、丸い線、大きめの目、表情が大きく動く | ゲン、ハル、タロウ、店主 |
| 2 | ややかわいい | 6〜7頭身、やわらかい線 | ミナ、ソウ、ケンジ、ミサキ |
| 3 | かっこいい | 7頭身以上、直線的、目は細め、表情の動きは小さい | ロク |
| 4 | かなりかっこいい | 同上。影を深く、色数を絞る | セキ、レイカ、ハヤト |
| 5 | 最もかっこいい | 同上。シルエットだけで誰かわかる強さ | ジン、クロウ |

- ★3以上のキャラには、それぞれ**光の色（グロー）**があります（§5 各キャラ）。目の光、アクセサリーの反射、リムライトにこの色を使ってください。
- ★が高いほど**表情の動きを小さく**します。強いキャラは顔に出ない、というゲームの設定と一致させるためです。その分、テルのしぐさ（§4）をはっきり描きます。
- ハヤト（★4）とクロウ（★5）をあえて同じ格にしないのは、「師匠とラスボスだけが最上位」と見た目でわかるようにするためです。

## 3. 納品物と形式

### 3-1. 1キャラあたりの納品物

| # | 納品物 | 内容 | 形式・サイズ |
|---|---|---|---|
| A | 立ち絵（バストアップ） | 胸から上、やや斜め向き。会話と対面シーンで使う | 透過 PNG、縦 2048px 以上 |
| B | 表情差分 6種 | §3-2 の6種。A と同じポーズで顔だけ差し替え | 透過 PNG、A と同じサイズ・位置 |
| C | テルのしぐさ | §4 のそのキャラのテル（強い手用と弱い手用の2つ） | 透過 PNG（Live2D の場合はモーション） |
| D | 卓のアイコン | 卓の席に出す顔の切り抜き。**画面では 46px 前後で表示** | 透過 PNG、512×512px |
| E | 元データ | レイヤーを残した PSD（Live2D の場合は `.cmo3` も） | PSD |

- D は A を縮小するだけでは小さすぎて顔がつぶれます。**46px でも誰かわかるように、目鼻と髪型を強調した別描き**をお願いします。
- 主人公は顔を描きません（プレイヤーが自分を重ねるため）。立ち絵は不要です。

### 3-2. 表情6種（全キャラ共通）

ファイル名とゲーム側の名前をそろえるため、英語の ID を必ず使ってください。

| ID | 表情 | 使う場面 |
|---|---|---|
| `normal` | 通常 | 待機中、会話の基本 |
| `thinking` | 考え中 | 相手が手番で迷っているとき |
| `confident` | 強気 | 大きく賭けるとき |
| `troubled` | 困り | 大きく賭けられて迷うとき |
| `win` | 勝ち | ハンドに勝ったとき |
| `lose` | 負け | ハンドに負けたとき |

★4〜5のキャラは、6種の差が小さくて構いません（例：ジンの `win` は口の端がわずかに上がるだけ）。ただし `normal` と並べて見比べたとき、違いがわかる程度にはしてください。

`{キャラID}_{種類}.png` 例：`jin_normal.png`、`jin_tell_strong.png`、`jin_icon.png`

|---|---|---|---|

### 3-4. Live2D で発注する場合

- 使う場面は**会話と対面シーンの大きな立ち絵だけ**です。卓の 46px アイコンは静止画（§3-1 D）のままにします。
- 動き：呼吸・まばたき・視線のゆれ（待機）、表情6種、テルのしぐさ（§4）、口パク（音声なし。文字送りに合わせて開閉する程度）。顔を大きく振る、全身を動かす、などは不要です。
- パラメータ名は Cubism の標準名（`ParamAngleX`、`ParamEyeLOpen`、`ParamMouthOpenY` など）を使ってください。表情とテル用に独自のパラメータを作る場合は、**最初の1体（ジン）で決めた名前を、2体目以降も同じにします。** ゲーム側のコードを1つで済ませるためです。
- 表情は `.exp3.json`、テルは `.motion3.json` で、ファイル名は §3-2・§4 の ID に合わせてください（例：`thinking.exp3.json`、`tell_bluff.motion3.json`）。
- テクスチャは 1体 2048px 1枚程度に収めてください（スマホのメモリのため）。
- 元データ（`.cmo3` と PSD）の納品をお願いします。後から表情を足すときに使います。

## 4. テル（クセ）のしぐさ

このゲームでは、相手が「強い手」か「ブラフ（弱い手）」のときに、決まったしぐさが出ます。画面には文字（例：「口元が緩んだ」）でも出ますが、**絵でも同じことが起きているように見せる**のが目標です。

### 4-1. 共通のしぐさ（ゲーム側の名前つき）

| ID | 画面の説明文 | 絵での見せ方 |
|---|---|---|
| `smile` | 口元が緩んだ | 口の端が片方上がる。かわいいキャラはにやにや、強いキャラはほんのわずか |
| `talk` | いつもより口数が多い | 口が開いて身ぶりが増える。手が前に出る |
| `glance` | 自分のチップをちらっと見た | 目線だけ下（手元）へ動く |
| `still` | 急に動かなくなった | まばたき・呼吸の動きが止まる。体が固まる |
| `stare` | こっちをじっと見ている | 目線がまっすぐプレイヤーへ。まばたきしない |
| `fast` | 考えずにすぐ賭けた | 前のめり、手がすっと前に出る |
| `sweat` | 汗をかいている | こめかみに汗、目が泳ぐ |

### 4-2. キャラごとのテル

| キャラ | 強い手のとき | ブラフのとき | 備考 |
|---|---|---|---|
| ゲン | `smile` | `talk` | 隠しごとができない人 |
| ハル | `glance` | `sweat` | 自信がない |
| ロク | `still` | `stare` | 感情を押さえこむ人 |
| セキ | `glance`（他人のチップを盗み見る） | `talk` | 確かめずにいられない |
| ミナ | `smile` | `fast` | 待つのが苦手 |
| レイカ | 逆のクセ：強いのに `talk`、弱いのに `glance` | — | わざと出している。目は笑っていない |
| ソウ | `smile` | `sweat` | 正直そのもの |
| ケンジ | `glance` | `talk` | |
| ミサキ | `smile` | `fast` | |
| タロウ | `still` | `sweat` | |
| ジン | 顎の傷に**触らない** | 顎の傷に**触る** | §5 ジン。最重要 |
| ハヤト | ジンと同じ姿勢で静かになる | 焦り（煽る、ゆっくり手を見せる） | §5 ハヤト |
| クロウ | 逆のクセ（全部わざと） | 逆のクセ | 隠しテル：本当に迷ったときだけ白い手袋の指先を直す |

## 5. キャラクター別シート

年齢は絵を描くための目安です（ゲーム内では明示しません）。

### 5-1. ジン（師匠） ★5　最もかっこいい　【最優先】

- **役どころ**：主人公の師匠。15年前は街一番の名手。今は港のバーで安いウイスキーを飲むだけの老人。
- **年齢の目安**：60代半ば
- **ひとこと**：自分を許せないまま15年飲んでいる、最強の老人。
- **見た目**：白に近い銀髪（`#e9e6df`）、短いあごひげ。**顎に古い切り傷**（20年前、少年のハヤトをかばって割れたグラスで切ったもの）。こげ茶の古いジャケット（`#2b2119`）。光は金 `#e2b65b`。
- **性格が見た目に出るところ**：短く言い切る、褒めない、目線は低め。猫背ではなく、座っているだけで卓が締まる姿勢。
- **小物**：安いウイスキーのグラス。チップ1枚（機嫌のいいときだけ指の上で転がす。§5-1 の差分として1枚あると嬉しい）。
- **テル（最重要）**：ふだん、無意識に顎の傷を指でなぞっている。**強い手のときだけ触らない。** ブラフのときは触る。
  - しぐさ C は2枚：`jin_tell_bluff`（人差し指で傷をなぞる）と `jin_tell_strong`（手は卓の上、傷から離れている）。
  - スマホで見ても「触っている／触っていない」がひと目でわかるように、手と傷の距離をはっきりさせてください。
- **追加でほしい1枚（任意）**：最終章で傷から手を離す瞬間。正面寄りで、まっすぐプレイヤーを見る。「お前には隠さん」。

### 5-2. ハヤト（元一番弟子、第5章のボス） ★4　かっこいい

- **役どころ**：ジンのクセを敵に売った元一番弟子。今はクロウの下で地下の賭場を任されている。
- **年齢の目安**：30代半ば
- **ひとこと**：師匠の打ち方を、師匠を否定するために使っている男。
- **見た目**：**ジンの配色を反転した版。** 黒髪、白いシャツ、光は暗めの赤（ロクの赤 `#e0344a` より暗く）。顔に傷は無い。
- **小物**：ジンからもらった古いカードプロテクター（手札の上に置く小さな重し）を今も使っている。物語で主人公に渡す大事な物なので、形がわかるように。
- **性格が見た目に出るところ**：皮肉な笑い、相手を見下ろす角度。マナーが悪い（ゆっくり手を見せる、など）。
- **テル**：ブラフや焦っているときは煽る表情（`hayato_tell_bluff`：片方の口角を上げて身を乗り出す）。**本当に強い手のときだけ、ジンと同じ姿勢で静かになる**（`hayato_tell_strong`：ジンの `normal` と同じ角度・同じ手の置き方。ただし顎には触らない）。ジンと並べたときに「同じだ」と気づけるようにしてください。
- **表情 `lose` の注意**：負けたあとは、怒りよりも寂しさが勝つ顔。

### 5-3. クロウ（王冠の主、第6章のボス） ★5　一番かっこいい

- **役どころ**：街一番のカードルーム「王冠」の主。15年前、ジンに勝った相手。ラスボス。
- **年齢の目安**：50代半ば
- **ひとこと**：勝ちを集めることに人生を使った、完璧な紳士。
- **見た目**：黒のスリーピース、**白い手袋**、銀の髪留め、**カラスの羽根のタイピン**。光は冷たい銀（例：`#c9d3e0`）。
- **性格が見た目に出るところ**：丁寧語を崩さない。怒らない。姿勢と所作が完璧。表情は6種とも差がごく小さい。
- **テル**：見せるクセは全部わざと（逆のクセ）。**隠しテル：本当に迷ったときだけ、白い手袋の指先を直す**（`crow_tell_hidden`）。ゲーム中で見つけられたら称号が出る隠し要素なので、目立たせすぎず、気づいた人にはわかる程度に。
- **表情 `lose`**：「ようやく、負けることができました」。悔しさではなく、ほっとした顔。

## 8. 契約で決めること（発注前に作家と合意）

リリース前調査（`prerelease/リリース前調査.md` §2-4）と Live2D 調査（§4-3）の要点です。

1. **使う範囲**：アプリ内での商用利用（広告収入あり）、App Store / Google Play での配信、ストアの紹介画像、宣伝（SNS、紹介動画、Webサイト）。
2. **著作権**：譲渡か、利用許諾か。個人開発なら「利用許諾＋上の範囲」で十分なことが多い。譲渡にする場合は「著作者人格権を行使しない」を一文入れる。
3. **改変**：表情の追加、色の調整、トリミング、縮小アイコン化をこちらでしてよいか。
4. **元データの納品**：PSD と `.cmo3`。追加料金になることが多いので、見積もりの段階で聞く。
5. **AI生成の使用**：使ってよいか、使わないでほしいか。使う場合でも、作家名や既存キャラ名を指示に入れないこと、既存作品に似せないことを条件にする。
6. **クレジット表記**：アプリのクレジット画面に名前を載せるか、どの名義で載せるか。
7. **実績公開**：作家が自分の実績として公開してよい時期（ゲームの公開後、など）。
8. **修正の回数**と、ラフ・線画・完成の各段階での確認。
9. **納期と支払い**：段階払い（ラフ確認後に半額、など）にするか。

Live2D 自体の利用料は、事業全体の年間売上が1,000万円未満のうちはかかりません（Live2D導入調査 §2）。
